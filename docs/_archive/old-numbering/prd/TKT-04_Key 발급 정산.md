## 1. 기능 개요

발급된 티켓(N Key · App Key)의 **전체 이력을 조회하고, 티켓별 과금(정산) 상태를 관리**한다. 재무·사업부가 "누구에게 무엇을 얼마에 발급했는지"를 확인하는 화면이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 **[티켓 발급] ▸ [Key 발급 정산]** (`/tickets/list`) |
| 데이터 출처 | **대장**(nkey(HLP) 발급 대장에서 가져온 과거 이력) + **신규발급**(이 시스템에서 발급한 티켓) |

---

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [티켓 발급] ▸ [Key 발급 정산]
   └─▶ TKT-04
         ├─ 필터·검색·정렬로 대상 티켓 찾기
         ├─ 행 [정산 등록] ─▶ TKT-05 (모달) ─ 저장 ─▶ TKT-04 갱신
         ├─ 행 [Key 정보]  ─▶ TKT-02 (모달, 발급된 티켓 값 기준) ─ 닫기 ─▶ TKT-04
         └─ 행 [삭제] ─ 확인 ─▶ 목록에서 제거
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-15` 티켓 = N Key / App Key + 정산 | 종류(N Key/App Key)와 **정산 구분(유료·무료·체험·미정)** 을 함께 관리 |
| `PC-016` 출처 구분 | **대장(ledger)** 과 **신규발급**을 배지·필터로 구분한다 |
| 요구사항 #1 | 체험 티켓은 **만료일과 잔여일**을 표시하고, 만료 건은 경고로 드러낸다 |
| `P-16` 정산 | 편집 정산(`PRJ-03`)과 별개. **코드 라이선스 과금**은 이 화면에서 관리 |

## 4. 사용법

### 4.1 상단 요약 (S1)

| 지표 | 의미 |
|---|---|
| 발급 티켓 | 현재 필터 기준 건수 |
| 유료 합계 | 유료 티켓 금액 합계 |
| 유료 건수 | 유료로 등록된 건수 |
| 무료 / 체험 | 각 건수 |
| 정산 미등록 | **아직 정산 구분을 등록하지 않은 건수**(0이 아니면 빨강 강조) |

요약은 **필터를 반영한 결과 기준**으로 다시 계산된다.

체험 만료 건이 있으면 목록 위에 경고가 표시된다 — **⚠ 체험 기간이 만료된 티켓 {n}건 — 유료 전환 또는 회수 여부를 확인하세요.** (S2)

### 4.2 필터 · 검색 (S3)

필터는 한 줄에 이어져 있고, 구분선(`|`)으로 묶음이 나뉜다.

| 요소 | 값 |
|---|---|
| 고객사 | 드롭다운. 기본 **고객사 전체** — 발급 이력이 있는 고객사만 나온다 |
| 종류 | `전체` / `N Key` / `App Key` |
| 정산 | `정산 전체` / `미정` / `유료` / `무료` — **체험은 필터에 없다** |
| 출처 | `전체` / `대장`(nkey(HLP) 발급 대장) / `신규발급`(이 화면에서 발급한 티켓) |
| 검색 | **고객사·내용 검색** — 발급 내용과 발급인을 함께 찾는다 |

### 4.3 정렬 (S4)

| 항목 | 동작 |
|---|---|
| 정렬 가능 열 | **발급일시 · 고객사 · 발급인** 3개. 머리글을 클릭하면 오름/내림이 바뀐다 |
| 기본 정렬 | **발급일시 내림차순(최근순)** |
| 표시 | 정렬 중인 열은 **▲ / ▼**(파랑), 나머지는 **↕**(회색) |

### 4.4 목록 항목

표는 가운데 정렬이며, **고객사 · 발급 내용 · 비고**만 왼쪽 정렬이다. 폭이 좁으면 가로 스크롤된다.

| 열 | 내용 |
|---|---|
| No | 발급 번호 — **삭제해도 다시 쓰지 않는다** |
| 발급일시 | 발급 시각(분 단위) |
| 종류 | **N Key**(파랑) / **App Key**(주황) |
| 고객사 | 업체명. 과거 이력이면 **대장** 배지(회색) |
| 발급 내용 | 발급 요약(코드 종류·S/O/B·페이지·권수·유효기간 등) |
| 발급인 | 발급한 직원. 없으면 `-` |
| 정산 | **미정**(회색) / **유료**(파랑) / **무료**(초록) / **체험**(주황). 체험은 아래 줄에 **~만료일 (D-n)**, 지났으면 **(만료)** 빨강 |
| 금액 | 유료일 때만 금액. 그 외는 회색 `-` |
| 비고 | 정산 등록 시 입력한 사유·계약 정보. 없으면 `-` |
| 작업 | [정산 등록] · [Key 정보] · [삭제] |

### 4.5 행 작업

| 버튼 | 동작 | 화면 |
|---|---|---|
| **[정산 등록]** | `TKT-05` 모달을 연다. 저장하면 목록의 정산·금액·비고가 즉시 갱신된다 | S8 |
| **[Key 정보]** | `TKT-02` 모달을 연다. **이미 발급된 티켓에 저장된 값**을 key·value로 보여준다(`TKT-01`의 같은 모달과 화면은 동일, 데이터 출처만 다름) | S7 |
| **[삭제]** | 확인 후 발급 기록을 목록에서 제거한다 | S13 |

`TKT-05` 정산 등록 모달은 고른 **과금 유형**에 따라 화면이 갈린다. 내용은 [TKT-05](TKT-05_정산%20등록.md) 참조.

| 과금 유형 | 추가 입력 | 화면 |
|---|---|---|
| 미정 | 없음 | S8 |
| 유료 | 금액(원) **필수** · 최근 유료 금액 참고 | S9 |
| 무료 | 없음(사유는 비고) | S10 |
| 체험 | 체험 만료일(기본 = 발급일 + 1개월) | S11 |
| 유료인데 금액 0 | 확인창 **유료는 금액을 입력해야 합니다.** | S12 |

## 5. 상태별 변화 · 메시지

### 5.1 상태

| 상태 | 화면 | 화면 번호 |
|---|---|---|
| 기본 목록 | 요약 5칸 + 필터 + 표. 최근순 정렬 | S1 |
| 정산 미등록 | 정산 열이 **미정**으로 표시되고, 상단 **정산 미등록** 건수에 포함 | S1 |
| 체험 진행 중 | 만료일과 **D-n** 표시 | S2 |
| 체험 만료 | 만료일 옆 **(만료)** 빨강 + 목록 상단 경고 배너 | S2 |
| 대장 이력 | 고객사명 옆 **대장** 배지 (툴팁: nkey(HLP) 발급 대장에서 가져온 과거 이력) | S2 |
| 필터 결과 없음 | 표가 비고 요약은 **0건 기준**으로 다시 계산된다 | S5 |
| 발급 이력 없음 | 아직 한 건도 발급하지 않은 상태 | S6 |

### 5.2 메시지

| 상황 | 노출 방식 | 문구 | 화면 |
|---|---|---|---|
| 발급 기록 삭제 | 확인창 | **발급 {No}번 기록을 삭제할까요?** | S13 |
| 체험 만료 존재 | 배너 | **⚠ 체험 기간이 만료된 티켓 {n}건 — 유료 전환 또는 회수 여부를 확인하세요.** | S2 |
| 필터 결과 없음 | 표 안내 | **필터에 맞는 티켓이 없습니다.** | S5 |
| 발급 이력 없음 | 표 안내 | **아직 발급된 티켓이 없습니다. 왼쪽 [티켓 발급] 메뉴의 [N Key 발급] 또는 [계정 발급]에서 발급하세요.** | S6 |
