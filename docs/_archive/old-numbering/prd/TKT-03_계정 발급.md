## 1. 기능 개요

**계정 = 고객사가 서비스(CasterN·폼솔루션·SDK)에 로그인하는 ID/PWD**다. 이 화면은 등록된 **모든 계정의 목록**이며, 여기서 계정을 **추가·상세 확인·삭제**한다. 등록과 상세 수정은 `TKT-06`에서 한다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 **[티켓 발급] ▸ [계정 발급]** (`/tickets/account`) |
| 형제 화면 | `TKT-01` N Key 발급 · `TKT-04` Key 발급 정산 |
| 하위 화면 | `TKT-06` 계정 등록(`/tickets/account/new`) · 상세·수정(`/tickets/account/{email}`) |
| 선행 조건 | 고객사가 `MEM-01`에 등록되어 있을 것. (App Key까지 발급하려면 `SOB-02`로 SOBP 할당) |

> **계정 수는 제한이 없다.** 한 고객사에 담당자별·서비스별로 여러 계정을 둔다 `PC-029`. ID(email)만 전체에서 유일하면 된다.
> **App Key 발급은 선택이다.** 계정만 먼저 등록해 두고 키는 나중에 `TKT-06` 상세에서 붙일 수 있다.

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [티켓 발급] ▸ [계정 발급]
   └─▶ TKT-03 계정 목록
          ├─ [＋ 계정 추가] ─────▶ TKT-06 등록 (/tickets/account/new)
          │                          └─ [계정 추가] ─▶ 목록에 노출
          ├─ ID(email) · [상세] ─▶ TKT-06 상세·수정 (/tickets/account/{email})
          │                          ├─ [저장]           ─▶ 계정 정보 반영
          │                          └─ [App Key 발급]   ─▶ TKT-04 · LOG-01 기록
          └─ [삭제] ─(확인창)─▶ 계정 + 연동 App Key 삭제
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `PC-029` 고객사당 계정 수 | **제한 없음.** 목록은 고객사가 아니라 **계정 단위**로 한 줄이다 |
| `PC-031` 계정 화면 분리 | 목록(`TKT-03`) / 등록·수정(`TKT-06`) 을 나눈다. **App Key 발급은 선택** |
| `PC-002` 내부 직원 전용 | 고객이 직접 계정을 만들지 않는다. **직원이 대신 등록**한다 |
| `P-13` 사용 서비스 | 계정은 **사용처(연동 서비스)** 를 갖고 그 서비스에서만 로그인된다 |
| `P-15` 티켓 = N Key / App Key | App Key 는 **계정과 연동되는 키**다. 계정 없이는 발급할 수 없다 |

## 4. 사용법

화면은 **요약 4칸 → 한 줄 필터 → 8열 표** 순서다.

### 4.1 요약 (S1)

| 칸 | 내용 |
|---|---|
| 등록 계정 | 전체 계정 수 |
| App Key 연동 | App Key가 **1개 이상** 있는 계정 수 |
| App Key 없음 | 아직 키가 없는 계정 수 (계정만 등록한 상태) |
| 발급 App Key | 발급된 키의 총 개수 |

> 요약은 **전체 기준**이며 필터의 영향을 받지 않는다.

### 4.2 필터 · 검색 (S3 · S4)

| 항목 | 규칙 |
|---|---|
| 고객사 | 계정이 등록된 고객사만 목록에 나온다 |
| 사용처 | CasterN / 폼솔루션 / SDK 연동 |
| 검색 | **ID(email) · 이름 · 고객사** 를 함께 본다 |
| 건수 | 필터 결과 건수를 함께 표시 |

세 조건은 **동시에** 걸린다. 조건에 맞는 계정이 없으면 **조건에 맞는 계정이 없습니다.** (S4)

### 4.3 목록 (S1)

| 열 | 표시 |
|---|---|
| 고객사 | `MEM-01` 고객사명 |
| ID (EMAIL) | 로그인 ID. 누르면 `TKT-06` 상세로 이동 |
| 이름 | NAME(담당자/사용자명) · 없으면 `—` |
| 사용처 | **CasterN / 폼솔루션 / SDK 연동** 배지. 값이 없는 과거 계정은 **미지정**(빨강) |
| CasterN 권한 | **전체 7** / **{n} / 7**(마우스를 올리면 권한 이름) / **미지정**(빨강, 0개) / **—**(CasterN 아님) |
| App Key | 이 계정에 연동된 키 개수 (0이면 회색) |
| 등록일 | 계정 생성일 |
| (작업) | **[상세]** · **[삭제]** |

### 4.4 계정 추가 (S1 → `TKT-06`)

**[＋ 계정 추가]** 를 누르면 `TKT-06` 등록 화면이 열린다. 등록을 마치면 **목록으로 돌아오고 새 계정이 표에 나타난다**.

### 4.5 삭제 (S5)

**[삭제]** → 확인창 → 계정과 **연동된 App Key가 함께** 삭제된다. 개별 App Key만 지울 때는 `TKT-06` 상세의 **[키 삭제]** 를 쓴다.
