## 2. 화면 구성

### 개요

**계정 발급** 은 서비스 로그인 계정을 관리하는 화면이다. 이 화면은 **목록**이며 등록·상세 수정은 `TKT-06` 이다.

계정은 **고객사당 여러 개**(제한 없음)를 둘 수 있고 ID(email)만 전체에서 유일하면 된다 `PC-029`. **App Key 발급은 선택**이라 계정만 먼저 만들어 두었다가 나중에 상세 화면에서 키를 붙일 수 있다.

CasterN 계정은 **권한 7종**(프로젝트 생성 · 심볼 편집 · 리소스 편집 · Ncode PDF 내보내기 · NCP2 내보내기 · App용 패키지 내보내기 · App 페이지 설정)을 개별 또는 모두 지정한다 `PC-031`.

### 상태 구성

이 화면은 **5개 상태**로 나뉜다. 구분: 기본 · 분기 · 차단 · 확인창

## 3. 상태별 변화

### TKT-03: S01 계정 목록 — 기본

*화면 정의서 상태 `S1`*

**구분** — 기본

좌측 메뉴 **[티켓 발급] ▸ [계정 발급]**(`/tickets/account`) 의 첫 화면. 등록된 **모든 고객사의 계정**을 한 표로 본다. 한 고객사에 계정을 **여러 개** 둘 수 있다 `PC-029`. **ID** 나 **[상세]** 를 누르면 `TKT-06` 상세·수정으로 간다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| [＋ 계정 추가] | 클릭 | `TKT-06` 등록 | `/tickets/account/new` |
| ID(email) · [상세] | 클릭 | `TKT-06` 상세·수정 | `/tickets/account/{email}` |
| [삭제] | 클릭 | S5 확인창 | 계정과 **연동 App Key가 함께** 삭제된다 |
| 요약 4칸 | 표시 | — | 등록 계정 · App Key 연동 · App Key 없음 · 발급 App Key |
| CasterN 권한 칸 | 표시 | — | **전체 7** / **{n} / 7**(마우스를 올리면 권한 이름) / **미지정**(빨강) / **—**(CasterN 아님) |
| App Key 칸 | 표시 | — | 이 계정에 연동된 키 개수 · 0이면 회색 |
| 사이드바 [N Key 발급] | 클릭 | `TKT-01` | 물리 키 발급 |
| 사이드바 [Key 발급 정산] | 클릭 | `TKT-04` | 발급 이력·정산 |
