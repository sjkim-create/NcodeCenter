## 2. 화면 구성

### 개요

**계정 등록·수정** — `TKT-03` 계정 목록에서 열리는 두 화면이다. **등록**(`/tickets/account/new`)은 ① 계정 정보 → ② 사용처·권한 → ③ App Key(선택) 3단계이고, **상세·수정**(`/tickets/account/{email}`)은 같은 ①② 를 고치고 ③에서 App Key 를 발급·삭제한다.

**App Key 발급은 선택**이다 — 계정만 먼저 등록해 두었다가 나중에 붙일 수 있다. CasterN 계정은 **권한 7종**을 개별 또는 모두 선택한다 `PC-031`.

### TKT-06: S05 App Key 함께 발급 (선택)
