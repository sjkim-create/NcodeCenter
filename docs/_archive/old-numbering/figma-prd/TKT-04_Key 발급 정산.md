## 2. 화면 구성

### 개요

발급된 티켓을 모아 보고 **정산(과금)** 을 등록하는 화면이다. 이 화면만 **폭 제한 없이** 전체를 쓴다(N Key·App Key 발급 폼은 900px 제한).

nkey(HLP) 발급 대장에서 가져온 **과거 이력**과 이 시스템에서 발급한 **신규 발급**이 한 목록에 섞여 있고, **대장** 배지와 출처 필터로 구분한다.

S7 은 `TKT-02` Key 정보 확인, S8~S12 는 `TKT-05` 정산 등록 모달이다.

| 체험 진행 중 | 표시 | — | **~2026-09-25 (D-29)** 주황 |

### TKT-04: S03 필터 — 종류 · 정산 · 출처

*화면 정의서 상태 `S3`*

**구분** — 필터

필터는 한 줄에 이어지고 구분선(**·**)으로 묶음이 나뉜다. ⚠ **정산 필터에는 「체험」이 없다** — `정산 전체 · 미정 · 유료 · 무료` 4개뿐이다. 고객사 목록에는 **발급 이력이 있는 고객사만** 나온다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 고객사 | 선택 | 해당 고객사만 | 기본 **고객사 전체** |
| 종류 | 클릭 | 전체 / N Key / App Key | — |
| 정산 | 클릭 | 정산 전체 / 미정 / 유료 / 무료 | **체험은 필터로 고를 수 없다** |
| 출처 | 클릭 | 전체 / 대장 / 신규발급 | 대장 = nkey(HLP) 발급 대장 · 신규발급 = 이 화면에서 발급한 티켓 |
| 검색 | 입력 | 발급 내용 + 발급인 | **고객사·내용 검색** |
| 요약 | 자동 | 재계산 | 필터 결과 기준으로 5칸이 모두 다시 계산된다 |
| 사이드바 [N Key 발급] | 클릭 | `TKT-01` | 고객사 선택 유지 |
| 사이드바 [계정 발급] | 클릭 | `TKT-03` | — |

| 발급인 | 클릭 | 가나다순 | — |

### TKT-04: S08 TKT-05 · 정산 등록 — 미정

*화면 정의서 상태 `S8`*

**구분** — 모달

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 대상 티켓 | 표시 | — | 잘못 열었으면 [취소]로 닫는다 |
| 과금 유형 | 클릭 | S9~S11 | 선택한 칸만 색이 채워진다 |
| 미정 | 선택 | 추가 입력 없음 | `TKT-04` 상단 **정산 미등록** 건수에 포함된 상태 유지 |
| 비고 | 입력 | — | 사유·계약 정보 |
| 최근 등록 | 표시 | — | 이미 등록한 이력이 있으면 **일시 · 등록자** |
| [저장] | 클릭 | `TKT-04` 갱신 | 목록의 정산·금액·비고가 즉시 바뀌고 `LOG-01` 에 기록 |
| [취소] · ✕ | 클릭 | `TKT-04` | 변경 없음 |

### TKT-04: S11 TKT-05 · 체험

*화면 정의서 상태 `S11`*

**구분** — 모달

**체험 만료일** 입력이 나타난다. 기본값은 **발급일 + 1개월**이며 바꿀 수 있다. 만료되면 목록에서 **(만료)** 로 바뀌고 상단 배너(S2)가 뜬다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 체험 만료일 | 선택 | — | 기본 = **발급일 + 1개월** |
| 안내 | 표시 | — | **만료되면 목록에서 (만료)로 표시되고 상단에 경고가 뜹니다.** |
