## 2. 화면 구성

### 개요

이미 코드를 받은 고객사를 **편집 관리 대상으로 올리는** 창이다. **고객사를 새로 만들거나 코드를 새로 할당하지 않는다** — 이미 할당된 코드 중 **어느 Owner를 편집할지** 고르는 것이다. 추가하면 ① 그 Owner 코드가 `PRJ-01`·`SOB-01` 에서 **편집** 으로 표시되고 ② 편집 프로젝트 목록에 그 고객사가 올라간다. 판정 규칙은 PRD §4.5.

### 상태 구성

이 화면은 **4개 상태**로 나뉜다. 구분: 기본 · 분기 · 차단

| 상태 | Figma 프레임 | 제목 | 구분 |
|---|---|---|---|
| `S1` | `PRJ-05:S01` | 진입 — 고객사 미선택 | 기본 |
| `S2` | `PRJ-05:S02` | Owner 코드 선택 | 기본 |
| `S3` | `PRJ-05:S03` | Owner 1개 — 자동 선택 | 분기 |
| `S4` | `PRJ-05:S04` | 할당 코드 없음 — 직접 입력 | 차단 |

## 3. 상태별 변화

### PRJ-05: S01 진입 — 고객사 미선택

*화면 정의서 상태 `S1`*

**구분** — 기본

`PRJ-02` 의 **[＋ 고객사 추가]** 로 열린다. ⚠ **고객사를 새로 만드는 화면이 아니다** — 이미 코드를 받은 고객사를 **편집 관리 대상으로 올리는** 창이다. 고객사를 고르기 전에는 아래가 비어 있고 **[추가]** 가 눌리지 않는다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 등록된 고객사 | 선택 | Owner 코드 목록 | `MEM-01` 등록분 · 가나다순 |
| [추가] | — | **비활성** | 고객사·Owner 가 모두 정해져야 눌린다 |
| 미선택 저장 | — | 확인창 | **고객사 관리에 등록된 고객사를 선택하세요.** |
| 다음 단계 안내 | 표시 | — | **추가 후 우측 상세에서 ＋교재(책) 추가로 편집 교재를 등록하세요.** |
| [취소] · ✕ | 클릭 | `PRJ-02` | 목록으로 복귀 |
| 코드 할당 필요 | — | `SOB-02` | 직접 코드 할당 |
| 고객사가 없을 때 | — | `MEM-02` | 고객사 등록 |
| 추가 후 다음 단계 | — | `PRJ-04` | 교재(책) 추가 |

### PRJ-05: S02 Owner 코드 선택

*화면 정의서 상태 `S2`*

**구분** — 기본

고객사를 고르면 그 고객사가 **발급받은 코드**가 버튼으로 열린다. **(코드 종류 · Section · Owner)** 가 같은 발급은 하나로 묶이고 **Section → Owner** 순으로 정렬된다. 목록 만드는 규칙은 PRD §4.5(가).

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| Owner 코드 버튼 | 클릭 | 선택 | 코드 종류 · S · O 를 함께 표시 |
| 개수 표기 | 표시 | — | 여러 개면 **{n}개 중 선택** |
| 정렬 | — | Section → Owner | 오름차순 |
| 선택 안내 | 표시 | — | **선택한 Owner 코드가 편집 관리 대상이 되어 코드 프로젝트·SOBP 맵에서 편집 플래그로 표시됩니다.** |
| 미선택 저장 | — | 확인창 | **Owner 코드를 선택하세요. (여러 개면 하나를 고르세요)** |
| [추가] | 클릭 | `PRJ-02` | 목록에 추가되고 **그 고객사가 바로 선택**된다 |
| [취소] · ✕ | 클릭 | `PRJ-02` | 목록으로 복귀 |
| 코드 할당 필요 | — | `SOB-02` | 직접 코드 할당 |
| 고객사가 없을 때 | — | `MEM-02` | 고객사 등록 |
| 추가 후 다음 단계 | — | `PRJ-04` | 교재(책) 추가 |

### PRJ-05: S03 Owner 1개 — 자동 선택

*화면 정의서 상태 `S3`*

**구분** — 분기

할당된 Owner 가 **하나뿐이면** 고객사를 고르는 즉시 그 코드가 선택된다. 바로 **[추가]** 를 누를 수 있다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| Owner 1개 | 자동 | 선택됨 | 개수 표기가 붙지 않는다 |
| [추가] | — | **활성** | 추가 조작 없이 바로 누를 수 있다 |
| 중복 추가 | — | 기존 항목으로 이동 | 같은 **고객사명 + Owner** 가 있으면 새 줄을 만들지 않는다 — PRD §4.5(나) |

### PRJ-05: S04 할당 코드 없음 — 직접 입력

*화면 정의서 상태 `S4`*

**구분** — 차단

그 고객사에 아직 할당된 코드가 없으면 경고가 나오고 **직접 입력** 칸이 열린다. 정상 절차는 `SOB-02` 에서 **코드를 먼저 할당**하는 것이고, 직접 입력은 **예외 경로**다(§7 미결).

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 경고 | 표시 | — | **{고객사} 는 아직 할당된 코드가 없습니다. Owner 코드를 직접 입력하거나, 먼저 SOBP 맵에서 코드를 할당하세요.** |
| Owner (직접 입력) | 입력 | 숫자 | **필수** |
| 코드 종류 | 선택 | PDS3(Ncode) / PDS2(Gcode) | 기본 PDS3 |
| 정상 절차 | — | `SOB-02` | 코드 할당 후 다시 시도 |
| [취소] · ✕ | 클릭 | `PRJ-02` | 목록으로 복귀 |
| 코드 할당 필요 | — | `SOB-02` | 직접 코드 할당 |
| 고객사가 없을 때 | — | `MEM-02` | 고객사 등록 |
| 추가 후 다음 단계 | — | `PRJ-04` | 교재(책) 추가 |
