## 2. 화면 구성

### 개요

발급된 티켓(N Key · App Key)의 **전체 이력을 조회하고, 발급 건별로 상세·정산 화면에 들어가는 진입점**이다. 목록에는 두 종류가 함께 쌓이며 종류 필터로 구분한다. **정산 등록과 Key 정보 확인은 이 화면의 모달이 아니라 발급 상세(TKT-02)의 탭**이다. 요약 합계는 **필터 결과 전체** 기준이라 페이지를 넘겨도 변하지 않는다. 계산 규칙은 PRD §4.7.

### 상태 구성

이 화면은 **8개 상태**로 나뉜다. 구분: 기본 · 분기 · 필터 · 빈 상태 · 차단

| 상태 | Figma 프레임 | 제목 | 구분 |
|---|---|---|---|
| `S1` | `TKT-03:S01` | 기본 목록 · 최근순 | 기본 |
| `S2` | `TKT-03:S02` | 체험 만료 경고 · 대장 이력 | 분기 |
| `S3` | `TKT-03:S03` | 필터 — 종류 · 정산 · 출처 | 필터 |
| `S4` | `TKT-03:S04` | 정렬 — 머리글 클릭 | 분기 |
| `S5` | `TKT-03:S05` | 필터 결과 없음 | 빈 상태 |

### TKT-03: S03 필터 — 종류 · 정산 · 출처

*화면 정의서 상태 `S3`*

**구분** — 필터

필터는 한 줄에 이어지고 구분선(**·**)으로 묶음이 나뉜다. ⚠ **정산 필터에는 「체험」이 없다** — 정산 전체 · 미정 · 유료 · 무료 4개뿐이다. 고객사 목록에는 **발급 이력이 있는 고객사만** 나온다. 필터가 바뀌면 **1페이지로 되돌아간다**.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 고객사 | 선택 | 해당 고객사만 | 기본 **고객사 전체** |
| 종류 | 클릭 | 전체 / N Key / App Key | — |
| 정산 | 클릭 | 정산 전체 / 미정 / 유료 / 무료 | **체험은 필터로 고를 수 없다** |
| 출처 | 클릭 | 전체 / 대장 / 신규발급 | — |
| 검색 | 입력 | 발급 내용 + 발급인 | **고객사·내용 검색** |
| 요약 | 자동 | 재계산 | 필터 결과 기준으로 5칸이 모두 다시 계산된다 |
| 페이지 | 자동 | 1페이지 | 필터·검색·정렬이 바뀌면 되돌아간다 |
| 사이드바 [계정 발급 (App Key 발급)] | 클릭 | `TKT-01` | App Key 발급 |
| 사이드바 [코드 프로젝트] | 클릭 | `PRJ-01` | 발급 원장 |
| 고객사 계약·단가 | 확인 | `MEM-01` | 업체 상세 |
