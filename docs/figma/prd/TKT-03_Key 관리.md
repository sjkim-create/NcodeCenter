## 2. 화면 구성

### 개요

발급된 티켓(N Key · App Key)의 **전체 이력을 조회하고, 발급 건별로 상세·정산 화면에 들어가는 진입점**이다. 목록에는 두 종류가 함께 쌓이며 종류 필터로 구분한다. **정산 등록과 Key 정보 확인은 이 화면의 모달이 아니라 발급 상세(TKT-02)의 탭**이다. 요약 합계는 **필터 결과 전체** 기준이라 페이지를 넘겨도 변하지 않는다. 계산 규칙은 PRD §4.7.

### 기능 개요

발급된 티켓(N Key · App Key)의 **전체 이력을 조회하고, 발급 건별로 상세·정산 화면에 들어가는 진입점**이다. 재무·사업부가 "누구에게 무엇을 얼마에 발급했는지"를 확인한다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 **[티켓 발급] ▸ [Key 관리]** |
| 목록 대상 | **N Key 와 App Key 를 함께** 쌓는다. N Key 는 이 메뉴에서, App Key 는 계정 등록·수정 화면에서 발급된다 |
| 데이터 출처 | **대장**(과거 발급 이력) + **신규발급**(이 시스템에서 발급한 티켓) |
| 성격 | **목록 화면** — 값 수정은 발급 상세에서 한다 |

### 화면 흐름 (Flow)

```
좌측 메뉴 [티켓 발급] ▸ [Key 관리]
   └─▶ TKT-03 목록
         ├─ [＋ N Key 발급] ──────────▶ TKT-04 N Key 생성
         ├─ [N Key 불러오기] ─────────▶ 파일 확인 창 ─ 닫기 ─▶ TKT-03
         ├─ 레코드(행) 클릭 ──────────▶ TKT-05 발급 상세 (발급 기본정보 탭) `PC-050`
         ├─ 행 [정산] ────────────────▶ TKT-02 발급 상세 (정산 정보 탭)
         ├─ 행 [상세] ────────────────▶ TKT-02 발급 상세
         └─ 행 [삭제] ─ 확인 ─────────▶ 목록에서 제거
```

정산 등록과 Key 정보 확인은 **더 이상 이 화면의 모달이 아니다.** 둘 다 발급 상세(`TKT-02`)의 탭으로 들어갔다.

### 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-15` 티켓 = N Key / App Key + 정산 | 종류와 **정산 구분(유료·무료·체험·미정)** 을 함께 조회한다 |
| `PC-016` 출처 구분 | **대장** 과 **신규발급**을 배지·필터로 구분한다 |
| 요구사항 #1 | 체험 티켓은 **만료일과 잔여일**을 표시하고, 만료 건은 경고로 드러낸다 |
| `P-16` 정산 | 편집 정산(`PRJ-03`)과 별개다. **코드 라이선스 과금**을 여기서 관리한다 |
| 발급 번호 | 삭제해도 **다시 쓰지 않는다** |

### 사용법

#### 4.1 상단 요약

| 지표 | 의미 |
|---|---|
| 발급 티켓 | 현재 필터 기준 건수 |
| 유료 합계 | 유료 티켓 금액 합계 |
| 유료 건수 | 유료로 등록된 건수 |
| 무료 / 체험 | 각 건수 |
| 정산 미등록 | 아직 과금 유형을 정하지 않은 건수 — 0이 아니면 강조한다 |

요약은 **필터를 반영한 결과 전체 기준**으로 다시 계산한다. **페이지를 넘겨도 합계는 변하지 않는다** — 페이지에 따라 합계가 달라지면 정산 화면으로서 오해를 부르기 때문이다.

체험 만료 건이 있으면 목록 위에 경고가 표시된다 — **⚠ 체험 기간이 만료된 티켓 {n}건 — 유료 전환 또는 회수 여부를 확인하세요.**

#### 4.7 계산 규칙

**(가) 요약 — 필터 결과 전체 기준**

```
유료 합계   = 필터 결과 중 정산이 '유료' 인 티켓의 금액 합
정산 미등록 = 필터 결과 중 정산이 '미정' 인 티켓 건수

예) 필터 결과 6건
    유료 3건 = 3,500,000 + 4,800,000 + 0 → 유료 합계 8,300,000
    미정 2건 → 정산 미등록 2건
    페이지당 50건으로 1페이지만 보고 있어도 위 값은 6건 전체 기준이다
```

**(나) 체험 잔여일**

```
잔여일 = 체험 만료일 − 오늘
0 이상이면 D-{잔여일}, 음수이면 (만료)

예) 오늘 2026-08-29
    만료일 2026-09-25 → 27일 남음 → D-27
    만료일 2026-07-31 → 29일 지남 → (만료) · 상단 경고 배너에 포함
```

**(다) 페이지 표시 범위**

```
전체 페이지 수 = 올림(전체 건수 ÷ 페이지당 건수)
시작 = (현재 페이지 − 1) × 페이지당 건수 + 1
끝   = 최소(현재 페이지 × 페이지당 건수, 전체 건수)

예) 전체 142건 · 페이지당 50건 · 3페이지
    전체 페이지 = 올림(142 ÷ 50) = 3
    시작 = (3 − 1) × 50 + 1 = 101
    끝   = 최소(150, 142) = 142
    표기 : 전체 142건 중 101~142 표시 · 3 / 3
```

### TKT-03: S03 필터 — 종류 · 정산 · 출처

*화면 정의서 상태 `S3`*

**구분** — 필터

필터는 한 줄에 이어지고 구분선(**·**)으로 묶음이 나뉜다. ⚠ **정산 필터에는 「체험」이 없다** — 정산 전체 · 미정 · 유료 · 무료 4개뿐이다. 고객사 목록에는 **발급 이력이 있는 고객사만** 나온다. 필터가 바뀌면 **1페이지로 되돌아간다**.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 고객사 | 선택 | 해당 고객사만 | 기본 **고객사 전체** |
| 종류 | 클릭 | 전체 / N Key / App Key | — |
| 정산 | 클릭 | 정산 전체 / 미정 / 유료 / 무료 | **체험은 필터로 고를 수 없다** |
