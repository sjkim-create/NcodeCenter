## 2. 화면 구성

### 개요

**고객사별로 어떤 코드(SOBP)를 얼마나 발급받았는지**를 조회·검색하는 화면. 코드 발급 자체는 `SOB-02`에서 이뤄지므로 **이 화면에는 프로젝트 등록 기능이 없다**(조회·검색 전용 / 수정·삭제만 가능). 실제 구현은 **고객사 선택 → 프로젝트 → 발급 구성** 3단이며, 좌측에 **코드 종류(PDS2/PDS3) · 유형(편집/코드발급) · 사용 서비스** 3중 필터가 있다. (2026-08-27 확인).

### 기능 개요

**고객사별로 어떤 코드(SOBP)를 얼마나 발급받았는지**를 조회·검색하는 화면. 코드 발급 자체는 `SOB-02`에서 이뤄지므로 **이 화면에는 프로젝트 등록 기능이 없다**(조회·검색 전용). 발급된 코드의 사용 서비스·공유 여부·편집 연결을 확인하는 용도다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 [코드 ▸ 코드 프로젝트] |
| 성격 | **조회·검색 전용** (등록 없음 / 수정·삭제만 가능) |
| 범위 | **전 서비스 공통** — 사용 서비스 필터로 casterN·폼솔루션·서비스없음 코드를 모두 조회한다. 그래서 특정 서비스 그룹이 아닌 [코드] 그룹에 둔다 |
| 구성 | 좌: 고객사 목록 · 우: 선택 프로젝트 상세 |

### 화면 흐름 (Flow)

```
[코드 ▸ 코드 프로젝트]
   └─▶ PRJ-01
         ├─ 고객사 검색 · 사용 서비스 필터 ─▶ 좌측 목록 축소
         ├─ 고객사 선택 ─▶ 우측 프로젝트 상세
         │     ├─ [✏️ 편집 →] ────────────▶ PRJ-02 (해당 owner의 편집 프로젝트)
         │     ├─ [수정] ─▶ 프로젝트 수정(모달) ─ 저장 ─▶ PRJ-01 갱신
         │     └─ [삭제] ─▶ 삭제 확인(모달) ─ 확정 ─▶ 코드 reset · 목록 갱신
         └─ 코드 신규 발급이 필요하면 ──────▶ SOB-01 → SOB-02
```

### 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-13` 사용 서비스 지정 위치 | **여기서는 지정하지 않는다.** 사용 서비스는 `SOB-02`에서 지정하며, 이 화면은 그 결과를 조회·필터한다 (`PC-011`) |
| `PC-011` 등록 제거 | 프로젝트 **신규 등록 기능 없음**. 코드는 `SOB-02`로만 발급된다 |
| `P-14` 편집 = casterN | 사용 서비스가 casterN이거나 편집 실적이 있는 프로젝트에는 **편집 배지**가 붙고 `PRJ-02`로 이동할 수 있다 |
| `P-12` 공통(커먼) 코드 | 공유 코드 프로젝트에는 **공유 코드** 표시와 **사용 고객사(하위) 목록**이 함께 나온다 |
| `P-11` 고객사 계층 | 하위 고객사는 별도 화면이 아니라 이 상세의 사용 고객사 목록에서 확인한다 |
| `P-09` 등급 | 폼솔루션 프로젝트에만 등급이 표시된다 |

### 사용법

화면은 **3단**이다 — 좌 **고객사** / 가운데 **프로젝트** / 우 **발급 구성**.

#### 4.1 상단 요약 (S1)

`고객사 {n} · 프로젝트 {n} · 발급 코드 {n} · 실등록 {n}` 이 **현재 필터 기준**으로 표시되고, 끝에 범위 안내가 붙는다 — 필터가 걸리면 **· 필터 적용 (전체 {n}곳 / {n}건)**, 아니면 **· 할당된 코드를 업체·서비스별로 조회 (발급은 [Ncode 예약·할당])**. 우측에 **[초기화]**.

#### 4.2 좌측 — 고객사 (S1 · S3 · S7)

필터가 **3중**으로 걸린다. 어느 하나를 바꾸면 **선택한 프로젝트가 해제**된다.

| 요소 | 값 | 화면 |
|---|---|---|
| 코드 종류 | `전체` / `PDS3` / `PDS2` / `PDS4(S-code)` / `OID` — 좌표(SOBP)의 속성 기준 `PC-032`. 옛 **IDS(A) = OID 동일** `PC-035` | S3 |
| 구분 | `전체` / `편집` / `코드발급` | S3 |
| 사용 서비스 | 드롭다운 · 기본 **사용 서비스 · 전체** | S1 |
| 고객사 검색 | 업체명으로 검색. `×` 로 해제 | S7 |

**필터를 걸면 그 조건에 맞는 프로젝트가 있는 고객사만** 목록에 남는다. 정렬은 **업체명 가나다순**.

| 카드 표시 | 내용 |
|---|---|
| 1줄 | 업체명 + 사업 종료 시 **종료** 배지(툴팁에 사유·이관 메모) |
| 2줄 | 사용 서비스 요약(없으면 **서비스 없음**) · `코드 {n}` · 보유 **코드 종류 배지**(N/G) |

목록이 비면 **결과 없음**. (S7)

#### 4.3 가운데 — 프로젝트 (S1 · S2)

제목은 `프로젝트 · {고객사} ({n})`.

| 카드 표시 | 내용 |
|---|---|
| 1줄 | 프로젝트명 |
| 2줄 | **코드 종류 + S · O 칩** (최대 4개, 넘으면 `+{n}`). 발급이 없으면 **미발급** |
| 3줄 | 사용 서비스 태그 · **편집** 태그 · **공유** 태그 |
| 4줄 | `발급 {n}코드 · {n}블록` |

프로젝트가 없으면 **이 고객사의 프로젝트가 없습니다.**

#### 4.4 우측 — 발급 구성 (S2)

프로젝트를 고르기 전에는 안내만 나온다 — *{고객사} — 가운데에서 프로젝트를 선택하면 **어떤 코드가 어떻게 발급되었는지**(SOBP 블록·발급일·코드 수) 확인할 수 있습니다.* (S1)

| 표시 | 내용 |
|---|---|
| 머리 | 프로젝트명 · 고객사 태그 · **코드 종류 + S/O 칩** · 사용 서비스 · **공유 코드** · 등급(폼솔루션만) · **✏️ 편집** · [수정] · [삭제] |
| ✏️ 편집 | 편집 실적이 있으면 심볼 수와 함께 표시. 클릭 시 `PRJ-02` 로 이동. 실적이 다른 owner에 귀속된 예외는 **✏️ 편집 → {귀속 대상}** |
| 발급 요약 4종 | **발급 코드(B×P)** · **실등록 페이지** · **편집 심볼** · **코드 종류** |
| 발급 SOBP 내역 | 순번 · **S/O/B/P 칩** · 발급일 · `{n}권 × {n}p = {n}` · 실등록이 있으면 **실등록 {n}p**. **조회 전용** |
| 발급 내역 없음 | **발급 내역이 없습니다. (미발급)** |

> 사용 서비스가 **서비스 없음**이면 태그가 비활성 형태로 표시된다 — 모니터링 대상이 아니라는 뜻이다.

#### 4.5 사용 고객사(하위) — 공유 코드일 때 (S4)

공통(커먼) 코드 프로젝트에는 **사용 고객사 목록**이 표시된다 — *공통(커먼)코드를 함께 쓰는 고객사 · 편집/티켓은 이 대장으로 진행.*

| 요소 | 동작 |
|---|---|
| 하위 고객사 검색 | 이름으로 거른다. 우측에 `표시 수 / 전체 수` |
| 고객사 칩 클릭 | 그 고객사가 **실제로 쓰는 SOBP(Book 단위)와 페이지 합계**를 표시. 다시 누르면 해제 |
| **신규** 배지 | 시드 데이터가 아니라 사용자가 등록한 사용 고객사 |
| 사용 고객사 없음 | **등록된 사용 고객사가 없습니다.** |

#### 4.6 프로젝트 수정 (모달) (S5)

우측 상세의 **[수정]** 으로 연다.

| 항목 | 필수 | 규칙 |
|---|---|---|
| 프로젝트명 | ✔ | |
| 고객사(업체) | ✔ | 등록된 고객사 중 선택 |
| 사용 서비스 | — | 표시·변경 가능하나 **정본 지정은 `SOB-02`** |
| 등급(폼솔루션) | — | 사용 서비스가 폼솔루션일 때만 표시 |
| 발급 SOBP 내역 | — | **조회 전용** — 발급 추가·수정은 이 화면에서 하지 않는다 |

#### 4.7 프로젝트 삭제 (S6)

[삭제] → 확인 모달. **삭제하면 그 프로젝트가 보유한 발급 코드가 reset(회수)** 되므로, **프로젝트명을 정확히 입력해야** [삭제 확정] 버튼이 활성화된다.

## 3. 상태별 변화

### PRJ-01: S01 기본 · 고객사 선택 (프로젝트 미선택)

*화면 정의서 상태 `S1`*

**구분** — 기본

### PRJ-01: S02 프로젝트 선택 · 발급 구성

*화면 정의서 상태 `S2`*

**구분** — 기본

프로젝트를 고르면 ③에 **발급 요약 4종 + 발급 SOBP 내역**이 표시된다. 발급 내역은 **조회 전용** — 발급/수정은 `SOB-02`(Ncode 예약·할당)에서 한다 `PC-011`.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 발급 요약 4종 | 조회 | — | 발급 코드(B×P) · 실등록 페이지 · 편집 심볼 · 코드 종류 |
| 발급 SOBP 내역 | 조회 | — | 블록마다 **N(PDS3) S O B P** 칩 + 발급일 + **{권}권 × {p}p = {코드}** + 실등록 |
| [수정] | 클릭 | S5 프로젝트 수정 모달 | — |
