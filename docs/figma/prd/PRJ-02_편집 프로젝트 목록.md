## 2. 화면 구성

### 개요

편집(casterN) 대상 고객사를 왼쪽에서 고르고 **같은 화면 오른쪽**에서 그 고객사의 편집 내역·정산(`PRJ-03`)을 본다. **사용 서비스 = casterN** 으로 할당된 코드가 이 화면의 관리 대상이다 `P-14`.

상단 한 줄 요약과 카드 수치는 모두 **지금 목록 기준**으로 다시 계산된다. S7~S10 은 `PRJ-05` 편집 고객사 추가 모달이다.

### 기능 개요

**편집(casterN) 대상 고객사 목록** 화면. 좌측에서 고객사를 고르면 우측에 그 고객사의 **편집 프로젝트 상세(`PRJ-03`)** 가 함께 표시된다. 편집량(페이지·심볼)과 정산(청구액)을 고객사 단위로 확인하는 진입점이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 [서비스 관리 ▸ CasterN 서비스 관리 ▸ 편집 프로젝트] · `PRJ-01`의 **[✏️ 편집 →]** |
| 구성 | 좌: 고객사 목록(줄 목록 · 상위 ▶ 하위) · 우: `PRJ-03` 상세 `PC-294` |
| 대상 | **편집현황 장부에 있는 업체만** 표시된다 |

### 화면 흐름 (Flow)

```
[서비스 관리 ▸ CasterN ▸ 편집 프로젝트]  또는  PRJ-01 [✏️ 편집 →]
   └─▶ PRJ-02
         ├─ 코드 종류 필터 · 고객사/owner 검색
         ├─ 좌측 고객사 선택 ─▶ 우측 PRJ-03 편집 프로젝트 상세
         │                        └─ 교재 행 클릭/추가 ─▶ PRJ-04
         ├─ [＋ 고객사] ─▶ PRJ-05 편집 고객사 추가(모달)
         │                   └─ [추가] ─▶ 목록에 반영 + 그 고객사 선택
         └─ 사용자 추가 항목 [삭제] ─▶ 목록 · 교재 · SOBP 맵 편집 표시까지 제거 `PC-075`
```

### 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-14` 편집 = casterN | 이 메뉴가 **casterN 서비스 관리 화면**이다. 편집 실적이 있는 코드가 목록 대상 |
| `PC-187` 편집 대상 | 편집 대상 후보는 **고객사 관리에 등록된 고객사 전부**다. 서비스 계정의 casterN 체크(계정 권한)와 무관하다 — ~~옛 `P-13`: 사용 서비스 지정이 정본~~ |
| `P-11` 고객사 계층 | 추가할 수 있는 고객사는 **`MEM-01`에 등록된 고객사**뿐이다 |
| `P-16` 정산 단가 | 목록의 금액은 **고객사 단가 기준**으로 계산된다. 단가 지정은 `MEM-02` |
| `P-01` SOBP | 편집 프로젝트는 **Owner 단위**로 관리한다(1 고객사에 Owner 여러 개 가능) |

### 사용법

#### 4.0 첫 화면 — 전체 고객사 `PC-038` `PC-040`

들어오면 **특정 고객사를 미리 고르지 않고**, 오른쪽에 **모든 고객사의 교재를 합친 목록**이 나온다. 표·필터·페이지네이션은 **고객사 상세(`PRJ-03`)와 같은 것**을 쓴다.

| 항목 | 내용 |
|---|---|
| 표 구성 | 상세와 동일 + **고객사** 열이 앞에 추가된다 |
| 항목 필터(셀렉트) | **상태 · 고객사 · 사용 고객사 · 코드(PDS2·PDS3·PDS4·OID)** — 타입 · 편집방식 필터는 열과 함께 없앴다 `PC-282` |
| 페이지네이션 | **25 / 50 / 100 / 200 / 500 / 전체 보기** · `전체 {n}건 중 {a}~{b} 표시` |
| 편집 | **조회 전용** — 교재 추가·수정·초기화 버튼은 나오지 않는다 |
| 집계 | 상단 편집량·정산 카드는 **전체 기준**으로 계산된다 |

| 동작 | 결과 |
|---|---|
| 좌측 고객사 줄 클릭 | 그 고객사의 교재별 상세(`PRJ-03`)로 들어간다(수정 가능) |
| 상세의 **[← 전체 고객사]** | 전체 화면으로 복귀 |
| URL `?owner={n}` 진입 | 그 고객사 상세로 바로 연다 (`SOB-01` 의 [✏️ 편집으로 이동 →]) |

#### 4.1 상단 전체 요약 (S1)

목록 위에 한 줄로 **현재 목록 기준** 집계가 표시된다. 코드 종류 필터·검색을 걸면 **이 수치도 함께 줄어든다.**

| 항목 | 내용 |
|---|---|
| 편집 고객사 | 목록에 보이는 고객사 수 · 뒤에 **(상위 {n} · 하위 {n})** — 상위 = 공용 코드를 가진 고객사, 하위 = 그 공용 코드 교재의 소유 고객사 `PC-293` |
| 편집 북코드 | 교재(권) 수 |
| 총 심볼 | 편집 심볼 합계 |
| 리소스 | 편집 리소스 용량(GB) |
| 청구액 | **고객사 단가 기준** 합계. 할인이 있으면 뒤에 **(기준가 {n} · 할인 −{n})** 이 경고로 붙는다 |

끝에 범위 안내가 붙는다 — 필터가 걸리면 **· 필터 적용 (전체 {n}곳 / {n}권)**, 아니면 **· 편집현황 장부에 있는 업체만 표시**.

#### 4.2 좌측 — 고객사 목록

| 요소 | 동작 | 화면 |
|---|---|---|
| 헤더 | **고객사 선택** + 우측 **[＋ 고객사]** 버튼 | S1 |
| 코드 종류 필터 | **셀렉트 박스** `PC-310` — `전체 코드 종류` / `PDS2 (Gcode)` / `PDS3 (Ncode)` / `PDS4 (S-code)` / `OID`, 항목마다 **(고객사 수)**. 해당 종류를 보유한 고객사만 표시. 교재 행의 **(코드 종류값, Section)** 으로 판별한다 `PC-037`. 고객사 줄 배지도 같은 종류 라벨 | S2 |
| 검색 | **고객사 · owner 검색**. 입력하면 `×` 가 나타나고 눌러서 해제 · **하위 고객사 이름도 찾는다** — 걸리면 그 상위 고객사 카드가 남고 맞는 하위 고객사만 펼쳐진다 `PC-293` · 「common」 처럼 그룹 고객사 이름으로 치면 **그룹 고객사만** 남는다(슬롯 고객사는 따로 걸리지 않는다) `PC-344` | S3 · S13 |
| 표시 수 | `{n}곳 표시` (필터 적용 시 ` · PDS3(Ncode) 보유` 처럼 종류를 덧붙인다) | S2 |
| 정렬 | **고객사명 가나다순** | S1 |
| 줄 선택 | 우측에 `PRJ-03` 상세 표시 · 선택한 줄은 파란 바탕 | S1 |
| **상위 고객사** | 공용(커먼) 코드를 가진 고객사 — 줄 앞 **▶**(누르면 하위 고객사 펼침 · 접힘) · 이름 뒤 **하위 {n}** `PC-293` `PC-294` | — |
| **고객사 표기** `PC-362` | 왼쪽 줄 이름 = **「고객사-owner」**(이름이 이미 「-owner」 로 끝나면 그대로 — 예: *Common-21* · *(유한)언어테스트-4*) · 상세 위 「상위 ▸ 하위」의 상위 이름도 같다 | S1 |
| **확장 언어 슬롯 고객사** `PC-344` `PC-362` | 교재가 **모두** 다른 고객사 확장 언어 그룹의 확장 Owner 에 있는 옛 슬롯 고객사(「Common 추가 언어 슬롯-964 · 965」 · 「Cake-1003」 등)는 **왼쪽 목록에 나오지 않는다** — 그룹 고객사(Common-21 · Cake-1009)만 보인다(「하위 {n}」 에도 세지 않는다) · 그룹 고객사를 고르면 **오른쪽 상세 위 탭** **[{고객사-owner} 교재 · n권] [🌐 확장 O{n} · n권] …** — 확장 탭을 누르면 그 확장 슬롯에 따로 등록된 교재를 본다(편집 데이터 그대로) · 검색은 그룹 고객사 이름으로 찾고, 슬롯 고객사 이름 · owner 로 찾으면 그룹 고객사가 남는다 · 슬롯 고객사로 바로 들어오면 그룹 고객사 + 그 확장 탭으로 연다 | S12 |
| **하위 고객사 목록** | 펼치면 상위 줄 아래 **세로 안내선 안**에 하위 고객사마다 **이름 · ⚠ {n}(서비스 티켓이 없는 교재 수 · 있을 때만) · 권수 배지** · 가나다순. 툴팁 *{고객사} — 교재 {n}권 중 {n}권은 서비스 티켓이 없습니다* · 검색에 걸리거나 하위 고객사를 고르면 저절로 펼친다 `PC-293` `PC-294` | — |
| **하위 고객사 선택** | 우측에 **상위 고객사의 `PRJ-03` 상세**를 열고 **사용 고객사 필터를 그 하위 고객사로** 건다 · 위에 **← 전체 고객사 · {상위} ▸ {하위}** — {상위}를 누르면 거르기를 푼다 `PC-293` | — |
| 결과 없음 | **검색 결과가 없습니다.** | S4 |

**고객사 줄 구성** `PC-294` — 고객사 관리 · App Key 관리 왼쪽 목록과 같은 모양

| 줄 | 내용 |
|---|---|
| 1 | (상위 고객사만) **▶** · 고객사명 · **하위 {n}** · **신규** 배지(이 화면에서 추가한 항목) · 오른쪽 **교재 권수 배지**(툴팁 *교재 {n}권* — 필터가 걸리면 *PDS3 {n}권*) |
| 2 | **코드 종류 배지**(PDS2 · PDS3 · PDS4 · OID) · 추가 항목이면 오른쪽에 **삭제** |

- 옛 **심볼 막대**(목록 최대값 대비 길이)는 없앴다 — 무엇의 몇 %인지 알기 어렵고, 심볼이 0이어도 최소 길이로 그려졌다 `PC-294`.
- **심볼 수도 목록에 두지 않는다** — 고객사를 고르면 오른쪽 **편집량** 집계에, 하위 고객사를 고르면 **그 하위 고객사 교재만의** 심볼 수가 나온다 `PC-294`.

**하위 고객사 판단** `PC-293` — 상위 고객사 교재 중 **그 Book 에 서비스 티켓을 받은 고객사**(교재 소유 `PC-291`), 티켓이 없으면 **등록된 사용 고객사**(⚠ 로 센다 `PC-290`). 사용 고객사가 없거나 상위 자신이면 상위 소유라 하위로 세지 않는다. **OID 교재는 서비스 티켓 대상이 아니라 ⚠ 로 세지 않는다.** 코드 종류 필터를 걸면 그 종류 교재만으로 센다.

선택한 코드 종류 필터는 **우측 상세에도 그대로 적용**되고, 집계도 그 종류의 교재만으로 다시 계산된다.

사용자가 추가한 항목만 **[삭제]** 할 수 있다(장부 데이터는 삭제 불가). 삭제는 **[＋ 고객사] 로 등록한 것을 그대로 되돌린다** `PC-075` — 아래 네 가지가 **함께** 사라진다. (S11)

| # | 지우는 것 | 지우지 않으면 생기는 일 |
|---|---|---|
| ① | 좌측 **고객사 카드** | 목록에 그대로 남는다 |
| ② | 직접 추가한 **교재** | 다시 추가하면 옛 교재가 되살아난다 |
| ③ | **SOBP 맵 Book 오버라이드** — 그 고객사가 공유(커먼) 코드에 남긴 **사용 고객사·편집 표시** | 맵의 Book 카드에 지운 고객사명이 남는다 |
| ④ | **코드 프로젝트의 편집 플래그**(`editing`·`editingOwner`) | **SOBP 맵 OWNER 카드에 [편집] 배지가 남는다** |

- 같은 코드 프로젝트를 쓰는 **다른 편집 고객사가 남아 있으면** ④ 플래그는 **그대로 둔다**.
- **편집현황 장부(원장)에 편집 이력이 있는 좌표**는 지운 뒤에도 **[편집]** 으로 보인다 — 실제 편집량이므로 **잔재가 아니다**.

#### 4.3 PRJ-05 · 편집 고객사 추가 (모달)

편집 장부에 없는 고객사를 편집 대상으로 추가한다. **수정 기능은 없다**(추가 전용).

| 항목 | 필수 | 규칙 | 화면 |
|---|---|---|---|
| 고객사 (고객사 관리 등록 고객사) | ✔ | `MEM-01` 등록 고객사 중 선택(가나다 정렬 · 자리표시 *- 고객사 선택 ({n}곳) -* · 사업 종료는 「(사업 종료)」). 0곳이면 *등록된 고객사가 없습니다 — 고객사 관리에서 먼저 등록하세요.* | S7 |
| Owner 코드 | ✔ | 그 고객사가 보유한 Owner 를 **SOBP 칩**(코드 종류 + S + O)으로 보여주고 눌러서 고른다. 여러 개면 `· {n}개 중 선택` | S8 |
| 할당된 코드 없음 | — | **직접 입력은 없다** — 코드 할당은 SOBP 맵에서만 `PC-045` · 빨간 안내 + [SOBP 맵으로 이동 →] | S9 |
| 확장 언어 그룹 고객사 | — | 그룹의 **확장 코드만** 빼고 나온다 · 그룹 기본 코드에 [기본] 칩 `PC-349` `PC-357` (「기본 코드 미정」 안내는 없앴다 — 그룹은 기본 코드를 골라 만든다) | S6 |

> 선택한 Owner 코드가 **편집 관리** 대상이 되어 코드 프로젝트·SOBP 맵에서 **편집** 플래그로 표시된다.
> 추가 후 우측 상세에서 **＋교재(책) 추가**로 편집 교재를 등록한다.

**[추가]** 는 고객사와 Owner 를 모두 고르기 전에는 눌리지 않는다. 추가하면 좌측 목록에 반영되고, **같은 고객사·owner가 이미 있으면 새로 만들지 않고 그 항목으로 이동**한다.

할당된 코드가 없는 고객사를 고르면 빨간 안내가 뜬다 — **🚫 {고객사} 는 아직 할당된 코드가 없습니다.** · **코드 할당은 [SOBP 맵] 에서만 합니다. 먼저 SOBP 맵에서 이 고객사에 코드를 할당한 뒤 다시 추가하세요.** + **[SOBP 맵으로 이동 →]** · [추가] 꺼짐 (S9)
