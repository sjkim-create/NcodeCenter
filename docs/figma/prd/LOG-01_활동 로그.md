## 2. 화면 구성

### 개요

**내부 직원이 언제 무엇을 했는지**를 시간순으로 확인하는 감사(audit) 화면. **ADMIN 전용**이며 STAFF는 본문이 🔒 안내로 대체된다. **조회 전용**(기록은 각 화면에서 자동 생성) · 한국시간(KST) 기준 · **보관 한 달** `PC-252`. **주 · 월 달력**에 활동 종류별 색으로 그날 활동을 보이고, 날짜를 누르면 **오른쪽에 그날 상세**가 나온다 `PC-251` `PC-252`. 행은 **고정 열**이라 종류 배지 길이에 목록이 흔들리지 않는다 `PC-073`.

### 기능 개요

**내부 직원이 언제 무엇을 했는지**를 시간순으로 확인하는 감사(audit) 화면. 편집·사업·재무 여러 부서가 같은 데이터를 다루므로, 코드 할당·티켓 발급·고객사 변경 같은 주요 행위의 **변경 이력 추적**이 목적이다.

| 항목 | 내용 |
|---|---|
| 권한 | **ADMIN 전용** — 메뉴 자체가 ADMIN에게만 노출된다 |
| 진입 | 좌측 메뉴 [활동 로그] · `DSH-01`의 **[전체 로그]** |
| 성격 | 조회 전용(기록은 각 화면에서 자동 생성) |
| 기록 시각 | 한국시간(KST) 기준 |

### 화면 흐름 (Flow)

```
DSH-01 [전체 로그]  또는  좌측 메뉴 [활동 로그](ADMIN)
   └─▶ LOG-01
         ├─ 월 · 직원 · 활동 종류 필터
         ├─ 월 ▸ 일 그룹으로 목록 확인
         └─ [전체 삭제] ─ 확인 ─▶ 기록 초기화 (되돌릴 수 없음)

기록은 각 화면에서 자동 생성:
   MEM-02 → 고객사 관리 · SOB-02 → 코드 할당(등록) · PRJ-01 → 프로젝트 등록
   TKT-02/01 → 티켓 발급 · PRJ-04 → 교재 추가 / 교재 작업 · 로그인/로그아웃
```

| 정책 | 이 화면에서의 적용 |

## 3. 상태별 변화

*화면 정의서 상태 `S1`*

**구분** — 기본

**ADMIN 전용** — 좌측 메뉴 [활동 로그] 또는 `DSH-01`의 [전체 로그]로 진입. **주 달력**(일~토 7칸)에 그날 활동 건수와 **활동 종류별 색**(색 막대 = 그날 비율 · 색 점 = 종류별 건수)이 보이고, 날짜를 누르면 **오른쪽에 그날 활동**이 시간순으로 나온다 `PC-251`. 처음엔 **이번 주 · 오늘**. 기록은 **한 달** 보관 `PC-252` — [‹] [›]로 지난 주를 넘겨 본다. [월]을 누르면 달 단위(S6).

### LOG-01: S06 월 보기

*화면 정의서 상태 `S6`*

**구분** — 분기
