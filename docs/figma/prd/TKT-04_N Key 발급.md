## 2. 화면 구성

### 개요

**티켓 = 고객사가 이미 할당받은 SOBP 코드를 실제로 쓸 수 있게 하는 사용 허가**다. 발급 메뉴는 사이드바 **[티켓 발급]** 그룹(`TKT-04` N Key 발급 · `TKT-01` 계정 발급 · `TKT-03` 발급 목록 · 정산)이며, 이 화면은 그중 **N Key 발급**(`/tickets/nkey`)이다.

**N Key** = 물리 키 · 오프라인 편집툴(Caster lite) 용 · **계정 불필요**. 고객사 선택값은 `TKT-04` · `TKT-01` · `TKT-03` **3개 화면이 공유**한다.

S11~S13 은 이 화면에서 열리는 **`TKT-02` Key 정보 확인** 모달이다.

### 기능 개요

**티켓 = 고객사가 이미 할당받은 SOBP 코드를 실제로 쓸 수 있게 하는 사용 허가**다. 발급 메뉴는 사이드바 **[티켓 발급] 그룹**의 3개 화면(`TKT-04` · `TKT-01` · `TKT-03`)으로 나뉘며, 이 화면은 그중 **N Key 발급**이다 `PC-030`.

**N Key** = 물리 키. 오프라인 편집툴(Caster lite)에서 쓰며 **계정이 필요 없다.** 발급하면 티켓 파일이 zip으로 내려받아진다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 **[티켓 발급] ▸ [N Key 발급]** (`/tickets/nkey`) |
| 형제 화면 | `TKT-01` **계정 발급** · `TKT-04` **N Key 발급** · `TKT-03` **Key 관리** (사이드바 [티켓 발급] 그룹 순서) |
| 선행 조건 | 고객사가 **`MEM-01`에 등록**되어 있고, **`SOB-02`로 SOBP를 할당**받았어야 한다 |

> **고객사 선택값은 3개 화면이 공유한다.** N Key 발급에서 고객사를 고른 뒤 `TKT-01`으로 옮겨도 그대로 유지된다.

### 화면 흐름 (Flow)

```
좌측 메뉴 [티켓 발급] ▸ [N Key 발급]
   └─▶ TKT-04
          │
          ├─ 고객사 선택 ─▶ 할당된 SOBP 범위 선택 ─▶ 발급 조건 입력
          │        │
          │        └─(할당 범위 없음)─▶ SOB-02 직접 코드 할당으로 먼저 할당
          │        └─(미등록 고객사)──▶ MEM-02 고객사 등록
          │
          │
          └─ [Key 생성] ─▶ zip 다운로드 + 발급 이력 기록
                              └─▶ TKT-03 Key 관리 목록에서 확인
                              └─▶ LOG-01 활동 로그 자동 기록(티켓 발급)

사이드바 [티켓 발급] 그룹에서 전환: TKT-04 ⇄ TKT-01 ⇄ TKT-03 (고객사 선택 유지)
```

### 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-15` 티켓 = N Key / App Key | **N Key = 물리 키(오프라인·계정 불필요)**. 계정 연동이 필요하면 `TKT-01` |
| `P-01` SOBP | 티켓은 Section·Owner·Book·Page 범위로 발급된다 |
| `P-05` 무겹침 | 티켓은 **이미 할당된 범위 안에서만** 발급된다. Book이 할당 범위를 넘으면 발급이 막힌다 |
| `P-12` 공통(커먼) 코드 | 공통코드 보유 고객사는 **사용 고객사(하위 고객사)를 반드시 지정**해야 발급된다. 지정값은 티켓 정보와 파일명에 포함된다. **이력 전용 공통코드는 발급 대상에서 제외**한다 |
| `P-02` 코드 종류 = 좌표 속성 | PatternType은 **선택한 좌표(SOBP)의 종류로 자동 결정**된다 `PC-032` — PDS3 → `Ncode_PDS3` · PDS2 → `Ncode_PDS2` · PDS4(S-code) → `Scode` · OID → `OID`. 사용자가 직접 고르지 않는다 |
| 요구사항 #1 | 사용 기한(ValidUntilTime)으로 기간 제한, Book·Page 볼륨으로 수량 제한 |

### 사용법

#### 4.1 발급 메뉴 (사이드바 [티켓 발급] 그룹) `PC-030`

발급 메뉴는 화면 안이 아니라 **사이드바**에 있다. 세 화면은 각각 독립된 주소를 가진다.

| 메뉴 | 화면 | 주소 |
|---|---|---|
| 계정 발급 (App Key 발급) | `TKT-01` (하위 `TKT-02`) | `/tickets/account` |
| N Key 발급 | `TKT-04` | `/tickets/nkey` |
| Key 관리 | `TKT-03` | `/tickets/nkey` |

| 요소 | 동작 | 화면 |
|---|---|---|
| 사이드바 [티켓 발급] 그룹 | 세 화면으로 이동한다. 그룹 위치는 **코드 다음, 서비스 관리 앞** | S1 |
| 고객사 선택 상태 | 화면을 바꿔도 유지된다 | S1 |
| `/tickets` 직접 접근 | 첫 메뉴인 `/tickets/account` 로 이동한다 | S1 |

#### 4.2 N Key 발급 — 단계

| 단계 | 내용 | 화면 |
|---|---|---|
| 1 | **회사이름(고객사)** 을 선택한다. 고객사를 바꾸면 **아래 입력이 모두 초기화**된다 | S1 |
| 2 | **할당된 SOBP 범위**를 고른다. 목록은 접혀 있고 클릭하면 펼쳐진다 | S4 |
| 2′ | 공통코드 보유 고객사면 범위 목록 대신 **사용 고객사** 선택이 나온다. 고르면 그 고객사가 쓰는 코드로 **범위가 자동 지정**된다 | S5 |
| 3 | **Start Book / Book 볼륨 / Start Page / Page 볼륨**을 입력한다. 범위를 고르기 전에는 **입력이 잠겨 있다** | S3 |
| 4 | **ValidUntilTime(사용 기한)** — 기본은 **무제한**이며, 체크를 풀면 달력으로 날짜를 고른다 | S7 |
| 5 | 필요하면 **Separate each book**을 체크한다 | S6 |
| 7 | **[Key 생성]** — 검증을 통과하면 zip 파일이 다운로드되고 발급 이력이 기록된다 | S10 |

**범위를 고르면 자동으로 채워지는 값**

| 항목 | 채워지는 값 |
|---|---|
| Start Book | 범위의 시작 Book |
| Book 볼륨 | **범위 전체 권수** |
| Page 볼륨 | 그 Section의 페이지 상한 |
| Section · Owner · PatternType | 범위 값 그대로(수정 불가) |

#### 4.3 입력 항목 · 검증

| 항목 | 필수 | 입력 방식 | 규칙 |
|---|---|---|---|
| 회사이름(고객사) | ✔ | 선택 | `MEM-01`에 등록된 고객사만 |
| 사용 고객사 | 조건부 ✔ | 선택 | **공통코드 보유 고객사일 때만** 표시·필수 |
| 할당된 SOBP 범위 | ✔ | 선택 | 고객사가 할당받은 범위 목록. 없으면 발급 불가 |
| Start Book | ✔ | 숫자 | 선택 범위의 `시작 ~ 끝` 안 |
| Book 볼륨(권) | ✔ | 숫자 | `1 ~ (범위 끝 − Start Book + 1)` |
| Start Page | ✔ | 선택 | `0` / `1 (기본)` / `2` |
| Page 볼륨 | ✔ | 숫자 | **1 이상.** 라벨에 Section 상한이 안내되지만 **상한을 넘겨도 막지 않는다** — §7 |
| ValidUntilTime | — | 달력 | 기본값 **무제한**(`99999999`). 체크를 풀면 달력으로 날짜를 고른다 |
| IssuedTime | — | 자동 | 발급일 고정값 |
| PatternType | — | 자동 | 좌표 종류에 따라 `Ncode_PDS3` / `Ncode_PDS2` / `Scode`(PDS4) / `OID` — ※ PDS4·OID 의 정식 파라미터 표기는 **개발팀 확인 필요**(§7) |
| TicketVersion | — | 자동 | `1` |
| Separate each book | — | 체크 | 체크: **북코드별 개별 티켓** / 해제: **1개 티켓에 병합** |

#### 4.4 SOBP 범위 선택 (S4)

| 요소 | 동작 |
|---|---|
| 접힘 상태 | 선택된 범위를 **S · O · B · P 칩**으로 보여준다. 아직 안 골랐으면 `- 범위 선택 -` |
| 펼침 목록 | 범위마다 **순번 + S/O/B/P 칩**. 현재 선택한 항목은 강조되고 `✓` 표시 |
| 목록 밖 클릭 | 목록이 닫힌다 |

#### 4.5 발급 예정 요약 (S3 · S8)

범위를 고르면 버튼 아래에 발급될 내용이 한 줄로 표시된다.

> 발급 예정: **S{n}/O{n}/B{시작}~{끝}** · 병합 티켓 1장 · P{시작}~{끝}

Book 끝 번호가 할당 범위를 넘으면 같은 줄에 **· ⚠ 할당 범위(B{끝}) 초과** 가 경고로 붙는다 (S8). 이 상태에서 [Key 생성]을 누르면 §5.2의 검증에 걸린다.

#### 4.6 하단 액션

| 버튼 | 동작 |
|---|---|
| **[목록]** | `TKT-03` Key 관리 목록으로 이동한다. 입력값은 저장되지 않는다 |
| **[Key 생성]** | 검증을 통과하면 티켓 파일을 만든다. 범위를 고르기 전에는 비활성 |

> **Key 정보 확인 모달은 폐기됐다.** 발급된 티켓의 항목은 `TKT-03` 목록에서 건별 상세(`TKT-05`)로 보고, 내려받은 외부 키 파일은 `TKT-03` 의 **N Key 불러오기**(`TKT-06`)로 확인한다.

#### 4.7 Key 생성 결과 (S10)

| 항목 | 내용 |
|---|---|
| 다운로드 | 티켓이 **폴더 형태의 zip 1개**로 내려받아진다 |
| 파일명 | `Ticket_{고객사}[_{사용고객사}]_S{Section}O{Owner}_B{시작}[-{끝}].zip` |
| Separate each book 체크 | zip 안에 **Book 하나당 파일 1개**(각 1권) |
| 해제 | zip 안에 **병합 티켓 파일 1개** |
| 사용 안내(화면 고정 문구) | Key 생성 시 티켓이 zip 파일(폴더 형태)로 다운로드됩니다. 다운로드 폴더에서 zip의 압축을 풀어 그 폴더째 nproj 폴더 또는 내 PC > 문서 > NeoLAB > CodeTickets에 넣은 뒤 Caster lite에서 사용합니다. |
| 이력 | `TKT-03` Key 관리 목록에 1건 추가 · `LOG-01`에 **티켓 발급**으로 기록 |

## 3. 상태별 변화

### TKT-04: S01 진입 직후 — 고객사 미선택

*화면 정의서 상태 `S1`*

**구분** — 기본

| 할당된 SOBP 범위 | — | 안내만 | **고객사를 먼저 선택하세요.** |

### TKT-04: S02 할당된 SOBP 범위 없음

*화면 정의서 상태 `S2`*

**구분** — 차단

고객사는 골랐지만 `SOB-02` 로 할당받은 코드가 없는 경우. 먼저 코드를 할당해야 티켓을 발급할 수 있다 `P-05`.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 범위 자리 | 표시 | — | **이 고객사에 할당된 SOBP 범위가 없습니다.** |
| [Key 생성] | 강제 실행 | 인라인 메시지 | **이 고객사에 할당된 SOBP 범위가 없습니다.** |
| 해결 | 이동 | `SOB-02` | SOBP 맵에서 코드를 할당한 뒤 재시도 |
| 미등록 고객사 | 이동 | `MEM-02` | 고객사 등록 후 재시도 |
| 사이드바 [계정 발급] | 클릭 | `TKT-01` | **고객사 선택 유지** |
| 사이드바 [Key 관리] | 클릭 | `TKT-03` | 발급·정산 목록 |

### TKT-04: S03 범위 선택 완료 — 발급 준비

*화면 정의서 상태 `S3`*

**구분** — 기본

범위를 고르면 **Start Book · Book 볼륨 · Page 볼륨** 이 자동으로 채워지고 Code Type 이 확정된다 `P-02`(PDS3→Ncode_PDS3 · PDS2→Ncode_PDS2 · PDS4→Scode · OID→OID). 버튼 아래에 **발급 예정** 요약이 나온다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 할당된 SOBP 범위 | 클릭 | S4 (목록 펼침) | 접힌 상태에서는 선택된 범위만 칩으로 표시 |
| 자동 채움 | — | Start Book / Book 볼륨 / Page 볼륨 | Start Book = 범위 시작 · Book 볼륨 = **범위 전체 권수** · Page 볼륨 = Section 상한 |
