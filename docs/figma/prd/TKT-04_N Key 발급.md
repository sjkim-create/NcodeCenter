## 2. 화면 구성

### 개요

**티켓 = 고객사가 이미 할당받은 SOBP 코드를 실제로 쓸 수 있게 하는 사용 허가**다. 발급 메뉴는 사이드바 **[티켓 발급]** 그룹(`TKT-04` N Key 발급 · `TKT-01` 계정 발급 · `TKT-03` 발급 목록 · 정산)이며, 이 화면은 그중 **N Key 발급**(`/tickets/nkey`)이다.

**N Key** = 물리 키 · 오프라인 편집툴(Caster lite) 용 · **계정 불필요**. 고객사 선택값은 `TKT-04` · `TKT-01` · `TKT-03` **3개 화면이 공유**한다.

S11~S13 은 이 화면에서 열리는 **`TKT-02` Key 정보 확인** 모달이다.

### TKT-04: S03 범위 선택 완료 — 발급 준비

*화면 정의서 상태 `S3`*

**구분** — 기본

범위를 고르면 **Start Book · Book 볼륨 · Page 볼륨** 이 자동으로 채워지고 PatternType 이 확정된다 `P-02`(PDS3→Ncode_PDS3 · PDS2→Ncode_PDS2 · PDS4→Scode · OID→OID). 버튼 아래에 **발급 예정** 요약이 나온다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 할당된 SOBP 범위 | 클릭 | S4 (목록 펼침) | 접힌 상태에서는 선택된 범위만 칩으로 표시 |
| 자동 채움 | — | Start Book / Book 볼륨 / Page 볼륨 | Start Book = 범위 시작 · Book 볼륨 = **범위 전체 권수** · Page 볼륨 = Section 상한 |
| Start Book | 숫자 입력 | 요약 갱신 | 허용 **400~499** |
| Book 볼륨 (권) | 숫자 입력 | 요약 갱신 | **1 ~ 100** (범위 끝까지) |
| Start Page | 선택 | 요약 갱신 | **0 / 1(기본) / 2** |
| Page 볼륨 | 숫자 입력 | 요약 갱신 | 라벨에 **최대 4,096** 안내 — 다만 **초과해도 막지 않는다** (§7 미결) |
| [Key 생성] | 클릭 | S10 | 검증 통과 시 zip 다운로드 |
| 사이드바 [계정 발급] | 클릭 | `TKT-01` | **고객사 선택 유지** |
| 사이드바 [Key 관리] | 클릭 | `TKT-03` | 발급·정산 목록 |
