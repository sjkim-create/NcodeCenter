## 2. 화면 구성

### 개요

코드를 발급받는 **업체(고객사) 마스터**. 사업자·계좌·서류·편집 단가·업무 이력을 관리한다. **모든 코드 발급과 티켓 발급의 선행 조건**이며, 여기에 등록되지 않은 업체에는 코드를 할당할 수 없다. 계층은 `P-11`에 따라 **상위 / 하위 / 단독** 3분류이고 구분 필터로 거른다. **행을 클릭하면 `MEM-02` 수정 화면**으로 이동한다. 기준: `web/components/CompaniesView.tsx`

## 3. 상태별 변화

### MEM-01: S01 기본 · 전체 목록

*화면 정의서 상태 `S1`*

**구분** — 기본

좌측 메뉴 [고객사 관리]로 진입. 구현은 **안내문 + 검색 + [초기화] + [＋ 고객사 등록]** 툴바 아래에 **구분 필터 줄**이 따로 있고, 표는 **11열**(No · 업체명 · 담당자/연락처 · 사업자번호 · 은행/계좌 · 커먼 코드 · 편집 단가 · **주소** · 서류 · 업무 · 작업)이다. 표 하단에 **표시 건수 선택 + 페이지네이션**이 붙는다. 기준: `web/components/CompaniesView.tsx`

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 행 클릭 | 클릭 | `MEM-02` (수정 모드) | 툴팁 **클릭하면 수정 화면으로 이동합니다** · 종료 업체는 **프로젝트 종료 고객사 (코드 발급 이력만)** |
| 업체명 헤더 | 클릭 | 가나다 정렬 토글 | ↕ → ▲(오름) → ▼(내림) · 활성 시 화살표 파랑 |

| 구분 필터 칩 | 클릭 | 해당 계층만 | 전체 / 상위(초록) / 하위(보라) / 단독(회색) — 각 칩에 건수 |

| « ‹ 1.. › » | 클릭 | 페이지 이동 | 우측에 **{현재} / {전체}** |

| 편집 단가 열 | 조회 | — | **전용 {n}항목**(주황 굵게) / **기본**(회색) `P-16` |

### MEM-01: S02 구분 필터 · 하위 고객사

### MEM-01: S03 검색 결과 없음

*화면 정의서 상태 `S3`*

**구분** — 빈 상태

검색 결과가 없으면 표 본문이 **한 줄 안내**로 대체된다(`colSpan 11`). 하단 페이지네이션은 **표시되지 않는다**.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 빈 목록 | 표시 | — | **"{검색어}" 검색 결과가 없습니다.** |
| 등록 0건일 때 | 표시 | — | **등록된 고객사가 없습니다.** |
| × (검색 지우기) | 클릭 | 전체 목록 복귀 | — |
| 페이지네이션 | — | **숨김** | 결과가 있을 때만 표시 |

### MEM-01: S04 프로젝트 종료 업체

*화면 정의서 상태 `S4`*

**구분** — 변형

PRD §5 — 사업이 끝난 고객사는 **행 전체가 흐리게**(배경 #fafafa · 불투명도 0.6) 표시되고 **종료** 배지가 붙는다. 툴팁은 종료 사유(`closedNote`)를 보여준다. 코드 발급 이력은 보존된다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 종료 행 | 표시 | — | 흐리게 + **종료** 배지 |
| 종료 배지 | hover | 툴팁 | 종료 사유 · 없으면 **프로젝트 종료** |
| 행 클릭 | 클릭 | `MEM-02` | 툴팁 **프로젝트 종료 고객사 (코드 발급 이력만)** |
| [삭제] | 클릭 | S5 | 종료 ≠ 삭제 — 종료는 이력 보존, 삭제는 코드 reset |
