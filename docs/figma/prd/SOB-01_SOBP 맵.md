### SOB-01: S01 기본 — 코드 전체 · 상태 전체

*화면 정의서 상태 `S1`*

**구분** — 기본

**좌표(SOBP)가 먼저**다 `PC-032`. Section·Owner·Book·Page 로 코드를 짚고, 그 좌표가 **PDS3 · PDS2 · PDS4(S-code, Section 44) · OID** 중 무엇인지를 **종류 칩**으로 가른다. 좌표는 유일하므로 중복은 성립하지 않는다. **옛 IDS(A코드) 표기는 OID 와 같은 것**으로 함께 본다 `PC-035`.

상단은 **「코드」 필터(전체 · PDS2 · PDS3 · PDS4 · OID)** 와 **「상태」 필터** 두 묶음이고, 오른쪽에 고객사 검색이 붙는다 `PC-039`. 처음 연 상태 = 코드 **전체** · 상태 **전체** · 고객사 비움이며, 전체 보기의 Section 정원은 그 섹션을 쓰는 **종류들의 최대치**다.

### SOB-01: S19 OID 좌표 보기

*화면 정의서 상태 `S19`*

**구분** — 분기

`PC-035` — **OID** 는 index 만 갖는 코드(외부 코드를 우리 펜으로 판독)이고 **옛 IDS(A코드) 표기와 같은 것**이다. 종류 칩 **OID** 로 좌표를 걸러 본다. Section 은 데이터가 있는 **3 · 4** 만 나오고, OID 는 같은 S/O 를 다른 종류와 함께 쓸 수 있어(index 부여) **OID 로 잡은 Book 만** 발급으로 표시된다. 업체별 index 목록은 `INF-04` 관리대장(코드 관리 정보 탭)에서 본다.
