## 2. 화면 구성

### 개요

**이 콘솔을 쓰는 내부 직원**의 이름 · 부서 · 역할 · 사용 여부를 관리하는 화면 `PC-297`. **ADMIN 전용**. 직원은 회사 계정으로 처음 로그인하면 **자동 등록**(STAFF)되고, 직원 이름은 N Key 담당자(`PC-296`) · 활동 로그 직원으로 쓰인다. 삭제는 없고 그만둔 직원은 「사용 중지」(로그인 불가).

### 기능 개요

**이 콘솔(NcodeCenter)을 쓰는 내부 직원**을 보고 관리하는 화면이다. 직원 이름은 N Key 발급의 **담당자**(`PC-296`)와 활동 로그의 **직원**으로 쓰인다.

| 항목 | 내용 |
|---|---|
| 권한 | **ADMIN 전용** — 메뉴가 ADMIN 에게만 보이고, STAFF 가 주소로 들어와도 본문 대신 🔒 안내 |
| 진입 | 좌측 메뉴 **[멤버 관리] ▸ [직원 계정]** (`/staff`) |
| 등록 | **자동** — 회사 계정(@neolab.net)으로 처음 로그인하면 그 이메일 · 회사 프로필 이름으로 등록되고 역할은 **STAFF**. 이 화면에 [등록] 버튼은 없다 |
| 삭제 | **없음** — 그만둔 직원은 「사용 중지」(활동 로그 · 담당자 기록이 이름을 쓰므로 지우지 않는다) |
| 기록 | 이름 · 부서 · 역할 · 사용 여부를 바꾸면 활동 로그(접속)에 남는다 |

#### 역할 차이

| 역할 | 쓸 수 있는 메뉴 |
|---|---|
| **ADMIN** | 모든 메뉴 + **활동 로그**(`LOG-01`) · **직원 계정**(이 화면) |
| **STAFF** | 고객사 관리 · 코드 할당 · 편집 · App Key / N Key 발급 · 정산 등 **업무 메뉴 전부**. 활동 로그 · 직원 계정은 보이지 않는다 |

관리자(ADMIN)는 **한 명 이상** 있어야 한다.

### 화면 흐름 (Flow)

```
회사 계정으로 첫 로그인 ─▶ 직원 자동 등록(STAFF)
좌측 메뉴 [멤버 관리] ▸ [직원 계정] (ADMIN)
   └─▶ MEM-03  집계 4칸 · 상태 칩 · 검색 · 직원 표
          ├ 이름 칸 고침 ─▶ 벗어나거나 Enter 면 저장 · LOG-01
          ├ 부서 · 역할 고름 ─▶ 바로 저장 · LOG-01
          └ [사용 중] / [사용 중지] 누름 ─▶ 바로 바뀜 · LOG-01
STAFF 가 /staff 로 들어옴 ─▶ 🔒 접근 권한이 없습니다
```

### 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-10` · `PC-122` 콘솔 로그인 = 회사 계정 | 직원 = 회사 계정(@neolab.net)으로 로그인하는 내부 직원. 이메일 = 로그인 계정이라 고칠 수 없다 |
| `PC-297` 자동 등록 | 처음 로그인하면 자동 등록(STAFF). 손으로 등록 · 삭제하지 않는다 |
| `PC-297` 이름 유지 | 이 화면에서 고친 이름 · 부서 · 역할 · 사용 여부는 다시 로그인해도 바뀌지 않는다(이름은 비어 있을 때만 회사 프로필 값) |
| `PC-297` 사용 중지 | 사용 중지한 직원은 로그인할 수 없다 — 회사 계정으로 들어와도 콘솔에 들이지 않는다 |
| `PC-297` 관리자 1명 이상 | 마지막 ADMIN 은 STAFF 로 바꾸거나 사용 중지할 수 없다. 로그인한 내 계정은 사용 중지할 수 없다 |

### 사용법

#### 4.1 화면 구성

| 영역 | 내용 | 화면 |
|---|---|---|
| 집계 4칸 | 직원(전체) · ADMIN(사용 중) · STAFF(사용 중) · 사용 중지(0 이 아니면 빨강) | S1 |
| 머리 줄 | 「직원 계정」 · ⓘ(직원 계정이란 — 자동 등록 · 사용 중지 안내) · 상태 칩 **[전체 n] [사용 중] [사용 중지 n]** · 검색(이름 · 이메일 · 부서) | S1 · S2 |

| 역할 ⓘ | 역할 머리의 ⓘ — ADMIN · STAFF 차이(1장 「역할 차이」) | S1 |

| 항목 | 입력 | 규칙 | 화면 |
|---|---|---|---|

## 3. 상태별 변화

### MEM-03: S01 기본 — 직원 표

*화면 정의서 상태 `S1`*

**구분** — 기본

이 콘솔을 쓰는 내부 직원. 회사 계정(@neolab.net)으로 처음 로그인하면 **그 이메일로 자동 등록**(STAFF)되므로 [등록] 버튼은 없다 `PC-297`. **이름**은 표에서 바로 고치고(벗어나거나 Enter 면 저장), **부서 · 역할**은 고르면 바로 저장, **상태**는 눌러 사용 중 ↔ 사용 중지. 이메일은 로그인 계정이라 고칠 수 없다. 지우지 않는다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 이름 · 부서 · 역할 · 상태 머리 | 클릭 | 그 순서로 정렬 | ▲ / ▼ · 다시 누르면 반대 · 기본 이름순 · 역할은 ADMIN → STAFF. 값을 바꿔도 줄은 그 자리(머리를 누를 때만 다시 정렬) |
| 이름 | 고침 | 벗어나거나 Enter 면 저장 · Esc 되돌림 | **이름 변경 — {이름}** · `LOG-01` |
| 부서 | 선택 | 바로 저장 | 처음 등록 때는 「- 미지정 -」 |
| 역할 | 선택 | 바로 저장 | **역할 변경 — {이름} · {역할}** |
| 역할 ⓘ | 클릭 | 역할 차이 말풍선 | **ADMIN** = 모든 메뉴 + 활동 로그 · 직원 계정 / **STAFF** = 업무 메뉴 전부(활동 로그 · 직원 계정 없음) · ADMIN 1명 이상 |
| 상태 | 클릭 | 사용 중 ↔ 사용 중지 | 사용 중지 = 로그인할 수 없음 · **사용 중지 — {이름}** |
| 직원 계정 ⓘ | 클릭 | 말풍선 | 자동 등록 · 사용 중지 안내 |

### MEM-03: S02 사용 중지 직원 보기

*화면 정의서 상태 `S2`*

**구분** — 필터

[사용 중지 n] 칩을 누르면 사용 중지한 직원만 남는다(흐린 줄). 검색은 이름 · 이메일 · 부서를 찾는다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| [사용 중지 n] | 클릭 | 사용 중지만 | [전체] · [사용 중] 으로 되돌림 |
| 검색 | 입력 | 맞는 직원만 | 없으면 **조건에 맞는 직원이 없습니다.** |
| 상태 [사용 중지] | 클릭 | 다시 사용 | **다시 사용 — {이름}** |

### MEM-03: S03 막힌 변경

*화면 정의서 상태 `S3`*

**구분** — 오류

관리자(ADMIN)가 없어지거나 내 계정이 잠기는 변경은 막고, 값은 그대로 둔 채 아래에 빨간 안내를 보인다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 마지막 ADMIN 역할 · 상태 | 변경 | **막음** | **관리자(ADMIN)가 한 명은 있어야 합니다. 다른 직원을 먼저 ADMIN 으로 지정하세요.** |
| 내 계정 상태 | 클릭 | **막음** | **로그인한 내 계정은 사용 중지할 수 없습니다.** |
| 이름 비움 | 벗어남 | 원래 이름으로 | **이름은 비울 수 없습니다.** |

### MEM-03: S04 STAFF 접근 차단

*화면 정의서 상태 `S4`*

**구분** — 권한

메뉴는 ADMIN 에게만 보이고, STAFF 가 주소(/staff)로 들어와도 본문 대신 🔒 안내가 나온다(활동 로그와 같다).

| 본문 | 표시 | — | **접근 권한이 없습니다** / **직원 계정은 관리자(ADMIN) 계정만 관리할 수 있습니다.** |
| 좌측 메뉴 [직원 계정] | — | **노출 안 됨** | ADMIN 에게만 표시 |
