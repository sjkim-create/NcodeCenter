### 개요

### 기능 개요

내려받은 **키 파일(.json)** 을 열어 그 안에 무엇이 들어 있는지 확인하는 창이다.

|---|---|

**쓰는 상황**

- 고객사가 "이 키가 어느 범위인지" 물어볼 때 받은 파일을 열어 확인한다

### 화면 흐름 (Flow)

```
TKT-03 Key 관리
```

### 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| 조회 전용 | 파일을 읽기만 한다. 저장·수정·업로드하지 않는다 |
| 원장과 무관 | 발급 원장에 없는 파일도 연다. 원장과 대조하지 않는다 |
| 파일 형식 | `Key 생성`으로 내려받은 **JSON 티켓 파일**을 기준으로 한다 |

### 사용법

#### 4.1 파일 선택

도구 막대의 **[📂 N Key 불러오기]** 를 누르면 파일 선택 창이 열린다. `.json` 파일을 고르면 내용을 읽어 창에 표시한다.

**같은 파일을 연속으로 다시 고를 수 있다** — 파일을 고친 뒤 다시 확인하는 경우를 위해서다.

#### 4.2 항목 표시

| 요소 | 내용 |
|---|---|
| 파일명 | 어떤 파일을 보고 있는지 창 위에 고정으로 표시한다 |
| 항목 수 | **{n}개 항목 (불러온 파일)** |
| 표 | `Key` · `Value` 2열. 파일에 들어 있는 항목을 **그대로** 나열한다 |

항목 구성은 발급 당시 만들어진 그대로다 — `CompanyName` · `IssuedTime` · `ValidUntilTime` · `Section` · `Owner` · `BookStart` · `BookVolume` · `PageStart` · `PageVolume` · `PatternType` · `TicketType` · `SeparateEachBook` 등. **중첩된 값은 펼쳐서 한 줄씩** 보여준다.

#### 4.3 항목 검색

검색어로 표를 거른다. **항목명과 값을 함께** 찾는다.

```
예) 파일 항목 13개에서 "book" 으로 검색
    BookStart   400
    BookVolume  100
    SeparateEachBook  N (1개 티켓 병합)
    → 3개 항목 표시
```

#### 4.4 표 복사

**[표 복사]** 는 **현재 표시 중인 항목**을 복사한다. 검색으로 걸러 놓았으면 걸러진 것만 복사된다.

#### 4.5 닫기

**[닫기]** 또는 **✕** 로 창을 닫으면 `TKT-03` 목록으로 돌아간다. 목록의 필터·페이지 상태는 그대로 유지된다.
