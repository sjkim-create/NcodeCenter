## 2. 화면 구성

### 개요

고객사의 **기본 정보 · 공통코드 귀속 · 편집 단가 · 관련 서류**를 입력한다. **등록과 수정이 같은 화면**이며 진입 방법으로 모드가 갈린다 — `MEM-01`의 [＋ 고객사 등록] = 등록(1단), 행 클릭 = 수정(2단 · 업무 원장 `MEM-03` 포함). 단가는 **3단 구조**(기본 단가 → 고객사 단가 → 교재별 할인)이며, 변경은 **이후 등록되는 교재부터** 적용되고 기존 교재는 등록 당시 단가를 유지한다 `PC-027`.

| 항목별 단가 입력 | 입력 | 전용 단가로 전환 | 항목마다 단위(페이지·심볼·건) 표시 |
