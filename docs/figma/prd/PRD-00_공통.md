## 2. 화면 구성

### 개요

모든 화면이 공유하는 **로그인 · 권한 · 셸 · 공통 패턴 · 메시지 규칙**. 각 화면 정의서는 여기서 정의한 규칙을 반복하지 않고 참조한다. 역할은 **ADMIN / STAFF** 2종이며 `LOG-01`만 ADMIN 전용 메뉴다. 프레임 1장 = 1440×900 · Figma 프레임 1개.

### 상태 구성

이 화면은 **14개 상태**로 나뉜다. 구분: 진입 · 분기 · 오류 · 성공 · 기본 · 모달 · 변형 · 권한 · 전환 · 확인창 · 패턴

| 상태 | Figma 프레임 | 제목 | 구분 |
|---|---|---|---|
| `S1` | `PRD-00:S01` | 로그인 · 기본 | 진입 |

## 3. 상태별 변화

### PRD-00: S01 로그인 · 기본

*화면 정의서 상태 `S1`*

**구분** — 진입

미로그인 상태로 화면 경로에 접근하면 이 화면으로 이동한다. PRD §4.1 · §2. SSO 미설정 환경의 **개발용 로컬 로그인** 형태이며, SSO 설정 시 S2로 대체된다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| 이메일 입력 | 입력 · Enter | 제출 | 회사 도메인 계정 **name@neolab.net** 형식 |
| 비밀번호 입력 | 입력 · Enter | 제출 | 초기값 = 이메일. Enter로 제출 |
| 로그인 계정 기억 | 체크 토글 | — | 체크 시 다음 진입에 이메일 자동 채움 |
| [로그인] | 클릭 | `DSH-01` | 성공 시 **{이름}({역할})으로 로그인** 인라인 표시 후 이동 |
| (비로그인 경로 접근) | 자동 | 로그인 화면 | 로그인 후 요청 화면으로 이동 |

SSO 자격증명이 설정된 환경. PRD §4.1 — 회사 Google Workspace 계정으로만 로그인한다.

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |
|---|---|---|---|
| [회사 Google 계정으로 로그인] | 클릭 | Google 인증 → `DSH-01` | @neolab.net 계정만 허용. 명단에 없어도 **STAFF로 자동 등록**(승인 불필요) |
| (인증 취소) | 자동 | S1 유지 | 세션당 1회만 자동 로그인 시도 — 취소 루프 방지 |
