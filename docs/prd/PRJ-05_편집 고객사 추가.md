## 1. 기능 개요

이미 코드를 받은 고객사를 **편집 관리 대상으로 올리는** 창이다. 고객사를 새로 만드는 화면이 아니다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | `PRJ-02` 편집 프로젝트 목록의 **[＋ 고객사 추가]** |
| 성격 | **연결 화면** — 고객사와 Owner 코드를 골라 편집 대상으로 지정한다 |
| 선행 조건 | 고객사가 `MEM-01`에 등록되어 있을 것 |

**하는 일 2가지**

1. 고른 **Owner 코드를 편집 관리 대상으로 표시**한다 → `PRJ-01` 코드 프로젝트와 `SOB-01` SOBP 맵에서 **편집** 으로 나타난다
2. **편집 프로젝트 목록에 그 고객사를 올린다** → 이후 교재(책)를 등록할 수 있다

> 코드를 새로 할당하지 않는다. **이미 할당된 코드 중 어느 Owner를 편집할지** 고르는 것이다.

## 2. 화면 흐름 (Flow)

```
PRJ-02 편집 프로젝트 목록
   └─ [＋ 고객사 추가] ─▶ PRJ-05
          ① 등록된 고객사 선택
          ② Owner 코드 선택
             ├─(할당 코드 있음)──▶ 코드 칩 중 하나 선택
             └─(할당 코드 없음)──▶ 🚫 추가 차단 · [SOBP 맵] 안내 (직접 입력 없음) `PC-045`
          └─ [추가] ─▶ PRJ-02 목록에 추가되고 그 고객사가 선택된다
                       ├─▶ PRJ-01 · SOB-01 에 편집 표시
                       └─▶ 이어서 PRJ-04 로 교재를 등록한다
```

## 4. 사용법

### 4.1 ① 등록된 고객사 선택

`MEM-01`에 등록된 고객사가 **가나다순**으로 나온다. 고르면 그 고객사가 보유한 **Owner 코드 목록**이 아래에 열린다.

**할당된 Owner가 하나뿐이면 자동으로 선택된다.**

### 4.2 ② Owner 코드 선택 — 할당 코드가 있을 때

그 고객사가 발급받은 코드를 **Section·Owner 조합마다 하나씩** 버튼으로 보여준다. 하나를 고른다.

| 표기 | 내용 |
|---|---|
| 코드 종류 | **PDS3(N)** 또는 **PDS2(G)** |
| S | Section |
| O | Owner |

여러 개면 **{n}개 중 선택** 이라고 함께 표기한다. 목록은 **Section → Owner** 순으로 정렬된다.

> 고른 Owner 코드가 **편집 관리** 대상이 되어 코드 프로젝트·SOBP 맵에서 **편집** 으로 표시된다.

### 4.3 ② Owner 코드 — 할당 코드가 없을 때

그 고객사에 아직 할당된 코드가 없으면 **추가할 수 없다** `PC-045`. **코드 할당은 `SOB-02`(SOBP 맵)에서만** 하며, 이 화면에는 Owner·코드 종류를 직접 넣는 칸을 두지 않는다.

| 항목 | 필수 | 내용 |
|---|---|---|
| ~~Owner (직접 입력)~~ | — | **폐지** `PC-045` |
| 코드 종류 | — | **PDS3(Ncode)** / **PDS2(Gcode)** |

정상 절차는 **`SOB-02`에서 코드를 먼저 할당**하는 것이며, **다른 경로는 없다** `PC-045`.

### 4.4 [추가] 이후

| 결과 | 내용 |
|---|---|
| 편집 프로젝트 목록 | 그 고객사가 목록에 추가되고 **바로 선택된 상태**가 된다 |
| 이미 있는 고객사 | 같은 **고객사명 + Owner** 조합이 이미 있으면 새로 만들지 않고 **그 항목으로 이동**한다 |
| 코드 프로젝트 · SOBP 맵 | 그 Owner 코드에 **편집** 표시가 붙는다 |
| 다음 단계 | 우측 상세에서 **[＋ 교재(책) 추가]** 로 교재를 등록한다 (`PRJ-04`) |

### 4.5 판정 규칙

**(가) Owner 코드 목록 만들기**

```
그 고객사의 코드 프로젝트에서 발급 내역을 모아
(코드 종류 · Section · Owner) 가 같은 것은 하나로 묶는다
정렬은 Section 오름차순 → Owner 오름차순

예) 발급 내역
    PDS3 S3/O212/B0~99
    PDS3 S3/O212/B100~199   → 위와 같은 조합 → 하나로 묶임
    PDS2 S3/O17/B400~499

    → 선택 버튼 2개 : [PDS2 S3 O17]  [PDS3 S3 O212]
```

**(나) 중복 추가 판정**

```
같은 고객사명 AND 같은 Owner 가 이미 목록에 있으면 → 새로 만들지 않고 그 항목 선택

예) 목록에 「웅진씽크빅 · owner 17」 이 있는 상태에서
    같은 고객사·owner 17 을 추가 → 새 줄이 생기지 않고 기존 항목으로 이동
    같은 고객사·owner 212 를 추가 → 새 줄 추가
```

> Owner 번호만으로 찾으면 **같은 owner를 쓰는 다른 고객사**가 잡히므로 고객사명까지 함께 본다.

## 5. 상태별 변화 · 메시지

### 5.1 상태

| 상태 | 화면 | 화면 번호 |
|---|---|---|
| 진입 — 고객사 미선택 | 고객사 선택만 있고 아래는 비어 있다. **[추가]** 비활성 | S1 |
| 할당 코드 선택 | 코드 버튼이 열린다. 하나를 고르면 **[추가]** 활성 | S2 |
| Owner 1개 — 자동 선택 | 고객사를 고르는 즉시 그 코드가 선택된다 | S3 |
| 할당 코드 없음 | 🚫 추가 차단 + SOBP 맵 안내 | S4 |

### 5.2 메시지

| 상황 | 노출 방식 | 문구 | 화면 |
|---|---|---|---|
| 할당 코드 없음 | 차단 | 🚫 **{고객사} 는 아직 할당된 코드가 없습니다.** 코드 할당은 **[SOBP 맵]** 에서만 합니다. 먼저 SOBP 맵에서 이 고객사에 코드를 할당한 뒤 다시 추가하세요. | S4 |
| 고객사 미선택 저장 | 확인창 | **고객사 관리에 등록된 고객사를 선택하세요.** | S1 |
| Owner 미선택 저장 | 확인창 | **Owner 코드를 선택하세요. (여러 개면 하나를 고르세요)** | S2 |
| 선택 안내 | 안내 | **선택한 Owner 코드가 편집 관리 대상이 되어 코드 프로젝트·SOBP 맵에서 편집 플래그로 표시됩니다.** | S2 |
| 다음 단계 안내 | 안내 | **추가 후 우측 상세에서 ＋교재(책) 추가로 편집 교재를 등록하세요.** | S1~S4 |

**[추가]** 는 고객사와 Owner가 모두 정해지기 전에는 **비활성**이다.
