## 1. 기능 개요

고객사에 **SOBP 코드를 할당(발급)** 하는 화면. NcodeCenter에서 **코드의 주인이 정해지는 유일한 지점**이며, 이 코드를 어떤 서비스가 쓸지(**사용 서비스**)도 여기서 지정한다.

두 가지 방식이 있다.

| 모드 | 사용 상황 |
|---|---|
| **자동 추천** | 판형·페이지 수·권수 조건만 알고 있고, 어느 Section·Owner에 넣을지 시스템이 정해주길 원할 때 |
| **직접 선택** | `SOB-01`에서 이미 고른 Section·Owner에 그대로 발급할 때 |

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | `SOB-01`의 **[＋ 직접 코드 할당]** |
| 할당 단위 | **S/O 단위** — Owner 전체를 그 고객사가 점유한다 |
| 선행 조건 | 대상 고객사가 **`MEM-01`에 등록**되어 있어야 한다 (이 화면에서 신규 고객사를 만들지 않는다) |

## 2. 화면 흐름 (Flow)

```
SOB-01 ─ [＋ 직접 코드 할당] ─▶ SOB-02
   │
   ├─(자동 추천)─ 고객사 선택 → 추천 조건 입력 → [추천 받기]
   │                                   │
   │                                   ├─ 추천 성공 ─▶ 발급 상세로 자동 이동([조건 다시 입력]으로 복귀 가능)
   │                                   └─ 추천 실패 ─▶ 사유 표시(조건 조정 또는 직접 선택)
   │
   ├─(직접 선택)─ 고객사 · 사용 서비스 선택 ─▶ 발급 상세
   │
   ├─ [취소] ─────────────▶ SOB-01 (변경 없음)
   └─ [할당] ─ 검증 통과 ─▶ SOB-01 (지도 갱신)
                              ├─▶ PRJ-01 에 코드발급 프로젝트 생성
                              └─▶ LOG-01 활동 로그 기록(코드 할당(등록))

미등록 고객사인 경우 ─▶ MEM-02 고객사 등록 후 재시도
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-05` 무겹침(최우선) | 이미 다른 고객사에 할당된 S/O에는 발급할 수 없다. 발급 상세 입력이 **잠금(🔒 전용 · 할당 불가)** 상태가 된다 |
| `P-07` SO 공유 불가 | Section·Owner는 고객사 식별 축. 예외는 **공유 OWNER로 지정한 경우**뿐이며, 그때는 Book 번호만 겹치지 않으면 된다 |
| `P-02` 코드 종류 N/G | **같은 S/O는 PDS3·PDS2 중 한쪽만** 사용할 수 있다. 반대쪽이 쓰는 Owner는 발급이 차단된다 |
| `P-13` 사용 서비스 지정 위치 | **사용 서비스는 이 화면에서만 지정한다**(`PC-011`). 코드 프로젝트에서는 지정하지 않는다 |
| `P-14` 편집 = casterN | 사용 서비스를 **casterN**으로 지정하면 그 코드는 편집 프로젝트(`PRJ-02`) 관리 대상이 된다 |
| `P-06` 연속성 | 자동 추천은 **연속된 권수 구간**을 찾아 배정한다. 구간을 잘게 쪼개 추천하지 않는다(파편화 방지) |
| `P-08` Owner 발급 이원화 | 추천은 **오너 단위**까지만 한다. 소규모 물량의 Book 흡수 여부는 담당자가 판단 |
| 테스트/개발 섹션 | PDS2 S0·S14는 **자동 추천에서 제외**. 직접 선택으로는 발급 가능 |
| `PC-026` 사용 서비스 3종 | 지정 가능한 서비스는 **casterN · 폼솔루션 · 서비스 없음** 뿐이다. 그 외 용도(Ncode 프린터 등)의 코드는 **서비스 없음(코드만 발급)** 으로 할당한다 |

## 4. 사용법

### 4.1 공통 — 고객사와 사용 서비스

| 항목 | 필수 | 규칙 |
|---|---|---|
| 고객사 | ✔ | 목록에서 선택하거나 직접 입력(검색). **`MEM-01`에 등록된 고객사만** 발급 가능 |
| 사용 서비스 | — | `casterN (편집툴)` / `폼솔루션` / `서비스 없음 (코드만 발급)` **3종**. 기본값 = 서비스 없음 |

사용 서비스별 안내

| 선택 | 안내 |
|---|---|
| 서비스 없음 | 코드만 발급 — 자체 서비스 미사용(사용량 모니터링 불가). |
| casterN | casterN 편집툴 — [편집 프로젝트]에서 관리·모니터링. |
| 폼솔루션 | 자체 서비스 — 코드 사용량이 모니터링됩니다. |

**선택 고객사의 기존 보유 코드**가 함께 표시된다. 코드를 클릭하면 그 S/O로 이동해 **이어서 추가 발급**할 수 있고, 시작 Book은 가장 빠른 빈 번호로 자동 설정된다. 보유 코드가 없으면 신규 오너로 발급된다.

### 4.2 자동 추천 모드

| 조건 | 규칙 |
|---|---|
| 코드 종류 자동 여부 | 자동이면 PDS2·PDS3 전체를 탐색해 적합한 타입을 추천. 해제하면 현재 선택된 종류 안에서만 추천 |
| 용도 | `소리펜` / `필기펜` |
| 발급 유형 | `코드만 발급` / `편집` |
| 판형 | 표준 목록에서 선택하거나 **직접 입력(mm)**. 값은 **가장 긴 변** 기준이며 코드 종류별 최대치를 넘을 수 없다 |
| 권당 페이지 | 1 이상 |
| 권수 | 1 이상 |

**[추천 받기]** — 고객사를 선택해야 활성화된다.

추천 규칙

- **신규 고객** → 판형·페이지 수를 수용하는 Section을 고르고 **새 Owner를 발급**한다.
- **기존 고객** → **기존 Section·Owner를 유지**하고 잔여 구간에서 배정한다.
- 추천 범위는 **Owner 단위**까지. Owner 안에서 Book을 잘게 쪼개지 않는다.
- 결과에는 판단 근거와 **대안 Section**(최대 판형·페이지)이 함께 표시된다.

추천이 성공하면 값이 즉시 발급 상세에 반영되고, **[조건 다시 입력]** 으로 조건 화면으로 되돌아갈 수 있다.

### 4.3 발급 상세 (직접 선택 또는 추천 적용 후)

발급 대상이 **코드 종류 · S · O · owner 전체**로 표시된다.

> 이 **S{n}/O{n}** 전체를 **{고객사}** 에 발급(점유)합니다. owner 아래 **모든 Book이 '사용가능'** 이 되고, 실제 발급 규모(코드 수)는 **편집 시 집계**됩니다.

**공유 OWNER** 로 지정하면 여러 고객사가 함께 쓸 수 있고, 이때는 **Book 번호만 배타**로 관리된다.

### 4.4 저장

**[할당]** — 검증을 통과하면 지도(`SOB-01`)로 돌아가고, 해당 고객사의 **코드발급 프로젝트**가 `PRJ-01`에 생성된다.

## 5. 상태별 변화 · 메시지

### 5.1 상태

| 상태 | 화면 |
|---|---|
| 전용 코드(다른 고객사 보유) | 발급 대상에 **🔒 전용 · 할당 불가** 표시, 입력 잠금. 안내 **⚠ 이미 {고객사} 전용입니다.** 공유 OWNER로 체크하면 해제 |
| 반대 코드 종류가 선점 | **🚫 {PDS3\|PDS2} 에서 이 owner를 사용 중 — 한쪽 PDS만 사용 가능** |
| 공유 OWNER | **✅ 공유 OWNER · S{n}/O{n} — 여러 고객사 사용 가능 (Book 번호만 배타)** + 현재 사용 고객사 목록 |
| 보유 코드 없음 | **보유한 코드가 없습니다 — 신규 오너로 추천됩니다.**(자동) / **새 S/O로 발급됩니다.**(직접) |
| 추천 단계 | 발급 대상(S/O)은 아직 미정이므로 표시되지 않는다 |

### 5.2 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|
| 고객사 미선택 | 확인창 | **고객사를 선택하세요. (신규 고객사는 고객사 관리에서 등록)** |
| 전용 코드에 발급 시도 | 확인창 | **전용 코드입니다. S{n}/O{n} 는 이미 {고객사} 에 할당되어 있습니다.** |
| 반대 코드 종류 충돌 | 확인창 | **{PDS3\|PDS2} 에서 이 owner를 이미 사용 중입니다. 같은 S/O 는 PDS3·PDS2 중 한쪽만 사용할 수 있습니다.** |
| 미등록 고객사 | 확인창 | **고객사 관리에 등록된 고객사가 아닙니다. 먼저 고객사 관리에서 등록하세요.** |
| 저장 실패 | 확인창 | **⚠ 할당이 저장되지 않았습니다.** + 사유 |
| 추천 — 고객사 미선택 | 인라인 | **고객사를 먼저 선택하세요.** |
| 추천 — 조건 미입력 | 인라인 | **판형·페이지 수·권수를 입력하세요.** |
| 추천 — 수용 Section 없음 | 인라인 | **판형 {n}mm · {n}p 를 수용하는 섹션이 없습니다. (조건을 낮추거나 직접 선택을 사용하세요)** |
| 추천 — 여유 구간 없음 | 인라인 | **조건을 만족하는 여유 오너/연속 {n}권 구간을 찾지 못했습니다.** |
| 추천 성공(신규) | 인라인 | **신규 — {용도}/{유형} 기준 {코드종류} 선호. 판형 {n}mm·{n}p 를 수용하는 S{n}(최대 {n}mm/{n}p)에 신규 오너 O{n} 발급.** |
| 추천 성공(기존) | 인라인 | **기존 고객 — {코드종류} S{n}/O{n} 를 유지하고 잔여 구간에서 할당합니다. ({용도})** |
