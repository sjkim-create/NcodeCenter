## 1. 기능 개요

**App Key 를 발급하는 화면**이다. 「**고객사 | App Key 계정 | 계정 상세**」 3단 한 화면에서 고객사를 고르고, 그 고객사의 App Key 계정을 만들고, 계정마다 App Key 와 코드 범위(=티켓)를 발급한다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 **[티켓 발급] ▸ [App Key 관리 (계정 발급)]** (`/tickets/account`) |
| 고객사 | **고객사 관리(`MEM-01`) 고객사를 불러온다** — 여기서 고객사를 등록하지 않는다 `PC-153` |
| 계정 | **App Key 계정** — 계정과 App Key 가 매칭되는 개념(계정당 App Key 1개) |
| 과거 자료 | 개발팀 **Caster_계정_퍼미션_티켓.xlsx** 의 계정 15건(대장) — 고객사명으로 고객사 관리 고객사에 잇는다 |
| 짝 화면 | `TKT-02` N Key 관리 — 같은 3단 · 같은 UI 조각 `PC-154` |

> **App Key 계정 ≠ 서비스 계정.** App Key 계정은 *계정과 App Key 를 매칭*하는 발급 단위이고, 고객사 관리(`MEM-02`)의 **서비스 계정**은 *고객사가 서비스 권한(CasterN 등)을 갖게 하는* 계정이다. 두 계정은 서로의 목록에 나오지 않는다 `PC-128` `PC-153`.

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [티켓 발급] ▸ [App Key 관리 (계정 발급)]
   └─▶ TKT-01  ┌ 고객사(고객사 관리) ┬ App Key 계정 ─────┬ 계정 상세 ─────────────────┐
               │ [발급 고객사]/[전체] │ 카드 목록          │ 탭: 계정 정보 / App Key 발급 │
               │ 검색 · 고객사 미연결 │ [＋ 계정 추가]      │                            │
               └──────────────────┴──────────────────┴────────────────────────────┘
      고객사 클릭 ─▶ 그 고객사 계정 · 첫 계정 상세
      [＋ 계정 추가] ─▶ 「새 계정 · 작성 중」 + 빈 폼 ─ [계정 추가] ─▶ 그 계정 상세 (범위를 골랐으면 App Key 동시 발급)
      계정 상세 ├ 계정 정보 [저장]
                ├ App Key 발급 ─ [코드 범위 발급] ─▶ 티켓 + 원장 티켓(TKT-02 목록에는 N Key 만) · LOG-01
                ├ 발급 내역 [티켓 삭제] / [키 삭제] · 티켓 선택 ─▶ Key 정보
                └ [계정 삭제] ─(확인창)─▶ 다음 계정
      발급 범위 없음 ─▶ SOB-02 에서 SOBP 할당 후 다시
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `PC-153` 키 발급 고객사 | 고객사 = **고객사 관리 고객사**. 키 발급 화면에서 고객사를 등록하지 않는다 |
| `PC-128` 계정 2종 | **App Key 계정**(이 화면) / **서비스 계정**(`MEM-02`) — 섞지 않는다 |
| `PC-029` 계정 수 | 고객사당 제한 없음. ID(이메일)는 **전체에서 유일**(서비스 계정 포함) |
| `PC-050` App Key 단위 | **계정당 1개**. 키 아래 **코드 범위(=티켓)를 여러 건** 발급 — 재발급 개념 없음 |
| `PC-118` 사용기간 | 계정이 아니라 **코드 범위(=티켓)마다** 유지 |
| `PC-119` 원장 티켓 | 코드 범위를 발급할 때마다 원장에 APP 티켓 1건. [티켓 삭제] 시 함께 제거 `PC-121` |
| `P-05` 무겹침 | 범위는 **발급 범위 목록에서 고른다**(좌표를 타이핑하지 않음). Book · Page 만 지정 |
| `PC-154` UI 통일 | `TKT-02` 와 같은 조각 — 한쪽만 고치지 않는다 |

### 4.4 App Key 발급 · 코드 범위 발급

| 항목 | 규칙 |
|---|---|
| 발급 범위 (Caster 대장 이력 · SOBP 할당) | 이 고객사의 Caster 대장 범위 + **고객사 관리에서 할당한 SOBP**. 고르면 Section·Owner·Book·Code Type 이 채워진다. 없으면 **이 고객사의 발급 범위가 없습니다.** (S10) |
| Start Book (시작 북코드) · Book 볼륨 (권) | 범위 안. **Book End = Start + 볼륨 − 1** `PC-050` |
| Start Page · Page 볼륨 | 계정마다 B·P 영역을 다르게 잡는다 `PC-059` |
| Code Type | PDS2 · PDS3 · PDS4 · OID `PC-064` |
| Valid From Time (사용기간 시작) · Valid Until Time (사용기간 끝) | 이 티켓의 기간. 끝은 날짜 또는 **무제한** `PC-118` |
| 자동·고정 | Section · Owner · Ticket Type(무제한 = Unlimited / 기간 = Period) · Ticket Version 1 |
| [코드 범위 발급] | 키가 없으면 첫 발급(App Key 29자 `PC-066`), 있으면 그 키에 티켓 1건 + 원장 티켓 `PC-119` |

**발급 결과(S8)** — **ID · PWD · App Key** 가 나오고 **[전체 복사]** 로 한 번에 복사한다.
