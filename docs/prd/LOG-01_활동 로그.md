## 1. 기능 개요

**내부 직원이 언제 무엇을 했는지**를 시간순으로 확인하는 감사(audit) 화면. 편집·사업·재무 여러 부서가 같은 데이터를 다루므로, 코드 할당·티켓 발급·고객사 변경 같은 주요 행위의 **변경 이력 추적**이 목적이다.

| 항목 | 내용 |
|---|---|
| 권한 | **ADMIN 전용** — 메뉴 자체가 ADMIN에게만 노출된다 |
| 진입 | 좌측 메뉴 [활동 로그] · `DSH-01`의 **[전체 로그]** |
| 성격 | 조회 전용(기록은 각 화면에서 자동 생성) |
| 기록 시각 | 한국시간(KST) 기준 |

---

## 2. 화면 흐름 (Flow)

```
DSH-01 [전체 로그]  또는  좌측 메뉴 [활동 로그](ADMIN)
   └─▶ LOG-01
         ├─ 월 · 직원 · 활동 종류 필터
         ├─ 월 ▸ 일 그룹으로 목록 확인
         └─ [전체 삭제] ─ 확인 ─▶ 기록 초기화 (되돌릴 수 없음)

기록은 각 화면에서 자동 생성:
   MEM-02 → 고객사 관리 · SOB-02 → 코드 할당(등록) · PRJ-01 → 프로젝트 등록
   TKT-01/03/05 → 티켓 발급 · PRJ-04 → 교재 추가 / 교재 작업 · 로그인/로그아웃
```

---

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `PC-002` 내부 직원 전용 | 기록 대상은 **내부 직원의 행위**뿐이다. 외부 고객 열람 없음 |
| 감사 목적 | 기록은 **자동 생성**된다. 사용자가 임의로 항목을 추가·수정할 수 없다 |
| 보관 기간 | 현재 **최근 7일**만 유지(테스트 기준) — 운영 기준은 §7 협의 항목 |
| 시간 기준 | 실행 환경의 시간대와 무관하게 **한국시간(KST)** 으로 기록·표시 |

## 4. 사용법

### 4.1 필터

| 필터 | 동작 |
|---|---|
| **월** | `YYYY년 M월` 단위. 기본 전체 |
| **직원** | 활동을 기록한 직원. 기본 전체 |
| **활동 종류** | 아래 8종. 각 종류에 **현재 조건 기준 건수**가 함께 표시된다 |

활동 종류

| 종류 | 발생 화면 |
|---|---|
| 고객사 관리 | `MEM-02` |
| 코드 할당(등록) | `SOB-02` |
| 프로젝트 등록 | `PRJ-01` |
| 티켓 발급 | `TKT-01` · `TKT-03` · `TKT-05`(정산 등록) |
| 교재 추가 | `PRJ-04` (등록) |
| 교재 작업 | `PRJ-04` (수정) |
| 로그인 / 로그아웃 | 로그인 화면 |

필터를 적용하면 상단에 **조건에 맞는 활동 {n}건**이 표시된다.

### 4.2 목록

| 표시 | 내용 |
|---|---|
| 그룹 | **월 ▸ 일** 단위로 묶여 표시(요일 포함) |
| 행 | 시각(시:분) · 활동 종류 · 직원 · 상세 내용 |
| 상세 내용 | 각 화면에서 남긴 요약 (예: 고객사·S/O·서비스·발급 범위) |

### 4.3 전체 삭제

[전체 삭제]는 **기록을 모두 지우고 새로 기록**한다. 되돌릴 수 없으므로 확인창을 거친다.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 |
|---|---|
| 기록 없음 | 조건에 맞는 활동 0건 |
| 보관 기간 경과 | 7일이 지난 기록은 목록에 나타나지 않는다 |
| ADMIN이 아닌 사용자 | 좌측 메뉴에 이 화면이 **노출되지 않는다** |

### 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|
| 전체 삭제 | 확인창 | **활동 로그를 전부 삭제하고 새로 기록하시겠습니까? (되돌릴 수 없습니다)** |
