## 1. 기능 개요

**내부 직원이 언제 무엇을 했는지**를 시간순으로 확인하는 감사(audit) 화면. 편집·사업·재무 여러 부서가 같은 데이터를 다루므로, 코드 할당·티켓 발급·고객사 변경 같은 주요 행위의 **변경 이력 추적**이 목적이다.

| 항목 | 내용 |
|---|---|
| 권한 | **ADMIN 전용** — 메뉴 자체가 ADMIN에게만 노출된다 |
| 진입 | 좌측 메뉴 [활동 로그] · `DSH-01`의 **[전체 로그]** |
| 성격 | 조회 전용(기록은 각 화면에서 자동 생성) |
| 기록 시각 | 한국시간(KST) 기준 |

---

## 2. 화면 흐름 (Flow)

```
DSH-01 [전체 로그]  또는  좌측 메뉴 [활동 로그](ADMIN)
   └─▶ LOG-01
         ├─ 월 · 직원 · 활동 종류 필터
         ├─ 월 ▸ 일 그룹으로 목록 확인
         └─ [전체 삭제] ─ 확인 ─▶ 기록 초기화 (되돌릴 수 없음)

기록은 각 화면에서 자동 생성:
   MEM-02 → 고객사 관리 · SOB-02 → 코드 할당(등록) · PRJ-01 → 프로젝트 등록
   TKT-02/01 → 티켓 발급 · PRJ-04 → 교재 추가 / 교재 작업 · 로그인/로그아웃
```

## 4. 사용법

### 4.1 상단 (S1)

*내부 직원 활동을 **월별 · 일자별**로 확인. 활동 종류·직원·월로 필터. · 전체 {n}건* 과 우측의 **[전체 삭제]** 로 이루어진다.

### 4.2 필터 (S1 · S2) `PC-251`

| 줄 | 요소 | 동작 |
|---|---|---|
| **기간 · 직원**(활동 종류 아래 `PC-255`) | **[주] [월]** · [‹] [›] · [이번 주] / [이번 달] · 직원 셀렉트 — 보는 기간 글자(주: YYYY. M.D (일) ~ M.D (토) / 월: YYYY년 M월)는 **달력 위** | 보기를 바꾸면 고른 날이 든 주 / 달로. ‹ › 는 한 주 / 한 달씩. 이번 주 · 달이 아니면 그 주 일요일 · 그 달 1일을 고른다 `PC-252` |
| **활동 종류** | 전체 · 8종 칩(색 점 + 라벨 + 건수) | 토글. 건수는 **이 주 · 직원 기준** |

활동 종류

| 종류 | 발생 화면 · 담는 것 |
|---|---|
| 고객사 | `MEM-01` · `MEM-02` 고객사 관리 — 등록 · 수정 · 사업 종료 · 온보딩 승인 / 거절 · 서비스 계정 |
| 코드 할당 | `SOB-01` · `SOB-02` SOBP 맵 — 할당 · 해제 |
| 편집 | `PRJ-02` ~ `PRJ-05` CasterN 편집 — 편집 고객사 추가 · 삭제, 교재 추가 · 작업 · 삭제 |
| App Key | `TKT-01` App Key 관리 — 계정 등록 · 수정, App Key 발급, 권한, 티켓 발급 · 수정 |
| N Key | `TKT-02` N Key 관리 — 발급 · 수정 · 키 다운로드 |
| 서비스 티켓 | `MEM-02` 고객사 관리 ▸ 서비스 티켓 — 지정 · 수정 |
| 정산 | 세 티켓 공통 — N Key · App Key · 서비스 티켓 정산 등록, 연간 라이선스 비용 |
| 접속 | 로그인 화면 — 로그인 · 로그아웃 |

> 종류는 **지금 메뉴 기준 8종**이다 `PC-248`. 정산은 따로 둔다. 색은 한눈에 구분되는 8색 — 고객사 파랑 · 코드 할당 보라 · 편집 청록 · App Key 노랑 · N Key 분홍 · 서비스 티켓 초록 · 정산 빨강 · 접속 회색 `PC-253`.

### 4.3 주 달력 · 상세 (S1 · S3) `PC-251`

| 영역 | 내용 |
|---|---|
| 월 달력(왼쪽 · [월]) | 그 달 1일이 든 주부터 6줄. 칸마다 날짜 · 건수 · 색 막대 · **색 점**(이름 없이 점만 — 마우스를 올리면 종류 · 건수, **4개씩 2줄 · 8개까지** `PC-253`). 그 달 밖 날은 흐리게 `PC-252` |
| 주 달력(왼쪽 · [주]) | **날짜를 행으로 7줄** `PC-254` — 줄마다 요일 · 날짜(오늘은 파란 배경) · **건수** · **색 점 + 종류 · 건수**(한 줄 · 색 막대 없음 `PC-255`). 고른 날은 파란 테두리, 앞날은 흐리게(고를 수 없음). 날짜 글씨는 보통 굵기 |
| 상세(오른쪽) | **{M}월 {D}일 ({요일}) · {n}건** — 그날 활동을 최신순으로. 행 = 시각 44 · 종류 배지 84 · 내용(2줄 · 넘치면 말줄임, 전체는 툴팁) / 직원 — 열 너비 고정 `PC-073` |
| 빈 날 | 달력 칸 **—**, 상세 **이 날 활동이 없습니다.** |
| 보관 | **한 달** — 그보다 오래된 기록은 지운다(브라우저 저장 · 운영은 서버 보관 필요) `PC-252` |

### 4.4 전체 삭제 (S4)

**[전체 삭제]** 는 기록을 모두 지우고 새로 기록한다. 되돌릴 수 없으므로 확인창을 거친다.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 | 화면 번호 |
|---|---|---|
| 기본 | 필터 2줄 + 주 달력 + 오늘 상세 | S1 |
