## 1. 기능 개요

**내부 직원이 언제 무엇을 했는지**를 시간순으로 확인하는 감사(audit) 화면. 편집·사업·재무 여러 부서가 같은 데이터를 다루므로, 코드 할당·티켓 발급·고객사 변경 같은 주요 행위의 **변경 이력 추적**이 목적이다.

| 항목 | 내용 |
|---|---|
| 권한 | **ADMIN 전용** — 메뉴 자체가 ADMIN에게만 노출된다 |
| 진입 | 좌측 메뉴 [활동 로그] · `DSH-01`의 **[전체 로그]** |
| 성격 | 조회 전용(기록은 각 화면에서 자동 생성) |
| 기록 시각 | 한국시간(KST) 기준 |

---

## 2. 화면 흐름 (Flow)

```
DSH-01 [전체 로그]  또는  좌측 메뉴 [활동 로그](ADMIN)
   └─▶ LOG-01
         ├─ 월 · 직원 · 활동 종류 필터
         ├─ 월 ▸ 일 그룹으로 목록 확인
         └─ [전체 삭제] ─ 확인 ─▶ 기록 초기화 (되돌릴 수 없음)

기록은 각 화면에서 자동 생성:
   MEM-02 → 고객사 관리 · SOB-02 → 코드 할당(등록) · PRJ-01 → 프로젝트 등록
   TKT-04/03/05 → 티켓 발급 · PRJ-04 → 교재 추가 / 교재 작업 · 로그인/로그아웃
```

| 정책 | 이 화면에서의 적용 |
|---|---|

## 4. 사용법

### 4.1 상단 (S1)

*내부 직원 활동을 **월별 · 일자별**로 확인. 활동 종류·직원·월로 필터. · 전체 {n}건* 과 우측의 **[전체 삭제]** 로 이루어진다.

### 4.2 필터 (S1 · S2)

필터는 **월 / 직원 / 활동 종류** 3줄이며, 각 줄 왼쪽에 라벨이 붙는다. 모두 **알약 칩**이고 기본값은 **전체**다.

> 칩은 **토글**이다 — 선택된 칩을 다시 누르면 **전체**로 돌아간다.

| 필터 | 동작 |
|---|---|
| **월** | `YYYY년 M월` 단위. 기록이 있는 달만 **최신순**으로 나온다 |
| **직원** | 활동을 기록한 직원. 칩에 **이니셜 아바타**가 함께 표시된다 |
| **활동 종류** | 아래 8종. 칩마다 **색 점**과 **건수**가 붙는다 |

> 활동 종류 칩의 건수는 **월·직원 필터만 반영**한다. 다른 종류를 골라도 이 숫자는 바뀌지 않는다.

활동 종류

| 종류 | 발생 화면 |
|---|---|
| 고객사 관리 | `MEM-02` |
| 코드 할당(등록) | `SOB-02` |
| 프로젝트 등록 | `PRJ-01` |
| 티켓 발급 | `TKT-04` · `TKT-01` · `TKT-05`(정산 등록) |
| 교재 추가 | `PRJ-04` (등록) |
| 교재 작업 | `PRJ-04` (수정) |
| 로그인 / 로그아웃 | 로그인 화면 |

필터 아래에 **조건에 맞는 활동 {n}건** 이 표시된다.

### 4.3 목록 (S1)

**최신순**으로 정렬되고 **월 ▸ 일** 로 묶인다.

| 구역 | 표시 |
|---|---|
| 월 헤더 | **{n}년 {n}월** + `{n}건` + 가로 구분선 |
| 일자 칸 (왼쪽) | **날짜 숫자**(크게) · `YYYY-MM · {요일}요일` · `{n}건` — 오른쪽 정렬 |
| 활동 카드 (오른쪽) | 한 줄에 **시각(시:분) · 활동 종류 배지(색) · 상세 내용 · 직원(이니셜 아바타)** |

상세 내용은 각 화면에서 남긴 요약이다 (예: 고객사·S/O·서비스·발급 범위).

### 4.4 전체 삭제 (S4)

**[전체 삭제]** 는 기록을 모두 지우고 새로 기록한다. 되돌릴 수 없으므로 확인창을 거친다.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 | 화면 번호 |
|---|---|---|
| 기본 | 필터 3줄 + 월 ▸ 일 그룹 목록 | S1 |
| 활동 종류 필터 | 해당 종류만 남고 **조건에 맞는 활동 {n}건** 이 줄어든다 | S2 |
| 조건에 맞는 기록 없음 | **해당 조건의 활동이 없습니다.** + *고객사 수정·코드 할당·프로젝트 등록·티켓 발급·교재 추가/작업·로그인 시 자동 기록됩니다.* | S3 |
| 보관 기간 경과 | **7일**이 지난 기록은 목록에 나타나지 않는다 | S1 |
| ADMIN이 아닌 사용자 | **화면 자체가 열리지 않는다** — 🔒 **접근 권한이 없습니다** / *활동 로그는 관리자(ADMIN) 계정만 열람할 수 있습니다.* | S5 |

> 좌측 메뉴에도 **ADMIN** 배지가 붙지만, 메뉴를 숨기는 것이 아니라 **화면에서 막는다.**

### 메시지

| 상황 | 노출 방식 | 문구 | 화면 |
|---|---|---|---|
| 전체 삭제 | 확인창 | **활동 로그를 전부 삭제하고 새로 기록하시겠습니까? (되돌릴 수 없습니다)** | S4 |
| 권한 없음 | 화면 대체 | **접근 권한이 없습니다 / 활동 로그는 관리자(ADMIN) 계정만 열람할 수 있습니다.** | S5 |
