## 1. 기능 개요

발급된 티켓(N Key · App Key)의 **전체 이력을 조회하고, 발급 건별로 상세·정산 화면에 들어가는 진입점**이다. 재무·사업부가 "누구에게 무엇을 얼마에 발급했는지"를 확인한다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 **[티켓 발급] ▸ [Key 관리]** |
| 목록 대상 | **N Key 와 App Key 를 함께** 쌓는다. N Key 는 이 메뉴에서, App Key 는 계정 등록·수정 화면에서 발급된다 |
| 데이터 출처 | **대장**(과거 발급 이력) + **신규발급**(이 시스템에서 발급한 티켓) |
| 성격 | **목록 화면** — 값 수정은 발급 상세에서 한다 |

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [티켓 발급] ▸ [Key 관리]
   └─▶ TKT-03 목록
         ├─ [＋ N Key 발급] ──────────▶ TKT-04 N Key 생성
         ├─ [N Key 불러오기] ─────────▶ 파일 확인 창 ─ 닫기 ─▶ TKT-03
         ├─ 발급번호 · 발급 내용 클릭 ──▶ TKT-02 발급 상세 (발급 기본정보 탭)
         ├─ 행 [정산] ────────────────▶ TKT-02 발급 상세 (정산 정보 탭)
         ├─ 행 [상세] ────────────────▶ TKT-02 발급 상세
         └─ 행 [삭제] ─ 확인 ─────────▶ 목록에서 제거
```

정산 등록과 Key 정보 확인은 **더 이상 이 화면의 모달이 아니다.** 둘 다 발급 상세(`TKT-02`)의 탭으로 들어갔다.

## 4. 사용법

### 4.1 상단 요약

| 지표 | 의미 |
|---|---|
| 발급 티켓 | 현재 필터 기준 건수 |
| 유료 합계 | 유료 티켓 금액 합계 |
| 유료 건수 | 유료로 등록된 건수 |
| 무료 / 체험 | 각 건수 |
| 정산 미등록 | 아직 과금 유형을 정하지 않은 건수 — 0이 아니면 강조한다 |

요약은 **필터를 반영한 결과 전체 기준**으로 다시 계산한다. **페이지를 넘겨도 합계는 변하지 않는다** — 페이지에 따라 합계가 달라지면 정산 화면으로서 오해를 부르기 때문이다.

체험 만료 건이 있으면 목록 위에 경고가 표시된다 — **⚠ 체험 기간이 만료된 티켓 {n}건 — 유료 전환 또는 회수 여부를 확인하세요.**

### 4.2 도구 막대

한 줄에 이어져 있고 구분선으로 묶음이 나뉜다.

| 요소 | 값 |
|---|---|
| 고객사 | 드롭다운. 기본 **고객사 전체** — 발급 이력이 있는 고객사만 나온다 |
| 종류 | `전체` / `N Key` / `App Key` |
| 정산 | `정산 전체` / `미정` / `유료` / `무료` — **체험은 필터에 없다** |
| 출처 | `전체` / `대장` / `신규발급` |
| 검색 | **고객사·내용 검색** — 발급 내용과 발급인을 함께 찾는다 |
| **[N Key 불러오기]** | 외부 키 파일을 열어 내용을 확인한다 (§4.5) |
| **[＋ N Key 발급]** | `TKT-04` N Key 생성 화면으로 이동한다 |

### 4.3 정렬 · 목록

| 항목 | 동작 |
|---|---|
| 정렬 가능 열 | **발급일시 · 고객사 · 발급인** 3개. 머리글을 누르면 오름/내림이 바뀐다 |
| 기본 정렬 | **발급일시 내림차순(최근순)** |

| 열 | 내용 |
|---|---|
| No | 발급 번호. **누르면 발급 상세로 이동** |
| 발급일시 | 발급 시각(분 단위) |
| 종류 | **N Key** / **App Key** |
| 고객사 | 업체명. 과거 이력이면 **대장** 배지 |
| 발급 내용 | 발급 요약(코드 종류·S/O/B·페이지·권수·유효기간 등). **누르면 발급 상세로 이동** |
| 발급인 | 발급한 직원. 없으면 `-` |
| 정산 | **미정 / 유료 / 무료 / 체험**. 체험은 아래 줄에 **~만료일 (D-n)**, 지났으면 **(만료)** |
| 금액 | 유료일 때만 금액. 그 외는 `-` |
| 비고 | 정산 등록 시 입력한 사유·계약 정보. 없으면 `-` |
| 작업 | **[정산]** · **[상세]** · **[삭제]** |

### 4.4 행 작업

| 버튼 | 동작 |
|---|---|
| **[정산]** | 발급 상세(`TKT-02`)를 열되 **정산 정보 탭이 선택된 상태**로 들어간다 |
| **[상세]** | 발급 상세(`TKT-02`)를 **발급 기본정보 탭**으로 연다 |
| **[삭제]** | 확인 후 발급 기록을 목록에서 제거한다 |

### 4.5 N Key 불러오기

도구 막대의 **[📂 N Key 불러오기]** 로 내려받은 **키 파일(.json)** 을 열어 항목을 확인한다. **발급 원장에 없는 외부 키도 확인할 수 있다.**

창 명세는 [TKT-06](TKT-06_N%20Key%20불러오기.md) 참조 — 항목 표시 · 항목 검색 · 표 복사 · 형식 오류 처리.

> 원장에 있는 건의 항목은 이 창이 아니라 `TKT-05` 발급 상세에서 본다.

### 4.6 페이지네이션

| 요소 | 값 |
|---|---|
| 페이지당 건수 | `25` / `50` / `100` / `200` / `500` / `전체 보기` — 기본 **50건** |
| 이동 | 처음 · 이전 · 페이지 번호(최대 7개) · 다음 · 끝 |
| 표기 | **전체 {n}건 중 {시작}~{끝} 표시** · 우측에 **{현재} / {전체}** 페이지 |
| 초기화 | 필터·검색·정렬이 바뀌면 **1페이지로 되돌아간다** |
| 목록이 빔 | 페이지네이션 막대를 표시하지 않는다 |

### 4.7 계산 규칙

**(가) 요약 — 필터 결과 전체 기준**

```
유료 합계   = 필터 결과 중 정산이 '유료' 인 티켓의 금액 합
정산 미등록 = 필터 결과 중 정산이 '미정' 인 티켓 건수

예) 필터 결과 6건
    유료 3건 = 3,500,000 + 4,800,000 + 0 → 유료 합계 8,300,000
    미정 2건 → 정산 미등록 2건
    페이지당 50건으로 1페이지만 보고 있어도 위 값은 6건 전체 기준이다
```

**(나) 체험 잔여일**

```
잔여일 = 체험 만료일 − 오늘
0 이상이면 D-{잔여일}, 음수이면 (만료)

예) 오늘 2026-08-29
    만료일 2026-09-25 → 27일 남음 → D-27
    만료일 2026-07-31 → 29일 지남 → (만료) · 상단 경고 배너에 포함
```

**(다) 페이지 표시 범위**

```
전체 페이지 수 = 올림(전체 건수 ÷ 페이지당 건수)
시작 = (현재 페이지 − 1) × 페이지당 건수 + 1
끝   = 최소(현재 페이지 × 페이지당 건수, 전체 건수)

예) 전체 142건 · 페이지당 50건 · 3페이지
    전체 페이지 = 올림(142 ÷ 50) = 3
    시작 = (3 − 1) × 50 + 1 = 101
    끝   = 최소(150, 142) = 142
    표기 : 전체 142건 중 101~142 표시 · 3 / 3
```

## 5. 상태별 변화 · 메시지

### 5.1 상태

| 상태 | 화면 | 화면 번호 |
|---|---|---|
| 기본 목록 | 요약 5칸 + 도구 막대 + 표 + 페이지네이션. 최근순 정렬 | S1 |
| 체험 만료 · 대장 이력 | 만료일 옆 **(만료)** 와 목록 상단 경고 배너. 고객사명 옆 **대장** 배지 | S2 |
| 필터 — 종류 · 정산 · 출처 | 세 묶음이 함께 걸린다. 요약이 결과 기준으로 다시 계산된다 | S3 |
| 정렬 | 발급일시 · 고객사 · 발급인 머리글로 오름/내림 전환 | S4 |
| 필터 결과 없음 | 표가 비고 요약은 **0건 기준**으로 다시 계산된다. 페이지네이션은 사라진다 | S5 |
| 발급 이력 없음 | 아직 한 건도 발급하지 않은 상태 | S6 |
| 페이지 이동 | 페이지당 건수 변경·페이지 이동. 요약 합계는 변하지 않는다 | S7 |
| 삭제 확인 | 확인창 | S8 |
