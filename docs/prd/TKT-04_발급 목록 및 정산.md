## 1. 기능 개요

발급된 티켓(N Key · App Key)의 **전체 이력을 조회하고, 티켓별 과금(정산) 상태를 관리**한다. 재무·사업부가 "누구에게 무엇을 얼마에 발급했는지"를 확인하는 화면이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | `TKT-01` 좌측 발급 메뉴 [발급 목록 · 정산] |
| 데이터 출처 | **대장**(nkey(HLP) 발급 대장에서 가져온 과거 이력) + **신규발급**(이 시스템에서 발급한 티켓) |

---

## 2. 화면 흐름 (Flow)

```
TKT-01 발급 메뉴 [발급 목록 · 정산]
   └─▶ TKT-04
         ├─ 필터·검색·정렬로 대상 티켓 찾기
         ├─ 행 [정산 등록] ─▶ TKT-05 (모달) ─ 저장 ─▶ TKT-04 갱신
         ├─ 행 [Key 정보]  ─▶ TKT-02 (모달, 발급된 티켓 값 기준) ─ 닫기 ─▶ TKT-04
         └─ 행 [삭제] ─ 확인 ─▶ 목록에서 제거
```

---

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-15` 티켓 = N Key / App Key + 정산 | 종류(N Key/App Key)와 **정산 구분(유료·무료·체험·미정)** 을 함께 관리 |
| `PC-016` 출처 구분 | **대장(ledger)** 과 **신규발급**을 배지·필터로 구분한다 |
| 요구사항 #1 | 체험 티켓은 **만료일과 잔여일**을 표시하고, 만료 건은 경고로 드러낸다 |
| `P-16` 정산 | 편집 정산(`PRJ-03`)과 별개. **코드 라이선스 과금**은 이 화면에서 관리 |

## 4. 사용법

### 4.1 상단 요약

| 지표 | 의미 |
|---|---|
| 발급 티켓 | 현재 필터 기준 건수 |
| 유료 합계 | 유료 티켓 금액 합계 |
| 유료 건수 | 유료로 등록된 건수 |
| 무료 / 체험 | 각 건수 |
| 정산 미등록 | **아직 정산 구분을 등록하지 않은 건수**(0이 아니면 강조) |

체험 만료 건이 있으면 목록 위에 경고가 표시된다 — **⚠ 체험 기간이 만료된 티켓 {n}건 — 유료 전환 또는 회수 여부를 확인하세요.**

### 4.2 필터 · 검색 · 정렬

| 요소 | 동작 |
|---|---|
| 고객사 | 드롭다운. 기본 **고객사 전체** |
| 종류 | `전체` / `N Key` / `App Key` |
| 정산 | `정산 전체` / `유료` / `무료` / `체험` / `미정` |
| 출처 | `전체` / `대장`(nkey(HLP) 발급 대장) / `신규발급`(이 화면에서 발급한 티켓) |
| 검색 | **고객사·내용 검색** |
| 정렬 | `발급일시` · `고객사` · `발급인` 열 머리글 클릭으로 오름/내림 전환 |

### 4.3 목록 항목

| 열 | 내용 |
|---|---|
| No | 발급 번호 |
| 발급일시 | 발급 시각 |
| 종류 | N Key / App Key |
| 고객사 | 업체명. 과거 이력이면 **대장** 배지 |
| 발급 내용 | 발급 요약(코드 종류·S/O/B·페이지·권수·유효기간 등) |
| 발급인 | 발급한 직원 |
| 정산 | 유료 / 무료 / 체험 / 미정. 체험은 **만료일과 D-n**(지났으면 **(만료)**) |
| 금액 | 유료일 때만 금액 표시 |
| 비고 | 정산 등록 시 입력한 사유·계약 정보 |
| 작업 | [정산 등록] · [Key 정보] · [삭제] |

### 4.4 행 작업

| 버튼 | 동작 |
|---|---|
| **[정산 등록]** | `TKT-05` 모달을 연다. 저장하면 목록의 정산·금액·비고가 즉시 갱신된다 |
| **[Key 정보]** | `TKT-02` 모달을 연다. **이미 발급된 티켓에 저장된 값**을 key·value로 보여준다(`TKT-01`의 같은 모달과 화면은 동일, 데이터 출처만 다름) |
| **[삭제]** | 확인 후 발급 기록을 목록에서 제거한다 |

## 5. 상태별 변화 · 메시지

| 상태 | 화면 |
|---|---|
| 정산 미등록 | 정산 열이 **미정**으로 표시되고, 상단 **정산 미등록** 건수에 포함 |
| 체험 진행 중 | 만료일과 **D-n** 표시 |
| 체험 만료 | 만료일 옆 **(만료)** 표시 + 목록 상단 경고 배너 |
| 대장 이력 | 고객사명 옆 **대장** 배지 (툴팁: nkey(HLP) 발급 대장에서 가져온 과거 이력) |
| 필터 결과 없음 | 목록이 비어 있고 상단 요약은 0건 기준으로 표시 |

### 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|
| 발급 기록 삭제 | 확인창 | **발급 {No}번 기록을 삭제할까요?** |
| 체험 만료 존재 | 배너 | **⚠ 체험 기간이 만료된 티켓 {n}건 — 유료 전환 또는 회수 여부를 확인하세요.** |
