## 1. 기능 개요

**App Key = 계정과 연동되는 키.** 온라인 편집툴(Caster U)·폼솔루션·SDK에서 사용하며, **계정(ID/PWD)과 SOBP 범위를 한 번에 발급**한다. 계정이 없으면 발급할 수 없으므로, 신규 고객사는 이 화면에서 계정 등록과 키 발급을 한 흐름으로 처리한다.

발급할 때 **사용처(연동 서비스)** 를 지정한다. 계정은 **그 서비스에서만 로그인**되며, 각 서비스는 자기 계정만 인증·관리한다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | `TKT-01` 좌측 발급 메뉴 [계정 + App Key] |
| 선행 조건 | 고객사가 `MEM-01`에 등록되어 있고 `SOB-02`로 SOBP를 할당받았을 것 |
| N Key와의 차이 | N Key는 계정 불필요(오프라인). **App Key는 계정 필수(온라인·SDK)** |

## 2. 화면 흐름 (Flow)

```
TKT-01 발급 메뉴 [계정 + App Key]
   └─▶ TKT-03
         ① 계정 ─ 회사(고객사) 선택
         │        ├─ 기존 계정 있음 ─▶ 계정 선택
         │        └─ 기존 계정 없음 ─▶ 신규 계정 입력(ID·PWD·NAME·ADDR·HOMEPAGE)
         ② 할당된 SOBP 범위 선택   ─(범위 없음)─▶ SOB-02 로 이동해 할당
         ③ 발급 조건(사용처·만료) 입력
         └─ [계정 등록 + App Key 발급] / [App Key 발급]
                  └─▶ 발급 결과(계정 ID·PWD·App Key) 표시
                  └─▶ 서비스 DB 목록에 계정·키 추가
                  └─▶ TKT-04 발급 목록 기록 · LOG-01 활동 로그 기록
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-15` 티켓 = N Key / App Key | **App Key = 계정 연동 키.** 계정 없이는 발급 불가 |
| `P-05` 무겹침 | 키는 **이미 할당된 SOBP 범위**에만 연결된다. 범위를 직접 타이핑하지 않는다 |
| `P-02` 코드 종류 N/G | PatternType은 선택한 범위에서 자동 결정 |
| `PC-002` 내부 직원 전용 | 고객이 직접 계정을 만들지 않는다. **직원이 대신 등록**한다 |
| `P-13` 사용 서비스 | 계정·App Key는 **사용처(연동 서비스)** 를 갖는다. 계정은 그 서비스에서만 로그인되고, 다른 서비스에서는 인증되지 않는다 |
| 요구사항 #1 | 만료일(또는 무제한)로 기간 제한 |

## 4. 사용법

### 4.1 ① 계정

회사(고객사)를 선택하면 **그 고객사에 이미 등록된 계정이 있는지에 따라 화면이 자동으로 갈린다.**

| 상황 | 화면 |
|---|---|
| 기존 계정 있음 | 계정 목록에서 선택 → 신규 입력 항목은 표시되지 않음 |
| 기존 계정 없음(신규) | 계정 입력 항목 표시 |

| 항목 | 필수 | 규칙 |
|---|---|---|
| 회사정보(고객사) | ✔ | `MEM-01` 등록 고객사 |
| 계정(기존 선택) | 조건부 | 기존 계정이 있을 때 |
| NAME(담당자/사용자명) | — | |
| ID (EMAIL) | ✔ | **이메일 형식**이어야 한다 |
| PWD | ✔ | 비밀번호를 요청하지 않는 고객사(SDK)는 **[임의 생성]** 으로 자동 생성 |
| ADDR(주소) | — | 고객사 주소가 자동 입력되며 수정 가능 |
| HOMEPAGE | — | |

### 4.2 ② 할당된 SOBP 범위

고객사가 할당받은 범위 목록에서 하나를 선택한다. 선택 결과가 키에 연결될 **Section · Owner · Book 범위 · Page 범위 · PatternType**이 된다. 범위가 없으면 발급 버튼이 비활성 상태로 유지된다.

### 4.3 ③ 발급 조건

| 항목 | 필수 | 규칙 |
|---|---|---|
| 사용처 (연동 서비스) | ✔ | **CasterN**(Caster U 웹 편집툴 · 계정 로그인) / **폼솔루션**(폼솔루션 서비스 · 계정 로그인) / **SDK 연동**(id/pwd + SOBP 직접 사용) |
| 만료일(기간) | — | 날짜 선택. **무제한** 체크 시 기간 제한 없음 |

### 4.4 발급

버튼 라벨은 상황에 따라 바뀐다 — 신규 계정이면 **[계정 등록 + App Key 발급]**, 기존 계정이면 **[App Key 발급]**.

발급이 끝나면 결과 영역에 **계정 ID · PWD · App Key**가 표시되고, **[전체 복사]** 로 세 값을 한 번에 복사해 고객사에 전달할 수 있다.

### 4.5 서비스 DB · 계정 & App Key

화면 하단에서 선택한 고객사의 **계정별 App Key 목록**을 확인·정리한다. 계정 행에는 **사용처(연동 서비스)** 가 함께 표시되며, App Key에도 같은 서비스가 기록된다.

| 동작 | 결과 |
|---|---|
| 사용처 배지 | 이 계정이 로그인할 수 있는 서비스. 값이 없는 과거 계정은 **미지정**으로 표시된다 |
| 계정 [삭제] | 확인창 → 계정과 **연동된 App Key가 함께 삭제**된다 |
| 키 [키 삭제] | 해당 App Key만 삭제 |

## 5. 상태별 변화 · 메시지

### 5.1 상태

| 상태 | 화면 |
|---|---|
| 고객사 미선택 | 서비스 DB 영역에 **고객사 선택 시 표시** 안내. 발급 버튼 비활성 |
| 할당 범위 없음 | 발급 버튼 비활성 → `SOB-02`에서 할당 필요 |
| 발급 완료 | 결과 영역에 **발급 완료 — 계정 + App Key (서비스 DB 등록됨)** 와 ID·PWD·App Key 표시. 신규 계정이었다면 입력 항목이 비워지고 방금 만든 계정이 선택 상태가 된다 |

### 5.2 메시지 (인라인)

| 상황 | 문구 |
|---|---|
| 회사 미선택 | **회사(고객사)를 선택하세요.** |
| ID 형식 오류 | **계정 ID는 이메일 형식이어야 합니다.** |
| 비밀번호 없음 | **비밀번호가 필요합니다. (요청 없으면 [임의 생성])** |
| 범위 미선택 | **할당된 SOBP 범위를 선택하세요.** |
| 계정 미선택(기존 계정 모드) | **계정을 선택하세요.** |
| 발급 성공 | **App Key 발급 완료 — 계정과 연동되어 서비스 DB에 등록되었습니다.** |
| 전체 복사 | **계정·키 정보가 복사되었습니다.** |

### 5.3 확인창

| 상황 | 문구 |
|---|---|
| 계정 삭제 | **이 계정과 연동 App Key를 삭제할까요?** |

## 7. 미결 · 협의

- [ ] **비밀번호 전달 방식** — 현재 화면 표시·복사. 메일 발송 등 안전한 전달 경로 필요 여부
- [ ] **키 회수(폐기)** — 삭제 외에 "정지/만료 처리" 상태가 필요한지
- [ ] 계정 1개에 App Key 여러 개를 허용하는 현재 방식의 **상한** 필요 여부
- [ ] **사용처 변경**(예: CasterN → 폼솔루션) 절차 — 현재는 계정 재등록. 변경 시 기존 App Key 처리 방식 확정 필요
- [ ] 서비스 측 **인증 연동 방식** — 서비스가 계정·App Key를 조회하는 API 규격 (개발팀 협의)
- [ ] 사용처가 없는 **기존 계정(미지정)** 의 일괄 지정 방법
