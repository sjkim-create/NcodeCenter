## 1. 기능 개요

내려받은 **키 파일(.json)** 을 열어 그 안에 무엇이 들어 있는지 확인하는 창이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | `TKT-03` Key 관리 도구 막대의 **[📂 N Key 불러오기]** |
| 성격 | **조회 전용** — 파일을 고쳐 저장하는 기능이 아니다 |
| 대상 | **발급 원장에 없는 외부 키 파일도 확인할 수 있다** |

> 발급 원장에 있는 건의 항목은 `TKT-05` 발급 상세에서 본다. 이 화면은 **파일** 을 본다.

**쓰는 상황**

- 고객사가 "이 키가 어느 범위인지" 물어볼 때 받은 파일을 열어 확인한다
- 예전에 내보낸 파일이 어느 발급 건인지 대조한다
- 파일이 정상인지(형식이 맞는지) 확인한다

## 4. 사용법

### 4.1 파일 선택

도구 막대의 **[📂 N Key 불러오기]** 를 누르면 파일 선택 창이 열린다. `.json` 파일을 고르면 내용을 읽어 창에 표시한다.

**같은 파일을 연속으로 다시 고를 수 있다** — 파일을 고친 뒤 다시 확인하는 경우를 위해서다.

### 4.2 항목 표시

| 요소 | 내용 |
|---|---|
| 파일명 | 어떤 파일을 보고 있는지 창 위에 고정으로 표시한다 |
| 항목 수 | **{n}개 항목 (불러온 파일)** |
| 표 | `Key` · `Value` 2열. 파일에 들어 있는 항목을 **그대로** 나열한다 |

항목 구성은 발급 당시 만들어진 그대로다 — `CompanyName` · `IssuedTime` · `ValidUntilTime` · `Section` · `Owner` · `BookStart` · `BookVolume` · `PageStart` · `PageVolume` · `PatternType` · `TicketType` · `SeparateEachBook` 등. **중첩된 값은 펼쳐서 한 줄씩** 보여준다.

### 4.3 항목 검색

검색어로 표를 거른다. **항목명과 값을 함께** 찾는다.

```
예) 파일 항목 13개에서 "book" 으로 검색
    BookStart   400
    BookVolume  100
    SeparateEachBook  N (1개 티켓 병합)
    → 3개 항목 표시
```

### 4.4 표 복사

**[표 복사]** 는 **현재 표시 중인 항목**을 복사한다. 검색으로 걸러 놓았으면 걸러진 것만 복사된다.

### 4.5 닫기

**[닫기]** 또는 **✕** 로 창을 닫으면 `TKT-03` 목록으로 돌아간다. 목록의 필터·페이지 상태는 그대로 유지된다.

## 5. 상태별 변화 · 메시지

### 5.1 상태

| 상태 | 화면 | 화면 번호 |
|---|---|---|
| 불러오기 완료 | 파일명 + 항목 수 + Key·Value 표 | S1 |
| 항목 검색 | 검색어에 맞는 항목만 남는다. 항목 수도 함께 줄어든다 | S2 |
| 검색 결과 없음 | 표에 안내만 남는다. 검색어를 지우면 전체가 돌아온다 | S3 |
| 형식 오류 | 오류 안내 + 빈 표. **창은 닫히지 않는다** | S4 |

### 5.2 메시지

| 상황 | 노출 방식 | 문구 | 화면 |
|---|---|---|---|
| 형식 오류 | 창 안내 | **⚠ JSON 형식의 티켓 파일이 아닙니다. Key 생성으로 내려받은 .json 파일을 선택하세요.** | S4 |
| 검색 결과 없음 | 표 안내 | **"{검색어}" 에 맞는 항목이 없습니다.** | S3 |
| 항목 없음 | 표 안내 | **표시할 항목이 없습니다.** | S4 |

형식 오류가 나도 **창이 닫히지 않아** 바로 다른 파일을 고를 수 있다.
