## 1. 기능 개요

코드를 발급받는 **업체(고객사) 마스터**. 사업자·계좌·서류·편집 단가·업무 이력을 한곳에서 관리한다. **모든 코드 발급과 티켓 발급의 선행 조건**이 되는 화면으로, 여기에 등록되지 않은 업체에는 코드를 할당할 수 없다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN (ADMIN 권장 — §7 협의) |
| 진입 | 좌측 메뉴 [고객사 관리] |
| 성격 | 목록 · 검색 · 등록/수정/삭제 |
| 등록·수정 화면 | `MEM-02` |

---

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [고객사 관리]
   └─▶ MEM-01
         ├─ 구분 필터(전체/상위/하위/단독) · 검색
         ├─ [＋ 고객사 등록] ─▶ MEM-02 (등록 모드)
         ├─ 행 클릭 ──────────▶ MEM-02 (수정 모드 · 업무 원장 MEM-03 포함)
         ├─ 행 [삭제] ─ 이름 입력 확인 ─▶ 프로젝트·코드 reset 후 목록 갱신
         └─ [초기화] ─ 확인 ─▶ 엑셀 시드로 복원
```

---

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-11` 고객사 계층 3분류 | **상위(공통코드 보유) / 하위(공통코드 사용) / 단독** 으로 구분해 필터한다. 하위 고객사도 **정식 회사 레코드**로 목록에 함께 표시된다 |
| `P-12` 공통(커먼) 코드 | 커먼 코드 보유·사용 여부를 목록에서 확인한다 |
| `P-16` 편집 단가 | 고객사별 편집 단가 지정 여부를 목록에서 확인하고, 지정은 `MEM-02`에서 한다 |
| `PC-002` 내부 직원 전용 | 고객이 직접 가입하지 않는다. **직원이 등록**한다 |
| `P-07` SO 공유 불가 | 고객사 = 코드 식별 축이므로, **같은 업체를 중복 등록하지 않는다**(중복 등록 시 코드 소유가 갈라진다) |

## 4. 사용법

### 4.1 검색 · 필터

| 요소 | 동작 |
|---|---|
| 검색 | **업체명·담당자·사업자번호 검색**. `×`로 해제 |
| 구분 필터 | `전체` / `상위 고객사` / `하위 고객사` / `단독 고객사` — 각 건수가 함께 표시된다 |
| [초기화] | 확인 후 엑셀 시드 상태로 복원 |
| 페이지네이션 | `«` `‹` `›` `»` |

### 4.2 목록 항목

No · 업체명 · 담당자 / 연락처 · 사업자번호 · 은행 / 계좌 · 커먼 코드 · 편집 단가 · 주소 · 서류 · 업무 · 작업

| 열 | 설명 |
|---|---|
| 커먼 코드 | 공통코드 보유(상위) 또는 사용(하위) 표시 |
| 편집 단가 | 고객사 전용 단가 지정 여부·요약 |
| 서류 | 등록된 관련 서류 수 |
| 업무 | 업무 원장(요청/처리/메모) 기록 수 |
| 작업 | [삭제] |

**행을 클릭하면 `MEM-02` 수정 화면**이 열린다.

### 4.3 등록

**[＋ 고객사 등록]** → `MEM-02` 등록 모드. 등록 직후 그 고객사는 `SOB-02`(코드 할당)·`TKT-01`(티켓 발급)의 선택 대상이 된다.

### 4.4 삭제

행의 [삭제] → 확인 모달. **삭제하면 그 고객사의 프로젝트와 발급 코드가 reset(회수)** 되므로 **업체명을 정확히 입력해야** 삭제가 확정된다.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 |
|---|---|
| 구분 필터 선택 | 해당 계층만 표시(각 칩에 건수) |
| 프로젝트 종료 업체 | 목록에서 종료 상태로 구분 표시 |
| 검색 결과 없음 | 목록이 비어 있음 |

### 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|
| 등록 완료 | 상단 알림 | **등록됨 · {업체명}** |
| 수정 완료 | 상단 알림 | **수정됨 · {업체명}** |
| 삭제 확정 | 상단 알림 | **삭제됨 · {업체명} · 프로젝트 {n}건 / 코드 {n}건 reset** |
| 초기화 | 확인창 | **테스트 데이터를 초기화할까요? (엑셀 시드로 복원)** |

## 6. 연결 화면

| 트리거 | 이동 | 설명 |
|---|---|---|
| [＋ 고객사 등록] · 행 클릭 | `MEM-02` | 등록 / 수정(업무 원장 `MEM-03` 포함) |
| 코드 할당 | `SOB-01` → `SOB-02` | 등록된 고객사에만 발급 가능 |
| 코드 보유 현황 | `PRJ-01` | 고객사별 코드 프로젝트 |
| 편집 실적·정산 | `PRJ-02` → `PRJ-03` | 편집 단가가 반영된 청구액 |
| 티켓 발급 | `TKT-01` / `TKT-03` | |
| 변경 이력 | `LOG-01` | **고객사 관리** 활동으로 기록 |
