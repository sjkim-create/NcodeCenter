## 1. 기능 개요

**고객사별로 어떤 코드(SOBP)를 얼마나 발급받았는지**를 조회·검색하는 화면. 코드 발급 자체는 `SOB-02`에서 이뤄지므로 **이 화면에는 프로젝트 등록 기능이 없다**(조회·검색 전용). 발급된 코드의 사용 서비스·공유 여부·편집 연결을 확인하는 용도다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 [코드 프로젝트] |
| 성격 | **조회·검색 전용** (등록 없음 / 수정·삭제만 가능) |
| 구성 | 좌: 고객사 목록 · 우: 선택 프로젝트 상세 |

---

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [코드 프로젝트]
   └─▶ PRJ-01
         ├─ 고객사 검색 · 사용 서비스 필터 ─▶ 좌측 목록 축소
         ├─ 고객사 선택 ─▶ 우측 프로젝트 상세
         │     ├─ [✏️ 편집 →] ────────────▶ PRJ-02 (해당 owner의 편집 프로젝트)
         │     ├─ [수정] ─▶ 프로젝트 수정(모달) ─ 저장 ─▶ PRJ-01 갱신
         │     └─ [삭제] ─▶ 삭제 확인(모달) ─ 확정 ─▶ 코드 reset · 목록 갱신
         └─ 코드 신규 발급이 필요하면 ──────▶ SOB-01 → SOB-02
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-13` 사용 서비스 지정 위치 | **여기서는 지정하지 않는다.** 사용 서비스는 `SOB-02`에서 지정하며, 이 화면은 그 결과를 조회·필터한다 (`PC-011`) |
| `PC-011` 등록 제거 | 프로젝트 **신규 등록 기능 없음**. 코드는 `SOB-02`로만 발급된다 |
| `P-14` 편집 = casterN | 사용 서비스가 casterN이거나 편집 실적이 있는 프로젝트에는 **편집 배지**가 붙고 `PRJ-02`로 이동할 수 있다 |
| `P-12` 공통(커먼) 코드 | 공유 코드 프로젝트에는 **공유 코드** 표시와 **사용 고객사(하위) 목록**이 함께 나온다 |
| `P-11` 고객사 계층 | 하위 고객사는 별도 화면이 아니라 이 상세의 사용 고객사 목록에서 확인한다 |
| `P-09` 등급 | 폼솔루션 프로젝트에만 등급이 표시된다 |

## 4. 사용법

### 4.1 좌측 — 고객사 목록

| 요소 | 동작 |
|---|---|
| 사용 서비스 필터 | 서비스별로 좌측 고객사 목록과 프로젝트를 함께 거른다. 기본 = 전체 |
| 고객사 검색 | 업체명으로 검색. `×`로 해제 |
| 목록 항목 | 업체명 · 프로젝트 건수. 사업이 종료된 업체는 **종료** 배지(툴팁에 사유·이관 메모) |
| [초기화] | 확인 후 화면 데이터를 시드 상태로 되돌린다 |

### 4.2 우측 — 프로젝트 상세

| 표시 | 내용 |
|---|---|
| 코드 종류 · S/O 칩 | 프로젝트가 보유한 코드 종류(N/G)와 Section·Owner |
| 사용 서비스 | `SOB-02`에서 지정한 값 |
| 공유 코드 | 여러 고객사가 함께 쓰는 코드일 때 표시 |
| 등급 | 폼솔루션일 때만 |
| ✏️ 편집 | 편집 실적이 있으면 심볼 수와 함께 표시. 클릭 시 `PRJ-02`로 이동. 편집 실적이 다른 owner에 귀속된 예외 건은 **✏️ 편집 → {귀속 대상}** 으로 표시 |
| 발급 요약 4종 | 발급 코드(B×P) · 실등록 페이지 · 편집 심볼 · 코드 종류 |
| 발급 SOBP 내역 | 발급 일자·범위·코드 수 등 (조회 전용, 발급 추가·수정은 이 화면에서 하지 않는다) |

### 4.3 사용 고객사(하위) — 공유 코드일 때

공통(커먼) 코드 프로젝트에는 **사용 고객사 목록**이 표시된다 — *공통(커먼)코드를 함께 쓰는 고객사 · 편집/티켓은 이 대장으로 진행.*

| 요소 | 동작 |
|---|---|
| 하위 고객사 검색 | 이름으로 거른다. 우측에 `표시 수 / 전체 수` |
| 고객사 칩 클릭 | 그 고객사가 **실제로 쓰는 SOBP(Book 단위)와 페이지 합계**를 표시. 다시 누르면 해제 |
| **신규** 배지 | 시드 데이터가 아니라 사용자가 등록한 사용 고객사 |

### 4.4 프로젝트 수정 (모달)

우측 상세의 **[수정]** 으로 연다.

| 항목 | 필수 | 규칙 |
|---|---|---|
| 프로젝트명 | ✔ | |
| 고객사(업체) | ✔ | 등록된 고객사 중 선택 |
| 사용 서비스 | — | 표시·변경 가능하나 **정본 지정은 `SOB-02`** |
| 등급(폼솔루션) | — | 사용 서비스가 폼솔루션일 때만 표시 |
| 발급 SOBP 내역 | — | **조회 전용** — 화면 안내: 발급 추가·수정은 현재 숨김 상태 |

### 4.5 프로젝트 삭제

[삭제] → 확인 모달. **삭제하면 그 프로젝트가 보유한 발급 코드가 reset(회수)** 되므로, **프로젝트명을 정확히 입력해야** [삭제 확정] 버튼이 활성화된다.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 |
|---|---|
| 고객사 미선택 | 우측에 선택 안내 표시 |
| 사용 서비스 = 서비스 없음 | 서비스 태그가 비활성 형태로 표시(모니터링 대상 아님) |
| 공유 코드인데 사용 고객사 없음 | **등록된 사용 고객사가 없습니다.** |
| 종료 업체 | 좌측 목록에 **종료** 배지 |

### 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|
| 프로젝트명 미입력 | 상단 알림 | **프로젝트명은 필수입니다.** |
| 고객사 미선택 | 상단 알림 | **고객사를 선택하세요.** |
| 수정 저장 | 상단 알림 | **수정됨 · {프로젝트명}** |
| 삭제 확정 | 상단 알림 | **삭제됨 · {프로젝트명} · 발급 코드 {n}건 reset** |
| 초기화 | 확인창 | **테스트 데이터를 초기화할까요? (엑셀 시드로 복원)** |

## 6. 연결 화면

| 트리거 | 이동 | 설명 |
|---|---|---|
| [✏️ 편집 →] | `PRJ-02` | 해당 owner의 편집 프로젝트로 이동 |
| 코드 신규 발급 | `SOB-01` → `SOB-02` | 이 화면에서는 발급하지 않는다 |
| 고객사 정보·단가 확인 | `MEM-01` → `MEM-02` | |
| 티켓 발급 | `TKT-01` / `TKT-03` | 발급된 코드로 사용 허가 생성 |
