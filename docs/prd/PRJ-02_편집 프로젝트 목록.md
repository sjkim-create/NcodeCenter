> 문서번호 `NcodeCenter_001_PRD_PRJ02` · 공통 규칙은 [PRD-00](PRD-00_공통.md)
> 포함: **PRJ-05 편집 고객사 추가**(모달, §4.3)

## 1. 기능 개요

**편집(casterN) 대상 고객사 목록** 화면. 좌측에서 고객사를 고르면 우측에 그 고객사의 **편집 프로젝트 상세(`PRJ-03`)** 가 함께 표시된다. 편집량(페이지·심볼)과 정산(청구액)을 고객사 단위로 확인하는 진입점이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 [서비스 관리 ▸ CasterN 서비스 관리 ▸ 편집 프로젝트] · `PRJ-01`의 **[✏️ 편집 →]** |
| 구성 | 좌: 고객사 카드 목록 · 우: `PRJ-03` 상세 |
| 대상 | **편집현황 장부에 있는 업체만** 표시된다 |

---

## 2. 화면 흐름 (Flow)

```
[서비스 관리 ▸ CasterN ▸ 편집 프로젝트]  또는  PRJ-01 [✏️ 편집 →]
   └─▶ PRJ-02
         ├─ 코드 종류 필터 · 고객사/owner 검색
         ├─ 좌측 고객사 선택 ─▶ 우측 PRJ-03 편집 프로젝트 상세
         │                        └─ 교재 행 클릭/추가 ─▶ PRJ-04
         ├─ [＋ 고객사] ─▶ PRJ-05 편집 고객사 추가(모달)
         │                   └─ [추가] ─▶ 목록에 반영 + 그 고객사 선택
         └─ 사용자 추가 항목 [삭제] ─▶ 목록에서 제거
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-14` 편집 = casterN | 이 메뉴가 **casterN 서비스 관리 화면**이다. 편집 실적이 있는 코드가 목록 대상 |
| `P-13` 사용 서비스 | 편집 대상 여부의 정본은 `SOB-02`의 사용 서비스 지정. 이 화면에서 서비스를 바꾸지 않는다 |
| `P-11` 고객사 계층 | 추가할 수 있는 고객사는 **`MEM-01`에 등록된 고객사**뿐이다 |
| `P-16` 정산 단가 | 목록의 금액은 **고객사 단가 기준**으로 계산된다. 단가 지정은 `MEM-02` |
| `P-01` SOBP | 편집 프로젝트는 **Owner 단위**로 관리한다(1 고객사에 Owner 여러 개 가능) |

## 4. 사용법

### 4.1 상단 요약

전체 편집 고객사 수·교재(권) 수와 **고객사 단가 기준** 집계가 표시된다. 필터가 걸리면 *필터 적용 (전체 {n}곳 / {n}권)* 으로 전체 대비 범위를 함께 보여준다.

### 4.2 좌측 — 고객사 목록

| 요소 | 동작 |
|---|---|
| 코드 종류 필터 | `전체` / `PDS2(Gcode)` / `PDS3(Ncode)` — 해당 종류를 보유한 고객사만 표시 |
| 검색 | **고객사 · owner 검색**. `×`로 해제 |
| 표시 수 | `{n}곳 표시` (필터 적용 시 종류 명시) |
| 카드 항목 | 고객사명 · Owner · 보유 권수 |
| 카드 선택 | 우측에 `PRJ-03` 상세 표시 |
| 사용자 추가 항목 [삭제] | 이 화면에서 추가한 항목만 삭제 가능(장부 데이터는 삭제 불가) |

선택한 코드 종류 필터는 **우측 상세에도 그대로 적용**된다.

### 4.3 PRJ-05 · 편집 고객사 추가 (모달)

편집 장부에 없는 고객사를 편집 대상으로 추가한다. **수정 기능은 없다**(추가 전용).

| 항목 | 필수 | 규칙 |
|---|---|---|
| 등록된 고객사 | ✔ | `MEM-01` 등록 고객사 중 선택(가나다 정렬) |
| Owner | ✔ | 그 고객사가 보유한 Owner 목록에서 선택. 목록에 없으면 **직접 입력** |
| 코드 종류 | — | `PDS3(Ncode)` / `PDS2(Gcode)` — 직접 입력할 때 지정 |

[추가]하면 좌측 목록에 반영되고, **같은 고객사·owner가 이미 있으면 새로 만들지 않고 그 항목으로 이동**한다.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 |
|---|---|
| 고객사 미선택 | 우측에 **좌측에서 고객사를 선택하세요.** |
| 검색 결과 없음 | **결과 없음** |
| 필터 적용 | 상단에 전체 대비 표시 범위 안내 |
| 사용자 추가 항목 | 카드에 삭제 가능 표시 |

### 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|
| 고객사 미선택(추가) | 확인창 | **고객사 관리에 등록된 고객사를 선택하세요.** |
| Owner 미선택(추가) | 확인창 | **Owner 코드를 선택하세요. (여러 개면 하나를 고르세요)** |

## 6. 연결 화면

| 트리거 | 이동 | 설명 |
|---|---|---|
| 좌측 고객사 선택 | `PRJ-03` | 같은 화면 우측에 상세 표시 |
| [＋ 고객사] | `PRJ-05`(모달) | 추가 후 이 화면 갱신 |
| 상세의 [＋ 교재(책) 추가] / 교재 행 클릭 | `PRJ-04` | 교재 등록·수정 |
| 고객사 단가 확인·변경 | `MEM-01` → `MEM-02` | 단가는 고객사 관리에서 지정 |
| 코드 발급이 먼저 필요할 때 | `SOB-01` → `SOB-02` | Owner 할당 후 편집 대상 추가 |
