## 1. 기능 개요

교재(책) 1권의 **편집 내역과 정산 근거를 입력**하는 화면. **등록과 수정이 같은 화면**이며 진입 방법으로 모드가 갈린다.

| 진입 | 모드 | 화면 제목 |
|---|---|---|
| `PRJ-03`의 **[＋ 교재(책) 추가]** | 등록 | 교재(책) 추가 |
| `PRJ-03`의 **교재 행 클릭** | 수정 | 교재(책) 편집 수정 |

여기서 입력한 **페이지 수와 심볼·기능 수량이 곧 청구액**이 되므로, 편집팀 작업 기록이자 정산 입력 화면이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 대상 단위 | 교재(책) 1권 = S/O/B 좌표 1개 |

## 2. 화면 흐름 (Flow)

```
PRJ-03
  ├─ [＋ 교재(책) 추가] ─▶ PRJ-04 (등록)
  └─ 교재 행 클릭 ───────▶ PRJ-04 (수정)
                              ├─ 진행 상태 변경(완료 ⇄ 진행중)
                              ├─ [교재 삭제] ─ 확인 ─▶ PRJ-03 목록에서 제거
                              ├─ [취소] ────────────▶ PRJ-03 (변경 없음)
                              └─ [저장] ────────────▶ PRJ-03 (목록·집계·청구액 갱신)
                                        └─▶ LOG-01 (등록=교재 추가 / 수정=교재 작업)
                                        └─▶ 공유 코드면 SOB-01 지도에 사용 고객사·편집 상태 반영
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-16` 정산 = 항목별 단가표 | 심볼·기능을 **항목별 수량**으로 입력하고, 각 항목 단가와 곱해 합산한다 |
| 단가 3단 구조 | 기본 단가 → **고객사 단가(`MEM-02`)** → **이 화면의 할인**(할인율·추가 할인액) |
| `P-12` 공통(커먼) 코드 | 공유 코드 Owner의 교재는 **사용 고객사 입력이 필수** |
| `P-01` SOBP | Book은 **사용 가능한 번호**에서만 고른다. 수정 모드에서는 S/O를 바꿀 수 없다 |
| `P-14` 편집 = casterN | 저장하면 그 Book은 편집 상태가 되어 `SOB-01` 지도에 반영된다 |
| 완료 잠금 규칙 | **완료 처리하려면 ncp2 최종수정 날짜가 필요**하고, 완료 상태에서는 내용이 잠긴다 |

## 4. 사용법

### 4.1 진행 상태

| 상태 | 의미 |
|---|---|
| 진행중 | 편집 작업 중 (기본값) |
| 완료 | 작업 종료 — **내용 잠금** |
| 보류 | 중단·대기 |

- **완료로 바꾸려면 ncp2 최종수정 날짜가 입력돼 있어야 한다.**
- 완료를 해제하면 그때의 ncp2 최종수정 날짜가 **이력으로 보관**되고(해제 시각·해제자 포함), 화면에서 확인할 수 있다.

### 4.2 코드 좌표 · 사용 고객사

| 항목 | 필수 | 규칙 |
|---|---|---|
| 할당된 S / O | ✔ | **등록 모드**에서 할당된 S/O가 여러 개면 선택. **수정 모드에서는 변경 불가** |
| Book | ✔ | **사용 가능한 번호**에서 선택 |
| 사용 고객사 | 공유 코드일 때 ✔ | 공유(커먼) 코드 Owner인 경우에만 표시·필수 |

### 4.3 교재 정보

| 항목 | 필수 | 규칙 |
|---|---|---|
| 교재명 | — | 목록·검색에 표시 |
| ncp2 파일명 | — | |
| ncp2 파일 크기(byte) | — | 서버 저장 용량 파악용 |
| 타입 | — | 소리펜 / 필기펜 등 |
| Start Page | — | 0 이상 |
| Total Page | — | **적용비 계산 기준(페이지 수)** |
| 발급일자(Ncode 발급일) | — | |
| ncp2 최종수정 | 완료 시 ✔ | **완료 처리의 선행 조건** |
| 발급인 | — | 코드 할당자·사용자 명단에서 선택 |
| 펜 모델 | — | 여러 개 선택 가능(추가/삭제) |
| 편집방식 | — | 여러 개 선택 가능(추가/삭제) |

### 4.4 심볼·기능 수량 (정산 근거)

펜 종류에 따라 입력 항목이 갈린다. 각 항목은 **수량 × 단가**로 계산된다.

| 구분 | 입력 항목 |
|---|---|
| **소리펜** | Ncode 편집(기본) · Compound 2~8언어 · 슬롯전환 · 그룹재생 · 게임 · 프롬프트 편집 · RAG 데이터 업로드 · 4도 Ncode 출력 |
| **필기펜** | none 편집비용 · Custom · action 변경 편집 · 노트서버 업로드 · 교원구몬/KEP |

> 페이지 단위 **Ncode 적용**은 Total Page로 자동 계산되므로 별도 수량을 입력하지 않는다.
> 단가 값의 정본은 정책(`P-16`)이며, 고객사별 단가는 `MEM-02`에서 지정한다.

### 4.5 정산 (교재 단위 조정)

**적용 단가** — 이 교재에 적용된 단가가 배지로 표시된다.

| 표시 | 의미 |
|---|---|
| **등록 시 단가 ({날짜})** | 저장 시점의 고객사 단가로 **고정**된 상태. 이후 고객사 단가가 바뀌어도 이 교재는 그대로 |
| **고객사 단가 / 기본 단가** | 아직 고정 전(신규 교재 또는 단가 이력이 없는 구 교재). **저장하면 현재 단가로 고정**된다 |
| **⚠ 고객사 단가 변경됨 — 현재 단가로 갱신** | 고정된 단가와 현재 고객사 단가가 다를 때만 표시. 누르면 확인 후 **이 교재만** 현재 단가로 다시 계산한다 |

| 항목 | 규칙 |
|---|---|
| 할인율(%) | 합계(할인 전) 기준 |
| 추가 할인액(₩) | 정액 차감 |
| 할인 사유 | 예) 재작업분 · 물량 협의 |
| [할인 초기화] | 할인 없음으로 되돌린다 |

산출 근거가 **적용비(페이지) → 편집·기능비 → 합계(할인 전) → 할인율 → 추가 할인액 → 청구액** 순으로 표시된다.
