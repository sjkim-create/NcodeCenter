## 1. 기능 개요

발급된 티켓 1건에 **과금 유형(유료 / 무료 / 체험 / 미정)과 금액·사유를 등록**한다. 업체·티켓마다 다르게 등록할 수 있으며, 등록 결과는 `TKT-04` 목록과 상단 정산 요약에 즉시 반영된다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | `TKT-04` 발급 목록 행의 **[정산 등록]** |
| 대상 | 티켓 1건 (모달 제목에 발급 번호 표시) |

---

## 2. 화면 흐름 (Flow)

```
TKT-04 발급 목록 ─ 행 [정산 등록] ─▶ TKT-05
                                      ├─ [취소] ──────▶ TKT-04 (변경 없음)
                                      └─ [저장] ──────▶ TKT-04 (정산·금액·비고 갱신)
                                                        └─▶ LOG-01 활동 로그 기록(티켓 발급)
```

---

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-15` 정산(과금) = 유료 / 무료 / 체험 / 미정 | 4가지 중 하나를 반드시 선택. 기본은 현재 등록된 값 |
| `PC-016` 티켓 발급 모델 | 정산은 **티켓 단위**로 등록한다(고객사 단위 일괄 등록 아님) |
| 체험 기준 | 체험 기본 기간 = **발급일 + 1개월** |
| `P-16` 편집 정산과 분리 | 편집 청구액(`PRJ-03`)과 별개 항목. 상호 합산하지 않는다 |

## 4. 사용법

### 4.1 대상 티켓 확인

모달 상단에 대상 티켓의 **고객사 · 종류(N Key/App Key) · 발급일시 · 발급 내용**이 표시된다. 잘못 열었으면 [취소]로 닫는다.

### 4.2 과금 유형 선택

| 유형 | 보조 설명 | 추가 입력 |
|---|---|---|
| **유료** | 금액 입력 | 금액(원) **필수** |
| **무료** | 청구 없음 | 없음(사유는 비고에 기록) |
| **체험** | 1개월 | 체험 만료일(기본 = 발급일 + 1개월) |
| **미정** | 미등록 | 없음 |

### 4.3 입력 항목 · 검증

| 항목 | 필수 | 규칙 |
|---|---|---|
| 과금 유형 | ✔ | 4종 중 1개 |
| 금액(원) | 유료일 때 ✔ | 0보다 커야 한다. 같은 고객사의 **최근 유료 금액**이 함께 표시되며 **[같은 금액 적용]** 으로 그대로 가져올 수 있다 |
| 체험 만료일 | 체험일 때 | 기본값 = 발급일 + 1개월. 날짜 변경 가능 |
| 비고(사유·계약 정보) | — | 예) 2026 연간 계약 포함 · 데모 제공 |

### 4.4 저장

[저장]하면 모달이 닫히고 `TKT-04` 목록의 **정산·금액·비고**가 갱신된다. 이미 등록한 이력이 있으면 모달 하단에 **최근 등록 시각과 등록자**가 표시된다.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 |
|---|---|
| 유료 선택 | 금액 입력 항목 표시. 같은 고객사의 최근 유료 금액이 있으면 참고 표시 + [같은 금액 적용] |
| 무료 선택 | 안내 문구 **청구하지 않는 티켓으로 기록됩니다. (사유는 아래 비고에 남겨 주세요)** |
| 체험 선택 | 만료일 입력 + 안내 **만료되면 목록에서 (만료)로 표시되고 상단에 경고가 뜹니다.** |
| 미정 선택 | 추가 입력 없음. `TKT-04` 상단 **정산 미등록** 건수에 포함된 상태 유지 |
| 재등록 | 하단에 **최근 등록: {일시} · {등록자}** 표시 |

### 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|
| 유료인데 금액 미입력·0 | 확인창 | **유료는 금액을 입력해야 합니다.** |

## 6. 연결 화면

| 트리거 | 이동 | 설명 |
|---|---|---|
| [저장] | `TKT-04` | 목록 갱신 후 복귀 |

| 저장(자동) | `LOG-01` | **정산 등록 · {고객사} · 발급 {No}번 · {유형}** 으로 활동 기록 |
| 고객사 기준 단가 확인 | `MEM-01` → `MEM-02` | 고객사별 편집 단가는 별도 항목(코드 라이선스 금액과 다름) |

## 7. 미결 · 협의

- [ ] **코드 라이선스 단가 기준표** — 현재는 티켓마다 금액을 직접 입력. 고객사·물량 기준 단가표를 둘지 (사업팀 협의)
- [ ] 체험 → 유료 **전환 이력**을 남길지(현재는 최신 상태만 보관)
