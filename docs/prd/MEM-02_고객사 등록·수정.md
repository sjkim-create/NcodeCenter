## 1. 기능 개요

고객사의 **기본 정보 · 공통코드 귀속 · 편집 단가 · 관련 서류**를 입력한다. **등록과 수정이 같은 화면**이며 진입 방법으로 모드가 갈린다.

| 진입 | 모드 | 표시 |
|---|---|---|
| `MEM-01`의 **[＋ 고객사 등록]** | 등록 | 기본 정보만 (업무 원장 없음) |
| `MEM-01`의 **행 클릭** | 수정 | 좌: 기본 정보 · 우: **업무 원장(MEM-03)** |

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN (ADMIN 권장 — §7) |
| 저장 결과 | `MEM-01` 목록 갱신 · `LOG-01`에 **고객사 관리** 활동 기록 |

---

## 2. 화면 흐름 (Flow)

```
MEM-01 ─ [＋ 고객사 등록] ─▶ MEM-02 (등록)
       └ 행 클릭 ─────────▶ MEM-02 (수정) ─ 우측 MEM-03 업무 원장
                                 ├─ [취소] ─▶ MEM-01 (변경 없음)
                                 └─ [저장] ─▶ MEM-01 (목록 갱신)
                                             └─▶ LOG-01 활동 기록
등록 완료 후 코드가 필요하면 ─▶ SOB-01 → SOB-02
편집 단가 변경은 ─────────────▶ PRJ-03 청구액에 즉시 반영
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-11` 고객사 계층 | 공통코드를 **사용**하도록 체크하면 그 고객사는 **하위 고객사**가 된다. **대표(상위) 회사는 자기 코드의 하위가 될 수 없어** 해당 항목이 비활성으로 표시된다 (`PC-015`) |
| `P-12` 공통(커먼) 코드 중앙 모델 | 하위 등록은 **이미 발급된 공통코드를 함께 쓰는 것**이므로 **코드 할당이 발생하지 않는다** |
| `P-16` 정산 단가 | 편집 단가는 **2026 항목별 단가표** 기준. **기본값에서 바꾼 항목만 이 고객사 전용 단가**가 된다 |
| 단가 3단 구조 | 기본 단가 → **이 화면의 고객사 단가** → 교재별 할인(`PRJ-04`) |
| 프로젝트 종료 | 사업이 끝난 고객사는 **종료**로 표시하고 사유·이관 메모를 남긴다(코드 발급 이력은 보존) |

## 4. 사용법

### 4.1 기본 정보

| 항목 | 필수 | 규칙 |
|---|---|---|
| 업체명 | ✔ | 코드·프로젝트가 이 이름으로 연결된다 |
| 담당자 | — | |
| 연락처 | — | |
| 사업자등록증번호 | — | 형식 예: `000-00-00000` |
| 주소 | — | `TKT-03` 계정 등록 시 기본 주소로 사용된다 |
| 은행명 / 계좌번호 | — | 정산 지급용 |
| 세금계산서 발행용 이메일 | — | 예: `tax@company.com` |

### 4.2 프로젝트 상태

| 값 | 의미 |
|---|---|
| 진행 | 정상 거래 중 |
| 종료 | 사업 정리. **종료 사유 / 코드 이관 메모**를 남긴다 (예: 엠베스트-28로 코드 이관) |

### 4.3 공통코드 사용 고객사(하위) 등록

*대표 회사 아래로 귀속 · 코드 할당 불필요*

- 사용할 공통코드를 체크하면 이 고객사가 그 **공통코드의 사용 고객사(하위)** 로 등록된다.
- 안내: 이미 발급된 공통코드를 쓰므로 **코드 할당은 없고**, 편집 프로젝트·티켓 발급에서 하위 고객사로 관리된다.
- **자기 회사가 보유한 코드는 선택할 수 없다**(비활성).

### 4.4 편집 단가 (2026 항목별)

*기본값에서 바꾼 항목만 전용 단가*

| 요소 | 동작 |
|---|---|
| 항목별 단가 입력 | 소리펜·필기펜 각 항목(적용·편집·Compound·슬롯전환·그룹재생·게임·프롬프트·RAG·4도출력 / none·Custom·action·노트서버·교원구몬KEP)에 단가를 지정. 항목마다 단위(페이지·심볼·건)가 표시된다 |
| 전용 항목 수 | 기본값과 다른 항목이 있으면 **전용 {n}항목** 배지 |
| [전체 기본값] | 모든 항목을 기본 단가로 되돌린다 |

안내: **편집 프로젝트의 청구액이 이 단가로 계산됩니다(항목 수량 × 단가). 교재별 할인은 편집 프로젝트 > 교재 수정에서.**

### 4.5 관련 서류

| 요소 | 동작 |
|---|---|
| 항목명 | 서류 이름을 직접 입력 |
| 파일 | 파일 등록 |
| [삭제] | 해당 서류 행 제거 |

### 4.6 MEM-03 · 업무요청 메모 (수정 모드 전용)

고객사와 주고받은 요청·처리 내역을 남기는 **업무 원장**. **수정 모드에서만** 우측에 표시된다(등록 시에는 없음).

| 요소 | 동작 |
|---|---|
| 종류 | **요청 / 처리 / 메모** |
| 입력 | **Enter 기록 · Shift+Enter 줄바꿈** |
| 수정·삭제 | **본인이 작성한 메모만** 가능 |
| 표시 | 작성자·작성 시각과 함께 시간순 |

## 5. 상태별 변화 · 메시지

| 상태 | 화면 |
|---|---|
| 등록 모드 | 기본 정보 1단. 업무 원장 없음 |
| 수정 모드 | 좌(기본 정보) / 우(업무 원장 `MEM-03`) 2단 |
| 대표(상위) 회사 수정 중 | 자기 공통코드 항목 **비활성** |
| 전용 단가 지정됨 | **전용 {n}항목** 배지 · `PRJ-03`에서 **고객사 단가** 기준으로 계산 |
| 전용 단가 없음 | `PRJ-03`에서 **기본 단가**로 계산 |
| 프로젝트 종료 선택 | 종료 사유·이관 메모 입력란 노출 |

### 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|

| 등록 저장 | 상단 알림 | **등록됨 · {업체명}** |
| 수정 저장 | 상단 알림 | **수정됨 · {업체명}** |
| 남의 메모 수정 시도 | 상단 알림 | **{작성자} 님이 작성한 메모입니다. 본인 글만 수정할 수 있습니다.** |
| 남의 메모 삭제 시도 | 상단 알림 | **{작성자} 님이 작성한 메모입니다. 본인 글만 삭제할 수 있습니다.** |
| 본인 글 확인 실패 | 상단 알림 | **본인이 작성한 메모만 수정할 수 있습니다.** |
| 메모 삭제 | 확인창 | **메모 {No}번을 삭제할까요?** |
