## 1. 기능 개요

고객사의 **기본 정보 · 공통코드 귀속 · 편집 단가 · 관련 서류**를 입력한다. **등록과 수정이 같은 화면**이며 진입 방법으로 모드가 갈린다.

| 진입 | 모드 | 표시 |
|---|---|---|
| `MEM-01`의 **[＋ 고객사 등록]** | 등록 | 기본 정보만 (업무 원장 없음) |
| `MEM-01`의 **행 클릭** | 수정 | 좌: 기본 정보 · 우: **업무 원장(MEM-03)** |

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN (ADMIN 권장 — §7) |
| 저장 결과 | `MEM-01` 목록 갱신 · `LOG-01`에 **고객사 관리** 활동 기록 |

## 2. 화면 흐름 (Flow)

```
MEM-01 ─ [＋ 고객사 등록] ─▶ MEM-02 (등록)
       └ 행 클릭 ─────────▶ MEM-02 (수정) ─ 우측 MEM-03 업무 원장
                                 ├─ [취소] ─▶ MEM-01 (변경 없음)
                                 └─ [저장] ─▶ MEM-01 (목록 갱신)
                                             └─▶ LOG-01 활동 기록
등록 완료 후 코드가 필요하면 ─▶ SOB-01 → SOB-02
편집 단가 변경은 ─────────────▶ 이후 등록되는 교재(PRJ-04)부터 적용 · 기존 교재는 유지
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-11` 고객사 계층 | 공통코드를 **사용**하도록 체크하면 그 고객사는 **하위 고객사**가 된다. **대표(상위) 회사는 자기 코드의 하위가 될 수 없어** 해당 항목이 비활성으로 표시된다 (`PC-015`) |
| `P-12` 공통(커먼) 코드 중앙 모델 | 하위 등록은 **이미 발급된 공통코드를 함께 쓰는 것**이므로 **코드 할당이 발생하지 않는다** |
| `P-16` 정산 단가 | 편집 단가는 **2026 항목별 단가표** 기준. **기본값에서 바꾼 항목만 이 고객사 전용 단가**가 된다 |
| `PC-027` 단가 적용 시점 | 단가는 **고객사마다 등록·수정**할 수 있고, 변경은 **이후 등록되는 교재(책)부터 적용**된다. **기존 교재는 등록 당시 단가를 그대로 유지**한다(소급 적용 없음) |
| 단가 3단 구조 | 기본 단가 → **이 화면의 고객사 단가** → 교재별 할인(`PRJ-04`) |
| 프로젝트 종료 | 사업이 끝난 고객사는 **종료**로 표시하고 사유·이관 메모를 남긴다(코드 발급 이력은 보존) |

## 4. 사용법

### 4.1 기본 정보

| 항목 | 필수 | 규칙 |
|---|---|---|
| 업체명 | ✔ | 코드·프로젝트가 이 이름으로 연결된다 |
| 담당자 | — | |
| 연락처 | — | |
| 사업자등록증번호 | — | 형식 예: `000-00-00000` |
| 주소 | — | `TKT-01` 계정 등록 시 기본 주소로 사용된다 |
| 은행명 / 계좌번호 | — | 정산 지급용 |
| 세금계산서 발행용 이메일 | — | 예: `tax@company.com` |

### 4.2 프로젝트 상태 (S6)

**토글 스위치**로 전환한다. 켜면 붉은색으로 바뀐다.

| 값 | 의미 |
|---|---|
| **진행중** | 정상 거래 중 (기본값) |
| **사업 종료** | 사업 정리. 아래에 **종료 사유 / 코드 이관 메모** 입력란이 나타난다 (예: 엠베스트-28로 코드 이관) |

> 안내: *사업 종료 시 코드 발급 이력만 유지되고, 목록·코드 프로젝트에서 비활성(회색)으로 표시됩니다.*

### 4.3 공통코드 사용 고객사(하위) 등록

*대표 회사 아래로 귀속 · 코드 할당 불필요*

- 사용할 공통코드를 체크하면 이 고객사가 그 **공통코드의 사용 고객사(하위)** 로 등록된다.
- 안내: 이미 발급된 공통코드를 쓰므로 **코드 할당은 없고**, 편집 프로젝트·티켓 발급에서 하위 고객사로 관리된다.
- **자기 회사가 보유한 코드는 선택할 수 없다**(비활성).

### 4.4 편집 단가 (2026 항목별)

*기본값에서 바꾼 항목만 전용 단가*

**🔊 소리펜 16항목 · ✍ 필기펜 6항목**을 각각 **2열**로 늘어놓고 값을 직접 입력한다. 두 그룹 모두 맨 위에 **Ncode 적용(페이지당)** 이 들어간다. (S5)

| 요소 | 동작 |
|---|---|
| 항목별 단가 입력 | 항목마다 **단위**(페이지당 / 심볼당 / 건당)가 함께 표시된다 |
| 기본값과 다른 항목 | 항목명이 **주황 굵게**, 입력칸도 **주황 테두리·연노랑 배경**으로 바뀐다 |
| 전용 항목 수 | 기본값과 다른 항목이 있으면 **전용 {n}항목** 배지 |
| [전체 기본값] | 모든 항목을 기본 단가로 되돌린다 |

전사 기본 단가(원)

| 🔊 소리펜 | 단가 | ✍ 필기펜 | 단가 |
|---|---|---|---|
| Ncode 적용 (페이지당) | 500 | Ncode 적용 (페이지당) | 500 |
| Ncode 편집(기본) (심볼당) | 1,000 | none 편집비용 (심볼당) | 1,000 |
| Compound 2 / 3 / 4언어 | 1,300 / 1,600 / 1,900 | Custom (심볼당) | 1,000 ⚠ |
| Compound 5 / 6 / 7 / 8언어 | 2,200 / 2,500 / 2,800 / 3,100 | action 변경 편집 (심볼당) | 1,500 |
| 슬롯전환 / 그룹재생 (건당) | 3,000 / 5,000 | 노트서버 업로드 (건당) | 10,000 |
| 게임 / 프롬프트 편집 / RAG 데이터 업로드 (건당) | 각 50,000 | 교원구몬/KEP (건당) | 1,000 ⚠ |
| 4도 Ncode 출력 (페이지당) | 1,000 | | |

> ⚠ **Custom · 교원구몬/KEP** 단가는 미확정(`PC-018` 확인 대기).

안내: **편집 프로젝트의 청구액이 이 단가로 계산됩니다(항목 수량 × 단가). 단가를 바꾸면 이후 등록되는 교재(책)부터 적용되고, 기존 교재는 등록 당시 단가가 그대로 유지됩니다. 교재별 할인은 편집 프로젝트 > 교재 수정에서.**

**단가 변경의 영향 범위**

| 대상 | 적용 |
|---|---|
| 이 화면에서 단가 저장 후 **새로 등록하는 교재** | **새 단가**로 계산 |
| 이미 등록된 교재 | **등록 당시 단가 유지** — 청구액이 바뀌지 않는다 |
| 기존 교재를 새 단가로 바꾸고 싶을 때 | `PRJ-04` 교재 수정에서 **[현재 단가로 갱신]** 을 눌러 개별 적용 |

### 4.5 관련 서류

| 요소 | 동작 |
|---|---|
| [＋ 서류 추가] | 행을 하나 추가한다 |
| 항목명 | 서류 이름을 직접 입력(항목명 자체를 바꿀 수 있다) |
| 파일 | 파일 등록. 고르기 전에는 **선택 없음** |
| [삭제] | 해당 서류 행 제거 |
| 서류 없음 | **등록된 서류가 없습니다.** |

### 4.6 MEM-03 · 업무요청 메모 (수정 모드 전용)

고객사와 주고받은 요청·처리 내역을 남기는 **업무 원장**. **수정 모드에서만** 우측에 표시된다(등록 시에는 없음).

| 요소 | 동작 | 화면 |
|---|---|---|
| 대상 | **고객사 공통** 또는 그 고객사의 **프로젝트**를 골라 기록한다 | S7 |
| 종류 | **요청 / 처리 / 메모** | S7 |
| 입력 | **Enter 기록 · Shift+Enter 줄바꿈** | S7 |
| 기록 목록 | 번호 · **대상 배지**(공통은 회색, 프로젝트는 파랑) · 종류 배지 · 작성일시(수정하면 **(수정됨)**) · 작성자(본인이면 **(나)** 파랑) | S2 |
| 본인 글 | 클릭하면 위 입력칸에서 수정 — 버튼이 **[수정 저장] · [취소]** 로 바뀐다. **[삭제]** 가능 | S7 |
| 타인 글 | **🔒 타인 글** 로 표시되고 수정·삭제할 수 없다 | S8 |
| 기록 없음 | **기록된 업무가 없습니다.** | S1 |

## 5. 상태별 변화 · 메시지

| 상태 | 화면 | 화면 번호 |
|---|---|---|
| 등록 모드 | 제목 **고객사 등록** · **1단**(좁은 창) · 업무 원장 없음 · 버튼 **[취소] / [등록]** | S1 |
| 수정 모드 | 제목 **고객사 수정** · 좌(기본 정보) / 우(업무 원장 `MEM-03`) **2단**(넓은 창) · 버튼 **[닫기] / [저장]** | S2 |
| 업체명 미입력 | 저장이 막히고 상단 알림 | S3 |
| 대표(상위) 회사 수정 중 | 자기 공통코드 항목 **비활성**(회색·체크 불가) | S4 |
| 전용 단가 지정됨 | **전용 {n}항목** 배지 · 바꾼 항목이 주황으로 강조 · `PRJ-03`에서 **신규 교재**부터 이 단가로 계산 | S5 |
| 전용 단가 없음 | 배지 없음 · `PRJ-03`에서 **기본 단가**로 계산 | S1 |
| 프로젝트 종료 선택 | 토글이 붉게 바뀌고 종료 사유·이관 메모 입력란 노출 | S6 |
| 메모 수정 중 | 해당 기록이 파랗게 표시되고 버튼이 **[수정 저장] / [취소]** 로 | S7 |
| 타인 글 | **🔒 타인 글** | S8 |

**저장하면 창이 닫히고 목록(`MEM-01`)으로 돌아간다.**
