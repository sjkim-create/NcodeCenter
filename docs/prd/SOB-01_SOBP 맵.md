## 1. 기능 개요

**Section → Owner → Book → Page** 를 단계별로 좁혀 들어가며 **어떤 코드가 누구에게 발급되어 있고, 어디가 비어 있는지**를 확인하는 코드 지도다. 신규 발급 대상 좌표를 여기서 고른 뒤 `SOB-02`로 할당한다. 코드 발급 업무의 출발점 화면이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 [SOBP 맵] |
| 성격 | 조회 + 발급 대상 선택. **실제 할당은 `SOB-02`에서 수행** |

---

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [SOBP 맵]
   └─▶ SOB-01
         ① 코드 종류 선택 (PDS3(Ncode) / PDS2(Gcode))
         ② 상태 필터 · 고객사 검색으로 범위 좁히기
         ③ SECTION ─▶ OWNER ─▶ BOOK ─▶ PAGE 드릴다운
         └─ [＋ 직접 코드 할당] ─▶ SOB-02 (현재 선택한 Section·Owner가 발급 대상)
                                    └─ 할당 완료 ─▶ SOB-01 로 복귀(선택 Book 갱신)
```

고객사명을 검색창에 정확히 입력하거나 목록에서 고르면 **그 고객사가 보유한 첫 S/O/B 위치로 지도가 자동 이동**한다.

---

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-05` 무겹침 | 이미 발급된 좌표는 상태·고객사명으로 드러나며, 그 위에 겹쳐 발급할 수 없다(`SOB-02`에서 차단) |
| `P-07` SO 공유 불가 | Section·Owner는 고객사 식별 축. 다른 고객사가 쓰는 S/O에는 발급할 수 없고, **공유(커먼) 코드로 지정된 Owner만 예외** |
| `P-02` 코드 종류 N/G | PDS3(Ncode)·PDS2(Gcode)를 탭으로 분리해 본다. **같은 S/O는 둘 중 한쪽만** 사용할 수 있으며, 반대쪽이 선점한 Owner는 **🚫 영역 할당됨**으로 표시된다 |
| `P-04` 코드 상태 | 상태는 **코드 발급 / 코드 미발급** 기준. 발급된 코드 안에서 **편집 / 공유 / 사용가능**을 세분해 보여준다 |
| `P-12` 공통(커먼) 코드 | 공유 Owner는 발급 여부와 무관하게 항상 **공유**로 표기하고, 사용 고객사를 함께 보여준다 |
| 테스트/개발 섹션 | PDS2 S0·S14는 상용 미출시 → **추천제외** 배지. 자동 추천에서는 빠지지만 직접 선택은 가능 |

## 4. 사용법

### 4.1 상단 도구

| 요소 | 동작 |
|---|---|
| 코드 종류 | `PDS3(Ncode)` / `PDS2(Gcode)` — 전환하면 Section 목록이 해당 종류 기준으로 다시 그려지고 선택이 초기화된다 |
| 상태 필터 | `전체` / `코드 발급` / `코드 미발급` / `편집` / `공유` / `사용가능` |
| 고객사 검색 | 비우면 전체. 목록에서 고르거나 정확히 입력하면 **해당 고객사 좌표로 이동**, 부분 입력이면 필터로만 동작 |
| 범례 | 코드발급 · 편집 · 사용가능 · 공유 · 미사용 |

상태 필터의 의미

| 필터 | 의미 |
|---|---|
| 코드 발급 | 발급(할당)된 코드 전체 (편집·공유·사용가능 포함) |
| 코드 미발급 | 아직 발급되지 않은 빈 코드 |
| 편집 | 발급된 코드 중 실제 편집에 쓰인 코드 |
| 공유 | 여러 고객사가 함께 쓰도록 지정된 OWNER |
| 사용가능 | 공유(커먼) 코드 중 아직 편집하지 않은 것 |

### 4.2 발급 대상 선택

도구 아래에 **[＋ 직접 코드 할당]** 버튼과 **발급 대상(현재 선택한 S/O)** 이 함께 표시된다 — *위에서 고른 Section·Owner에 코드를 발급합니다.*

### 4.3 드릴다운 4단

| 단계 | 표시 정보 | 조작 |
|---|---|---|
| **SECTION** | Section 번호, `사용 owner {n} / {전체}`, 추천제외 배지 | 클릭 → 하위 선택 초기화 |
| **OWNER** | Owner 번호, 상태 배지(공유 / 🚫 영역 할당됨 / 코드 상태), 보유 고객사명, 언어 슬롯 표기 | 클릭 → Book 목록 갱신 |
| **BOOK** | Book 번호, 상태, 사용 고객사·교재명 | 클릭 → Page 목록 갱신 |
| **PAGE** | 선택한 Book의 페이지 상태 | 조회 |

목록 조작

| 기능 | 동작 |
|---|---|
| 번호 점프(`O`·`B` 입력) | 입력한 번호부터 이후 목록만 표시. `✕`로 해제 |
| [＋ 더 보기] | 다음 묶음을 이어서 표시(남은 개수 함께 표시). 스크롤로도 이어 로드 |
| 필터로 결과가 없을 때 | **S{n} 에는 {필터} 에 해당하는 Owner가 없습니다.** + [필터 해제] |
| 상위 선택 변경 | 현재 선택이 목록에서 사라지면 첫 항목으로 자동 이동 |

## 5. 상태별 변화 · 메시지

| 표시 | 의미 |
|---|---|
| **공유** | 공유(커먼) 코드로 지정된 Owner. 툴팁으로 공유 사유·범위 안내 |
| **🚫 영역 할당됨** | 반대 코드 종류(PDS3↔PDS2)가 이 Owner를 선점 — 현재 종류에서는 사용 불가 |
| **코드발급 / 편집 / 사용가능 / 미사용** | 코드 상태 배지 |
| **추천제외** | 테스트/개발 전용 Section (자동 추천 제외, 직접 선택 가능) |
| 사용 고객사 표기 | 공유 코드는 **실사용 고객사**만 표시한다(대표 오너명으로 대체 표기하지 않음) |
| 결과 없음 | **결과 없음** 또는 필터 안내 문구 + [필터 해제] |

이 화면 자체에는 저장 동작이 없어 검증 메시지가 없다. 할당 관련 메시지는 `SOB-02`.
