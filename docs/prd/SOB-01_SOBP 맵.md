## 1. 기능 개요

**Section → Owner → Book → Page** 를 단계별로 좁혀 들어가며 **어떤 코드가 누구에게 발급되어 있고, 어디가 비어 있는지**를 확인하는 코드 지도다. 신규 발급 대상 좌표를 여기서 고른 뒤 `SOB-02`로 할당한다. 코드 발급 업무의 출발점 화면이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 [SOBP 맵] |
| 성격 | **조회 전용**. 이 화면 자체에는 저장 동작이 없다 |
| 발급 | **[＋ 직접 코드 할당]** 을 누르면 `SOB-02` 가 **이 화면 위에 창으로** 열린다 |

---

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [SOBP 맵]
   └─▶ SOB-01
         ① 코드 종류 선택 (PDS3(Ncode) / PDS2(Gcode))
         ② 상태 필터 · 고객사 검색으로 범위 좁히기
         ③ SECTION ─▶ OWNER ─▶ BOOK ─▶ PAGE 드릴다운
         └─ [＋ 직접 코드 할당] ─▶ SOB-02 (현재 선택한 Section·Owner가 발급 대상)
                                    └─ 할당 완료 ─▶ SOB-01 (지도 갱신 · 선택 Book 초기화)
```

고객사명을 검색창에 정확히 입력하거나 목록에서 고르면 **그 고객사가 보유한 첫 S/O/B 위치로 지도가 자동 이동**한다.

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-05` 무겹침 | 이미 발급된 좌표는 상태·고객사명으로 드러나며, 그 위에 겹쳐 발급할 수 없다(`SOB-02`에서 차단) |
| `P-07` SO 공유 불가 | Section·Owner는 고객사 식별 축. 다른 고객사가 쓰는 S/O에는 발급할 수 없고, **공유(커먼) 코드로 지정된 Owner만 예외** |
| `P-02` 코드 종류 N/G | PDS3(Ncode)·PDS2(Gcode)를 나눠서 본다. **같은 S/O는 둘 중 한쪽만** 쓸 수 있으며, 반대쪽이 선점한 Owner는 **🚫 영역 할당됨**으로 표시된다 |
| `P-04` 코드 상태 | 상태는 **코드 발급 / 코드 미발급** 기준. 발급된 코드 안에서 **편집 / 공유 / 사용가능**을 세분해 보여준다 |
| `P-12` 공통(커먼) 코드 | 공유 Owner는 발급 여부와 무관하게 항상 **공유**로 표기하고, 사용 고객사를 함께 보여준다 |
| 테스트/개발 섹션 | **PDS2 S0·S14** 는 상용 미출시 → **추천제외** 배지. 직접 선택은 가능. **PDS3에는 추천제외 Section이 없다** |

## 4. 사용법

### 4.1 상단 도구

| 요소 | 동작 | 화면 |
|---|---|---|
| 코드 종류 | `PDS3(Ncode)` / `PDS2(Gcode)` — 전환하면 Section 목록이 다시 그려지고 **아래 선택·번호 점프·더 보기가 모두 초기화**된다 | S1 · S2 |
| 상태 필터 | `전체` / `발급 전체` / `코드 미발급` / `편집` / `공유` / `사용가능` | S1 · S3 · S4 · S5 · S6 · S7 |
| 고객사 검색 | 비우면 전체. 목록에서 고르거나 정확히 입력하면 **해당 고객사 좌표로 이동**, 부분 입력이면 필터로만 동작 | S8 |
| 범례 | 코드발급 · 편집 · 사용가능 · 공유 · 코드 미발급 | S1 |

상태 필터의 의미 (표기는 화면 그대로)

| 화면 표기 | 의미 | 화면 |
|---|---|---|
| 전체 | 필터 없음 | S1 |
| 발급 전체 | 발급(할당)된 코드 전체 (편집·공유·사용가능 포함) | S3 |
| 코드 미발급 | 아직 발급되지 않은 빈 코드 | S4 |
| 편집 | 발급된 코드 중 실제 편집에 쓰인 코드 | S5 |
| 공유 | 여러 고객사가 함께 쓰도록 지정된 OWNER | S6 |
| 사용가능 | 공유(커먼) 코드 중 아직 편집하지 않은 것 | S7 |

> 필터는 Section·코드 종류를 바꿔도 유지된다. 결과가 비면 §4.5의 안내가 나온다.

### 4.2 발급 대상 선택 (S1)

도구 아래에 **[＋ 직접 코드 할당]** 버튼과 **발급 대상(현재 선택한 S/O)** 이 함께 표시된다 — *위에서 고른 Section·Owner에 코드를 발급합니다.*

### 4.3 드릴다운 4단

| 단계 | 표시 정보 | 조작 | 화면 |
|---|---|---|---|
| **SECTION** | Section 번호, `사용 owner {n} / {정원}`, 추천제외 배지 | 클릭 → 하위 선택 초기화 | S1 · S2 |
| **OWNER** | Owner 번호, 상태 배지(공유 / 🚫 영역 할당됨 / 코드 상태), 보유 고객사명, 언어 슬롯(🌐) | 클릭 → Book 목록 갱신 | S12 |
| **BOOK** | Book 번호, 상태, 사용 고객사·교재명. **반대 코드 종류가 발급한 Book은 선택할 수 없다** | 클릭 → Page 용량 갱신 | S13 |
| **PAGE** | **Page 용량 맵** — §4.4 | 조회 | S14 · S15 · S17 |

Section 목록

| 코드 종류 | Section |
|---|---|
| PDS3(Ncode) | 0 · 3 · 5 · 10 · 11 · 14 · 15 |
| PDS2(Gcode) | 0 · 3 · 14 — **S0 · S14 = 추천제외** |

언어 슬롯(🌐)은 **PDS2의 S3** 에서만 표시된다. 값은 db에서 직접 관리한다.

### 4.4 PAGE — 용량 맵

선택한 Book의 페이지를 **얼마나 쓰고 있는지** 보여주는 조회 전용 영역이다.

요약 4종

| 항목 | 의미 |
|---|---|
| 전체 | 이 Section이 Book 하나에 줄 수 있는 최대 페이지 |
| 권장 | 운영 권장 사용량 **1,000p** (전체 용량이 더 작으면 전체가 상한) |
| 실 사용 | 실제 편집·발급에 쓰인 페이지 |
| 잔여 (발급 가능) | 전체 − 실 사용 |

막대 3종

- **전체** — 100% 기준
- **권장** — 전체 대비 권장 비율
- **실 사용** — **두 줄**로 나눠 표시한다(권장 기준 / 실제 사용). 실제 사용이 권장을 넘으면 **넘은 구간이 빗금**으로 그려지고 범례에 **⚠ 초과 +{n}p** 가 붙는다

각 막대에 마우스를 올리면 수치 안내가 뜬다 (S17).

| 상황 | 화면 | 화면 번호 |
|---|---|---|
| 사용 중 | 고객사 · 프로젝트 · 교재 · **사용 구간** 을 함께 표시 | S1 |
| 사용 중 아님 | **미사용 (발급 가능) — 이 S/O/B에는 사용 중인 프로젝트가 없습니다.** · 실 사용 0p · 사용 구간 줄 없음 | S14 |
| 공유 코드 | 라벨이 **고객사 → 공유 고객사** 로 바뀐다. 실사용 고객사가 없으면 **사용 고객사 없음** | S15 |
| 편집 중인 코드 | **편집** 배지 + **[✏️ 편집으로 이동 →]** (`PRJ-02`) | S15 |

### 4.5 목록 조작

| 기능 | 동작 | 화면 |
|---|---|---|
| 번호 점프(`O`·`B` 입력) | 입력한 번호부터 이후 목록만 표시. `✕`로 해제. 정원을 넘겨 입력하면 **정원-1로 보정**, 숫자만 받는다 | S9 |
| [＋ 더 보기] | 다음 **80개**를 이어서 표시(남은 개수 함께 표시). 목록을 끝까지 스크롤해도 자동으로 이어 로드된다 | S16 |
| 필터로 결과가 없을 때 | **S{n} 에는 {걸린 필터} 에 해당하는 Owner가 없습니다.** + [필터 해제] | S10 |
| 필터 없이 결과가 없을 때 | **결과 없음** 만 표시 | S11 |
| 상위 선택 변경 | 현재 선택이 목록에서 사라지면 첫 항목으로 자동 이동 | S1 |

> **[필터 해제]** 는 상태·고객사·검색어·번호 점프·더 보기를 **한 번에** 되돌린다.
> 안내 문구에 들어가는 조건은 **상태 · 고객사 · 검색어 · O 번호 이후** 를 이어 붙인 것이다.

## 5. 상태별 변화 · 메시지

| 표시 | 의미 | 화면 |
|---|---|---|
| **공유** | 공유(커먼) 코드로 지정된 Owner. **발급 여부와 무관하게 항상 이 배지가 우선**한다. 안내 아이콘에 공유 사유·사용 고객사 | S6 · S12 · S15 |
| **🚫 영역 할당됨** | 반대 코드 종류(PDS3↔PDS2)가 이 Owner를 선점 — 현재 종류에서는 사용 불가 | S12 |
| **코드발급 / 편집 / 사용가능 / 코드 미발급** | 코드 상태 배지 | S3 · S4 · S5 · S7 |
| **추천제외** | 테스트/개발 전용 Section (자동 추천 제외, 직접 선택은 가능) — **PDS2 S0·S14 만** | S2 |
| 🌐 언어 슬롯 | PDS2 S3 의 언어 확장 Owner | S12 |
| Book 선택 불가 | 반대 코드 종류가 이미 발급한 Book — 회색으로 눌리지 않고 부제에 **{반대PDS} 발급 · 선택 불가** | S13 |
| 사용 고객사 표기 | 공유 코드는 **실사용 고객사**만 표시한다(대표 오너명으로 대체 표기하지 않음) | S12 · S15 |
| 결과 없음 | **결과 없음** 또는 필터 안내 문구 + [필터 해제] | S10 · S11 |

배지 우선순위는 **① 공유 → ② 🚫 영역 할당됨 → ③ 코드 상태** 순이다.

이 화면 자체에는 저장 동작이 없어 검증 메시지가 없다. 할당 관련 메시지는 `SOB-02`.
