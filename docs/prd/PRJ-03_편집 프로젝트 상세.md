## 1. 기능 개요

선택한 편집 고객사(Owner)의 **교재(책) 편집 내역과 정산(청구액)** 을 관리하는 화면. 편집량(페이지·심볼)이 곧 청구 근거이므로, **편집팀의 작업 관리 화면이자 재무팀의 정산 근거 화면**이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | `PRJ-02`에서 고객사 선택 → **같은 화면 우측에 표시**(목록과 동시 노출) |
| 대상 단위 | 고객사 + Owner |
| 편집 단위 | 교재(책) 1권 = 목록 1행 → 등록·수정은 `PRJ-04` |

> **교재 = 내부 편집 기록** `PC-283` — 서비스 티켓의 하위 항목이 아니라 내부 편집팀이 한 작업 · 정산 정보를 모은 기록이다. casterN **마스터 계정**과 **Resource Studio** 작업이 자동으로 들어오고, 고객사가 직접 편집한 작업은 들어오지 않는다(`PRJ-04` §4.11).

> 좌측 목록과 함께 보이므로 **다른 고객사로 바로 전환**할 수 있고, `PRJ-02`의 코드 종류 필터가 이 상세에도 그대로 적용된다.

## 4. 사용법

### 4.1 상단 (S1)

고객사명 · **owner {번호}** · 보유 코드 종류(N/G) 배지가 표시되고, 우측에 **[초기화]**, **[＋ 교재(책) 추가]** 가 있다.

### 4.2 요약 지표 (S1)

두 묶음으로 나뉜다 — 왼쪽 **편집량**(수량), 오른쪽 **정산**(금액).

**편집량**

| 지표 | 의미 |
|---|---|
| 교재(책) | 교재 수 (필터 적용 시 **교재(책)·필터**로 표기) |
| TOTAL PAGE | PDF 편집 대상 페이지 합 (교재의 `Total Page` 합계 · **정산과 무관** `PC-089`) |
| 소리펜 심볼 합 / 필기펜 심볼 합 | 펜별 심볼 수 |
| 심볼 합계 | 소리펜 + 필기펜 |

**정산**

| 지표 | 의미 |
|---|---|
| 적용비 (Ncode 적용) | **[Ncode 적용] 수량 × 적용 단가** `PC-085` — 아래에 `{타입} {n}p × 단가` |
| 편집·기능비 | 심볼·기능 항목별 단가 합 — 아래에 `심볼·기능 {n} (항목별 단가)` |
| 청구액 | 기준가 − 할인 — 아래에 `할인 −{n}` 또는 `할인 없음` |

### 4.3 단가 기준 표시

지표 아래 한 줄에 **신규 교재에 적용될 현재 고객사 단가**가 배지로 표시된다 — *{고객사 단가|기본 단가} (신규 교재 기준) : 적용 - {n}원/페이지 · 편집(기본) - {n}원/심볼*. 고객사 전용 단가가 없으면 전사 기본 단가를 쓴다.

**목록의 청구액은 교재마다 고정된 단가로 계산된다** `PC-027`. 즉 고객사 단가를 올려도 이전에 등록한 교재의 금액은 그대로이고, 그 뒤에 등록하는 교재부터 새 단가가 반영된다.

| 표시 | 조건 | 화면 |
|---|---|---|
| **고객사 단가 (신규 교재 기준)** 배지 | 전용 단가 있음 · 옆에 `항목별 단가는 고객사 관리 참조` | S2 |
| **기본 단가 (신규 교재 기준)** 배지 | 전용 단가 없음 (툴팁: 고객사 전용 단가가 없어 전사 기본 단가로 계산합니다.) | S3 |
| **프로젝트 단가·할인 {n}건** 배지 | 고객사 단가와 다른 단가·할인이 걸린 교재가 있을 때 | S2 |
| **할인 −{금액} ({n}%)** 배지 | 할인 합계가 있을 때 (툴팁에 적용 교재 수·기준가) | S2 |
| **청구액 {금액}** | 항상 | S1 |

같은 줄 끝의 **`?`** 버튼을 누르면 **계산식 · 단가 근거**가 왼쪽 아래로 펼쳐진다. 내용이 길어 **세로로 스크롤**되며(최대 화면 높이의 70%), **4개 블록**으로 구성된다. (S4)

맨 위에 안내가 있다 — *단가는 3단계로 적용됩니다 — 기본 단가 → 고객사 단가(고객사 관리) → 프로젝트 단가·할인(교재 편집 수정).*

| 블록 | 내용 |
|---|---|
| **① 현재 집계 계산식** | `적용비용(페이지 {n} × {단가})` → `편집·기능비(심볼·기능 {n}, 항목별 단가 합)` → `기준가` → `할인({n}%, 적용 교재 {n}건)` → **청구액** 표. 아래에 **적용 단가 / 편집 단가**와 전용·기본 구분. 필터 중이면 제목 옆에 **(필터 {n}건 기준)**. 고객사 관리에 없는 고객사면 **※ 고객사 관리에 등록되지 않아 기본 단가로 계산됩니다.** |
| **② 소리펜 변경후 단가 (전사 기본값)** | 적용 **₩500**/페이지(변경전 300) · 편집 **₩1,000**/심볼(변경전 900). 전 고객사 공통이며 예외(잉글리시에그 편집 변경전 600, 트윈클 보드 단가)를 함께 적는다 |
| **③ 개별 견적서 (참고)** | 실제 견적 2건 — *2026-07-16 양지사 플래너 4종* / *2026-05-26 블루래빗 생생자연관찰*. 각 항목 단가와 합계(VAT 구분) |
| **④ 정의** | 적용 = PDF 1페이지 당 · 편집(기본) = **음원 재생 영역 1개 = 심볼**(mp3 개수와 다름) · 프롬프트 = 대화(포코로) 세션 1개 당 |

> **전사 기본 단가는 적용 ₩500/페이지 · 편집(기본) ₩1,000/심볼**이다.
