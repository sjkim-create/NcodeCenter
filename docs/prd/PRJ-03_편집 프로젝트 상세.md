## 1. 기능 개요

선택한 편집 고객사(Owner)의 **교재(책) 편집 내역과 정산(청구액)** 을 관리하는 화면. 편집량(페이지·심볼)이 곧 청구 근거이므로, **편집팀의 작업 관리 화면이자 재무팀의 정산 근거 화면**이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | `PRJ-02`에서 고객사 선택 → **같은 화면 우측에 표시**(목록과 동시 노출) |
| 대상 단위 | 고객사 + Owner |
| 편집 단위 | 교재(책) 1권 = 목록 1행 → 등록·수정은 `PRJ-04` |

> 좌측 목록과 함께 보이므로 **다른 고객사로 바로 전환**할 수 있고, `PRJ-02`의 코드 종류 필터가 이 상세에도 그대로 적용된다.

---

## 2. 화면 흐름 (Flow)

```
PRJ-02 좌측 고객사 선택 ─▶ PRJ-03 (우측 상세)
   ├─ [＋ 교재(책) 추가] ───▶ PRJ-04 (등록 모드)
   ├─ 교재 행 클릭 ─────────▶ PRJ-04 (수정 모드)
   ├─ [계산식 · 단가 근거] ─▶ 청구액 산출 근거 펼침 → [닫기]
   ├─ [초기화] ─ 확인 ─────▶ 엑셀 시드 상태로 복원
   └─ 단가를 바꾸려면 ──────▶ MEM-01 → MEM-02 (고객사 단가)
```

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-16` 정산 = 항목별 단가표 | 청구액 = **적용비(페이지 × 적용단가) + 편집·기능비(항목별 수량 × 단가) − 할인** |
| 단가 3단 구조 | **기본 단가 → 고객사 단가(`MEM-02`) → 교재별 단가·할인(`PRJ-04`)** 순으로 우선 적용된다 |
| `P-14` 편집 = casterN | 이 화면의 데이터가 casterN 서비스의 편집 실적이다 |
| `P-12` 공통(커먼) 코드 | 공유 코드 Owner의 교재는 **사용 고객사**를 반드시 지정해야 한다(`PRJ-04`) |
| `P-01` SOBP | 교재는 S/O/B 좌표에 매인다. 상세에서 좌표를 임의로 바꾸지 않는다 |

## 4. 사용법

### 4.1 상단

고객사명 · Owner · 보유 코드 종류(N/G)가 표시되고, 우측에 **[초기화]**, **[＋ 교재(책) 추가]** 가 있다.

### 4.2 요약 지표

**편집량**

| 지표 | 의미 |
|---|---|
| 교재(책) | 교재 수 (필터 적용 시 **교재(책)·필터**로 표기) |
| TOTAL PAGE | PDF 편집 대상 페이지 합 |
| 소리펜 심볼 합 / 필기펜 심볼 합 | 펜별 심볼 수 |
| 심볼 합계 | 소리펜 + 필기펜 |

**정산**

| 지표 | 의미 |
|---|---|
| 적용비(페이지) | 페이지 수 × 적용 단가 |
| 편집·기능비 | 심볼·기능 항목별 단가 합 |
| 청구액 | 기준가 − 할인 |

### 4.3 단가 기준 표시

현재 계산에 쓰인 단가가 **고객사 단가** 또는 **기본 단가**로 표시된다 — *적용 - {n}원/페이지 · 편집(기본) - {n}원/심볼*. 고객사 전용 단가가 없으면 전사 기본 단가로 계산한다.

- 고객사 단가와 다른 단가가 걸린 교재 수, **할인 적용 교재 수·기준가**가 함께 표시된다.
- **[계산식 · 단가 근거]** 를 열면 `적용비용 → 편집·기능비 → 기준가 → 할인 → 청구액` 순서로 산출 근거를 볼 수 있다. 화면 안내: *단가는 3단계로 적용됩니다 — 기본 단가 → 고객사 단가(고객사 관리) → 프로젝트 단가·할인(교재 편집 수정).*

### 4.4 목록 — 검색 · 필터

| 요소 | 동작 |
|---|---|
| 검색 | **교재명 검색** (공유 코드 Owner면 **교재명·사용고객사 검색**) |
| 상태 | 진행 상태로 거른다 |
| 사용 고객사 | 공유 코드 Owner일 때만 표시 |
| 타입 | 소리펜/필기펜 등 교재 타입 |
| 편집방식 | 편집 방식별 |
| 페이지네이션 | `«` `‹` `›` `»` |

### 4.5 목록 항목

No · 상태 · (사용 고객사) · 교재명 · 코드 · 타입 · S/O/B · 페이지 · 심볼 개수 · 편집방식 · 발급일 · 최종 수정일 · 메모 · ncp2 크기(byte) · 정산(청구액)

**행을 클릭하면 `PRJ-04` 수정 모드**로 열린다.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 |
|---|---|
| 고객사 미선택(부모 화면) | `PRJ-02` 우측에 **좌측에서 고객사를 선택하세요.** |
| 필터 적용 | 교재 지표가 **교재(책)·필터**로 바뀌고 집계가 필터 기준으로 계산된다 |
| 고객사 전용 단가 있음 | **고객사 단가** 배지 |
| 전용 단가 없음 | **기본 단가** 배지 (툴팁: 고객사 전용 단가가 없어 전사 기본 단가로 계산합니다.) |
| 할인 적용 교재 존재 | 할인 건수·기준가 표시, 청구액 지표에 **할인 −{금액}** |
| 공유 코드인데 사용 고객사 미입력 | 해당 행에 **미입력** 표시 (툴팁: 공유 코드인데 사용 고객사가 비어 있습니다. 교재를 열어 입력하세요.) |

### 메시지

| 상황 | 노출 방식 | 문구 |
|---|---|---|
| 초기화 | 확인창 | **엑셀 시드로 초기화할까요?** → 완료 시 상단 알림 **초기화됨** |
| 저장 공간 부족 | 상단 알림 | **⚠ 브라우저 저장 공간이 가득 차 저장하지 못했습니다. 다른 사이트 데이터를 정리한 뒤 다시 저장하세요.** |

## 6. 연결 화면

| 트리거 | 이동 | 설명 |
|---|---|---|
| [＋ 교재(책) 추가] | `PRJ-04` | 등록 모드 |
| 교재 행 클릭 | `PRJ-04` | 수정 모드 |

| 고객사 단가 변경 | `MEM-01` → `MEM-02` | 단가 변경 후 이 화면 금액이 재계산된다 |
| 코드 좌표 확인 | `SOB-01` | 해당 S/O/B 위치 확인 |
| 편집 실적 기록 확인 | `LOG-01` | 교재 추가·교재 작업 기록 |
