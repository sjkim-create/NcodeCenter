## 1. 기능 개요

**PUI(Physical UI) = 종이 위 컨트롤러**에 쓰이는 코드. 재생·정지·볼륨 같은 **피지컬 조작 기능이 어떤 Book/Page에 매핑돼 있는지**를 확인하는 참조 화면이다. 일반 콘텐츠 코드와 달리 기능 자체가 코드에 고정돼 있어 **조회·참조 중심**으로 사용한다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 [PUI 코드 (피지컬)] |
| 성격 | **참조 전용** (기능표·할당 코드 조회) + 참고 이미지 보관 |
| 구성 | 좌: PUI 할당(Section/Owner) 목록 · 우: 선택 할당 상세 |

---

## 2. 화면 흐름 (Flow)

```
좌측 메뉴 [PUI 코드 (피지컬)]
   └─▶ PRJ-06
         ├─ 좌측에서 PUI 할당(S/O) 선택 ─▶ 우측 상세
         │     ├─ 프로젝트 / 할당 코드 표
         │     ├─ 이미지(펼치기/접기)
         │     ├─ 기능표(펼치기/접기)
         │     └─ 원본 데이터(펼치기/접기)
         └─ 코드 좌표를 지도에서 확인하려면 ─▶ SOB-01
```

---

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-01` SOBP | PUI도 동일하게 Section/Owner/Book/Page 좌표로 관리한다 |
| `P-02` 코드 종류 N/G | 할당별 코드 종류(PDS)를 함께 표기 |
| `P-05` 무겹침 | PUI 할당 코드도 일반 코드와 같은 원장에서 관리된다(별도 코드 체계가 아님) |
| 참조 성격 | 이 화면에서는 **코드를 발급하지 않는다.** 발급은 `SOB-02` |

## 4. 사용법

### 4.1 좌측 — PUI 할당 목록

| 표시 | 내용 |
|---|---|
| S / O | 할당된 Section·Owner |
| 라벨 | 할당 이름(있을 때) |
| 건수 | `프로젝트 {n} · 기능 {n}` |

항목을 선택하면 우측에 상세가 표시된다.

### 4.2 우측 — 상세

| 영역 | 내용 |
|---|---|
| 머리 | `S{n} / O{n} · {라벨}` · 코드 종류(PDS) · 원본 시트명 |
| **프로젝트 / 할당 코드** | 프로젝트 · Book · Page · 제품 · 고객사 · 메모/포함기능 · 부서/발급인 · 비고 |
| **이미지** | 참고 이미지 등록·확인. [펼치기 ▼] / [접기 ▲] |
| **기능표** | 대구분 · 소구분 · 기능명 · 요약 · Book · Page · params |
| **원본 데이터** | 가공 전 원본 행 확인 |

### 4.3 사용 절차

1. 좌측에서 확인할 PUI 할당(S/O)을 고른다.
2. **프로젝트 / 할당 코드** 표에서 어떤 프로젝트가 어떤 Book/Page를 쓰는지 확인한다.
3. **기능표**에서 기능별 Book·Page·params를 확인한다(피지컬 버튼 매핑 근거).
4. 필요하면 참고 이미지를 등록해 둔다.
