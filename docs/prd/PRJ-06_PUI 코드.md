## 1. 기능 개요

**PUI = Paper UI(종이 UI)** 의 약자다 `PC-043`. **종이 위 컨트롤러**에 쓰이는 코드로, 재생·정지·볼륨 같은 **종이 위 조작 기능이 어떤 Book/Page에 매핑돼 있는지**를 확인하는 참조 화면이다. 일반 콘텐츠 코드와 달리 기능 자체가 코드에 고정돼 있어 **조회·참조 중심**으로 사용한다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 좌측 메뉴 [서비스 관리 ▸ CasterN 서비스 관리 ▸ PUI 코드 (페이퍼)] |
| 성격 | **참조 전용** (기능표·할당 코드 조회) + 참고 이미지 보관 |
| 구성 | 좌: PUI 할당(Section/Owner) 목록 · 우: 선택 할당 상세 |

## 2. 화면 흐름 (Flow)

```
[서비스 관리 ▸ CasterN ▸ PUI 코드 (페이퍼)]
   └─▶ PRJ-06
         ├─ 좌측에서 PUI 할당(S/O) 선택 ─▶ 우측 상세
         │     ├─ 프로젝트 / 할당 코드 표
         │     ├─ 이미지(펼치기/접기)
         │     ├─ 기능표(펼치기/접기)
         │     └─ 원본 데이터(펼치기/접기)
         └─ 코드 좌표를 지도에서 확인하려면 ─▶ SOB-01
```

## 4. 사용법

### 4.1 상단 요약 (S1)

맨 위 한 줄에 화면 이름과 규모가 나온다 — **PUI 코드 관리** · *종이 위 컨트롤러(Paper UI) 프로젝트 할당 코드* · `할당 {n}` · `프로젝트 {n}` · `기능 {n}`

### 4.2 좌측 — PUI 할당 목록 (S1)

제목은 **PUI 할당 (Section/Owner)**. 들어오면 **첫 할당이 자동 선택**된다.

| 표시 | 내용 |
|---|---|
| S / O | 할당된 Section·Owner (`S{n}/O{n}`) + **코드 종류 배지** |
| 라벨 | 할당 이름(있을 때만) |
| 건수 | `프로젝트 {n} · 기능 {n}` |

### 4.3 우측 — 상세

머리에 `S{n} / O{n} · {라벨}` 과 `{코드 종류} · 시트 {시트명}` 이 표시되고, 그 아래 **프로젝트 / 할당 코드 ({n})** 표가 온다. 이어서 **접었다 펼치는 3개 묶음**이 나온다.

| 묶음 | 기본 | 내용 | 화면 |
|---|---|---|---|
| **프로젝트 / 할당 코드** | 항상 | 프로젝트 · Book · Page · 제품 · 고객사 · 메모/포함기능 · 부서/발급인 · 비고 | S2 |
| **🖼 컨트롤러 이미지** | **펼침** | 참고 이미지 등록·확인 · *디자인 시안·인쇄물 이미지를 올려 보면서 작업* | S3 |
| **⚙ 기능 매핑 (Book/Page/params)** | 접힘 | 대구분 · 소구분 · 기능명 · 요약 · Book · Page · params | S2 |
| **📄 원본 시트** | 접힘 | 엑셀 원본 그대로 · `{n}행` 배지 · 영역 안에서 스크롤 | S4 |

각 묶음 제목 옆에 **건수 배지**가, 오른쪽 끝에 **펼치기 ▼ / 접기 ▲** 가 있다.

| 표가 빌 때 | 문구 | 화면 |
|---|---|---|
| 프로젝트 표 없음 | **정규화된 프로젝트 표가 없습니다. 아래 원본 시트에서 확인하세요.** | S1 |
| 기능 매핑 없음 | **이 할당에는 기능 매핑 표가 없습니다.** | S1 |

### 4.4 컨트롤러 이미지 (S3 · S5 · S6)

| 요소 | 동작 |
|---|---|
| [＋ 이미지 업로드] | 여러 장을 한 번에 고를 수 있고 **한 번에 최대 8장**까지 받는다 |
| 저장 위치 | **브라우저에 저장**된다 — 서버로 올라가지 않는다. 안내: *브라우저에 저장 · 클릭하면 크게 보기* |
| 이미지 클릭 | **화면 전체 위에 크게** 열린다. 파일명과 **[닫기 ✕]**, 바깥 어두운 영역을 눌러도 닫힌다 (S6) |
| [삭제] | 그 이미지만 제거 |
| 이미지 없음 | 점선 박스 **업로드된 이미지가 없습니다. PUI 컨트롤러 디자인/인쇄 시안을 올려보세요.** |

### 4.5 사용 절차

1. 좌측에서 확인할 PUI 할당(S/O)을 고른다.
2. **프로젝트 / 할당 코드** 표에서 어떤 프로젝트가 어떤 Book/Page를 쓰는지 확인한다.
3. **기능 매핑**에서 기능별 Book·Page·params를 확인한다(종이 위 버튼 매핑 근거).
4. 필요하면 참고 이미지를 등록해 둔다.
5. 정규화되지 않은 항목은 **원본 시트**에서 확인한다.
