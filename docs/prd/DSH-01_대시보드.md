## 1. 기능 개요

로그인 후 처음 만나는 화면. **코드가 얼마나 발급(할당)되어 있고 · 어느 Section에 · 어느 업체가 많이 가지고 있는지**, 그리고 **내부 직원이 최근 무엇을 했는지**를 한 화면에서 파악한다. 편집팀뿐 아니라 사업부·재무팀이 코드 발급 규모를 확인하는 진입점이다.

| 항목 | 내용 |
|---|---|
| 권한 | STAFF / ADMIN |
| 진입 | 로그인 성공 직후 · 좌측 메뉴 [대시보드] |
| 성격 | **조회 전용** — 이 화면에서 데이터를 등록·수정하지 않는다 |

---

## 2. 화면 흐름 (Flow)

```
로그인 ──▶ DSH-01 대시보드
             ├─ [전체 로그] ─────────▶ LOG-01 활동 로그
             ├─ 좌측 메뉴 SOBP 맵 ───▶ SOB-01 (Section·Owner 상세 확인)
             ├─ 좌측 메뉴 고객사 ────▶ MEM-01 (업체 상세 확인)
             └─ 좌측 메뉴 편집 ──────▶ PRJ-02 (편집량·정산 확인)
```

이 화면은 **요약**만 제공한다. 상세 확인·수정은 각 화면코드로 이동해서 수행한다.

---

## 3. 정책

| 정책 | 이 화면에서의 적용 |
|---|---|
| `P-04` 코드 상태 = 할당됨 / 미발급 | 코드 상태 카드는 **할당됨 / 미발급** 2가지로만 표기. 예약(RESERVED)·사용중(IN_USE) 구분은 표시하지 않는다 (`PC-004`·`PC-005`) |
| `P-01` SOBP | 집계 축은 Section / Owner / Book. 한글 대체어를 쓰지 않는다 |
| 테스트/개발 섹션 | 상용 미출시 Section(1·44)에는 **테스트/개발** 배지를 붙여 상용 물량과 구분한다 |
| `P-18` 사용 관제(목표) | 현재 집계는 원장 기준. 자체 서비스 실사용량 자동 반영은 미구현(§7) |

## 4. 사용법

### 4.1 화면 구성

**① 상단 KPI 4종**

| KPI | 의미 |
|---|---|
| 할당 코드 레코드 | Owner×Book 원장 건수 (모두 발급된 코드) |
| 업체(ACCOUNT) | 등록 업체 수 |
| 할당 Book 합계 | 발급된 Book 총량 |
| 코드 섹션 | 집계 대상 Section 수 |

화면은 **KPI 4칸** 아래 **좌(넓게) / 우(360px)** 2단이다.

**② Section별 소유 현황** (좌) — Section마다 소유 owner 수를 가로 막대로 비교한다. 이름 옆에 배지가 붙는다 — 상용 미출시면 **테스트/개발**(보라), 옛 체계면 **레거시**(주황). 배지는 표기 전용이다. (S3)

**③ 업체별 점유 Top 6** (좌) — 소유 owner 수 기준 상위 6개 업체. 순위·업체명·막대·`owner {n}` 으로 표시되고 **막대 색이 항목마다 다르다**.

**④ 코드 상태** (우) — **할당됨(발급)** 과 **미발급(섹션 정원의 잔여)** 두 가지. 아래 안내: *코드 상태는 **할당됨 / 미발급** 두 가지입니다. 예약(선점) vs 사용중 구분은 폐기되었습니다.* `PC-004`

**⑤ 최근 활동 (내부 직원)** (우) — **최근 7건**만 시간순으로 보여준다. 한 줄은 `MM-DD HH:MM` · **활동 종류 배지**(색) · 내용 · 직원 이름. 우측 [전체 로그]로 `LOG-01` 이동. (S2)

### 4.2 사용 절차

1. 로그인하면 대시보드가 열린다.
2. KPI로 **전체 발급 규모**를 확인한다.
3. Section별·업체별 카드로 **어디에 몰려 있는지** 확인한다.
4. 특정 Section·Owner의 실제 점유 상태를 보려면 `SOB-01`로 이동한다.
5. 특정 업체의 계약·단가·업무 이력을 보려면 `MEM-01`로 이동한다.
6. 누가 무엇을 했는지 확인하려면 [전체 로그] → `LOG-01`.

## 5. 상태별 변화 · 메시지

| 상태 | 화면 | 화면 번호 |
|---|---|---|
| 데이터 정상 | KPI 4 + 카드 4종 표시 | S1 |
| 최근 활동 없음 | **기록된 활동이 없습니다. (고객사 수정·코드 할당·프로젝트 등록·티켓 발급·교재 작업·로그인 시 기록)** — [전체 로그] 이동은 그대로 가능 | S2 |
| 상용 미출시 Section | 항목 옆 **테스트/개발** 배지 (툴팁: 상용 미출시 · 개발/테스트 전용) | S3 |
| 레거시 Section | 항목 옆 **레거시** 배지(주황) | S3 |
| STAFF 로 진입 | **화면이 ADMIN 과 완전히 같다** — 이 화면에는 권한 분기가 없다 | S4 |

> **권한 차이는 좌측 메뉴뿐**이다. **활동 로그** 메뉴에 **ADMIN** 배지가 붙지만 메뉴 자체는 보이며, [전체 로그]로 들어가면 `LOG-01` 화면에서 **🔒 접근 권한이 없습니다** 로 막힌다.
>
> ⚠ Section 배지(테스트/개발·레거시)는 `SOB-01` 의 **추천제외**(PDS2 S0·S14)와 **다른 값**이다.

이 화면에는 사용자 입력이 없어 **검증 오류 메시지가 발생하지 않는다.**
