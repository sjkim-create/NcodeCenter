S1 기본 · 데이터 정상S2 처리할 알림 없음S3 Section 정원 경고S4 편집 상태 미지정 — 전량 진행중S5 미정산 추정 불가S6 최근 활동 없음S7 STAFF 진입 — 화면은 동일
로그인 후 처음 만나는 화면. 코드가 얼마나 남아 있고 · 편집이 얼마나 진행됐고 · 받을 돈이 얼마이고 · 지금 처리할 일이 무엇인지를 한 화면에서 파악한다. 분야별 4개 구역(코드 · 편집 · 정산 · 운영)으로 나뉘며 조회 전용이다 — 상세 확인·수정은 각 화면코드로 이동해서 수행한다. 집계는 화면을 열 때 원장에서 다시 계산하며, 계산 규칙과 예시는 PRD §4.2 에 있다.
S1기본 · 데이터 정상기본
로그인 성공 직후 열리는 기본 진입 화면. 분야별 4개 구역을 위에서 아래로 배치한다 — ① 코드(SOBP) ② 편집(CasterN) ③ 정산 ④ 운영. 각 구역은 요약 3장 + 상세 카드로 이루어지고, 구역 제목 우측 링크로 해당 관리 화면에 들어간다. 조회 전용이며 사용자 입력이 없어 검증 오류가 없다.
