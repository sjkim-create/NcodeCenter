App Key = 계정과 연동되는 키. 온라인 편집툴(Caster U)·폼솔루션·SDK 에서 쓰며 계정(ID/PWD)과 SOBP 범위를 한 번에 발급한다. 계정이 없으면 발급할 수 없으므로 신규 고객사는 이 화면에서 계정 등록과 키 발급을 한 흐름으로 처리한다.
카드 한 장 안에 ① 계정 → ② 할당된 SOBP 범위 → ③ 발급 조건 이 이어지고, 맨 아래에 서비스 DB 목록이 붙는다. TKT-01 과 고객사 선택값을 공유한다.
S1진입 — 고객사 미선택기본
TKT-01 좌측 발급 메뉴 [계정 + App Key] 로 들어온다. 고객사를 고르기 전에는 계정 칸이 고객사를 먼저 선택 으로 잠기고, 범위·서비스 DB 도 안내만 나오며 발급 버튼이 비활성이다.
