TKT-01계정 발급 상태 5개 PRD: docs/prd/TKT-01_계정 발급.md
S1 계정 목록 — 기본S2 등록된 계정 없음S3 필터 · 검색S4 결과 없음S5 계정 삭제 확인창
계정 발급 은 서비스 로그인 계정을 관리하는 화면이다. 이 화면은 목록이며 등록·상세 수정은 TKT-02 이다.
계정은 고객사당 여러 개(제한 없음)를 둘 수 있고 ID(email)만 전체에서 유일하면 된다 PC-029. App Key 발급은 선택이라 계정만 먼저 만들어 두었다가 나중에 상세 화면에서 키를 붙일 수 있다.
CasterN 계정은 권한 6종(프로젝트 생성 · 심볼 편집 · 리소스 편집 · Ncode PDF 내보내기 · NCP2 내보내기 · App용 패키지 내보내기)을 개별 또는 모두 지정한다 PC-031 PC-058.
S1계정 목록 — 기본기본
좌측 메뉴 [티켓 발급] ▸ [계정 발급](/tickets/account) 의 첫 화면. 등록된 모든 고객사의 계정을 한 표로 본다. 한 고객사에 계정을 여러 개 둘 수 있다 PC-029. ID 나 [상세] 를 누르면 TKT-02 상세·수정으로 간다.
