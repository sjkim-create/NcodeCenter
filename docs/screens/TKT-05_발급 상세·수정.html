발급된 티켓 한 건을 열어 기록을 바로잡고 정산을 등록하는 화면이다. N Key 와 App Key 를 같은 화면으로 열며, 종류에 따라 머리말 표기와 Key 정보 항목 구성만 달라진다. 탭은 발급 기본정보 / 정산 정보 2개이고 [저장] 한 번으로 두 탭이 함께 기록된다 — 탭은 화면을 나눠 보여줄 뿐 저장 단위가 아니다. 폐기된 정산 등록 모달과 Key 정보 확인 모달의 기능이 이 화면으로 흡수됐다. 계산 규칙은 PRD §4.5.
S1발급 기본정보 탭 — 기본기본
TKT-03 목록의 발급번호 · 발급 내용 · [상세] 로 들어오면 이 탭이 먼저 열린다. 고객사 · 발급일시 · 발급인은 원장 기준값이라 잠금이고, 발급 내용과 Key 정보만 고친다. 머리말에 종류 · 발급 번호 · 고객사가 붙는다.
