MEM-02고객사 등록·수정 상태 11개 PRD: docs/prd/MEM-02_고객사 등록·수정.md
S1 등록 — 기본 정보 탭S2 상세·수정 — 기본 정보 탭 · 업무요청 메모S3 편집 단가 탭 — 소리펜 · 필기펜 그룹S4 관련 서류 탭S5 업체명 미입력 오류S6 대표(상위) 회사 수정S7 전용 단가 지정됨S8 프로젝트 종료 선택S9 업무요청 메모 입력 중S10 남의 메모 수정 시도S11 메모 삭제 확인창
고객사의 기본 정보 · 공통코드 귀속 · 편집 단가 · 관련 서류를 입력한다. 모달이 아니라 별도 페이지 2개다 — MEM-01 의 [＋ 고객사 등록] = 등록, 행을 누르면 상세·수정. 입력 항목이 길어 좌측을 3탭(기본 정보 / 편집 단가 / 관련 서류)으로 나눴고, 수정 화면에서는 업무요청 메모가 탭과 무관하게 우측에 고정된다 — 단가를 조정하면서 요청 내용을 함께 볼 수 있다. 단가는 3단 구조(기본 단가 → 고객사 단가 → 교재별 할인)이며, 변경은 이후 등록되는 교재부터 적용되고 기존 교재는 등록 당시 단가를 유지한다 PC-027.
S1등록 — 기본 정보 탭기본
MEM-01의 [＋ 고객사 등록]으로 진입. PRD §1 — 등록 모드는 기본 정보 1단이며 업무 원장(MEM-03)이 없다. 필수는 업체명 하나뿐.
