INF-04OID 관리대장 상태 4개 PRD: docs/prd/INF-04_OID 관리대장.md
S1 기본 — index 관리 업체S2 book 미분할 업체S3 필터 · 검색S4 검색 결과 없음
OID 관리대장 — OID 는 index 만 갖는 코드로, 외부 코드를 우리 펜으로 읽으려고 만든 방식이다. 펜으로 찍으면 코드 값이 1개만 나오고, 총량이 약 6만 개뿐이라 분량이 적으면 book 으로 나누지 않는다.
대장은 업체 구분에 S/O 를 써 왔고 분량이 늘어난 업체만 book 번호로 나눴는데, 그 book 번호가 곧 OID index 로 보인다. 그래서 이 화면은 업체 + index 로 모아 본다. 좌표 기준 조회는 SOB-01 의 종류 [OID] 필터로 한다 PC-035. (옛 IDS(A코드) 표기 = OID 동일)
S1기본 — index 관리 업체기본
Ncode 정보(/info)의 [OID 관리대장] 탭이다 — 별도 메뉴로 두지 않는다 PC-034. 맨 위 안내에 OID 개념이 고정으로 붙는다 — index 만 갖는 코드, 펜으로 찍으면 코드 1개만, 총량 약 6만 개, 분량이 적으면 book 미분할 PC-033.
왼쪽은 업체(관리 단위), 오른쪽은 그 업체의 index + 교재 표다. 기존 SOBP 좌표는 📝 메모로만 표시한다.
