이 콘솔을 쓰는 내부 직원의 이름 · 부서 · 역할 · 사용 여부를 관리하는 화면 PC-297. ADMIN 전용. 직원은 회사 계정으로 처음 로그인하면 자동 등록(STAFF)되고, 직원 이름은 N Key 담당자(PC-296) · 활동 로그 직원으로 쓰인다. 삭제는 없고 그만둔 직원은 「사용 중지」(로그인 불가).
S1기본 — 직원 표기본
이 콘솔을 쓰는 내부 직원. 회사 계정(@neolab.net)으로 처음 로그인하면 그 이메일로 자동 등록(STAFF)되므로 [등록] 버튼은 없다 PC-297. 이름은 표에서 바로 고치고(벗어나거나 Enter 면 저장), 부서 · 역할은 고르면 바로 저장, 상태는 눌러 사용 중 ↔ 사용 중지. 이메일은 로그인 계정이라 고칠 수 없다. 지우지 않는다.
