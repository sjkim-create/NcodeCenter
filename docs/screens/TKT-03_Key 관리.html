TKT-03N Key 관리 상태 8개 PRD: docs/prd/TKT-03_Key 관리.md
S1 기본 목록 · 최근순S2 체험 만료 경고 · 대장 이력S3 필터 — 고객사 · 정산 · 출처S4 정렬 — 머리글 클릭S5 필터 결과 없음S6 발급 이력 없음S7 페이지 이동 · 건수 변경S8 발급 기록 삭제 확인
발급된 티켓(N Key · App Key)의 전체 이력을 조회하고, 발급 건별로 상세·정산 화면에 들어가는 진입점이다. 목록에는 두 종류가 함께 쌓이며 종류 필터로 구분한다. 정산 등록과 Key 정보 확인은 이 화면의 모달이 아니라 발급 상세(TKT-02)의 탭이다. 요약 합계는 필터 결과 전체 기준이라 페이지를 넘겨도 변하지 않는다. 계산 규칙은 PRD §4.7.
S1기본 목록 · 최근순기본
요약 5칸 → 도구 막대 → 9열 표 → 페이지네이션 순서다. 목록은 N Key 만 다룬다 PC-061 — App Key 는 계정 단위라 TKT-02 계정 상세의 [Key 정보] 에서 본다. 기본 정렬은 발급일시 내림차순이다. ⚠ 정산 등록·Key 정보 모달은 폐기되어 발급 상세의 탭으로 이동했다.
