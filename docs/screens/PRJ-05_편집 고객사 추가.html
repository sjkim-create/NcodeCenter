S1 진입 — 고객사 미선택S2 Owner 코드 선택S3 Owner 1개 — 자동 선택S4 할당 코드 없음 — 추가 차단
이미 코드를 받은 고객사를 편집 관리 대상으로 올리는 창이다. 고객사를 새로 만들거나 코드를 새로 할당하지 않는다 — 이미 할당된 코드 중 어느 Owner를 편집할지 고르는 것이다. 추가하면 ① 그 Owner 코드가 PRJ-01·SOB-01 에서 편집 으로 표시되고 ② 편집 프로젝트 목록에 그 고객사가 올라간다. 판정 규칙은 PRD §4.5.
S1진입 — 고객사 미선택기본
PRJ-02 의 [＋ 고객사 추가] 로 열린다. ⚠ 고객사를 새로 만드는 화면이 아니다 — 이미 코드를 받은 고객사를 편집 관리 대상으로 올리는 창이다. 고객사를 고르기 전에는 아래가 비어 있고 [추가] 가 눌리지 않는다.
