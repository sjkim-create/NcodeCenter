코드를 발급받는 업체(고객사) 마스터. 사업자·계좌·서류·편집 단가·업무 이력을 관리한다. 모든 코드 발급과 티켓 발급의 선행 조건이며, 여기에 등록되지 않은 업체에는 코드를 할당할 수 없다. 계층은 P-11에 따라 상위 / 하위 / 단독 3분류이고 구분 필터로 거른다. 행을 클릭하면 MEM-02 수정 화면으로 이동한다. 기준: web/components/CompaniesView.tsx
S1기본 · 전체 목록기본
좌측 메뉴 [고객사 관리]로 진입. 구현은 안내문 + 검색 + [초기화] + [＋ 고객사 등록] 툴바 아래에 구분 필터 줄이 따로 있고, 표는 11열(No · 업체명 · 담당자/연락처 · 사업자번호 · 은행/계좌 · 커먼 코드 · 편집 단가 · 주소 · 서류 · 업무 · 작업)이다. 표 하단에 표시 건수 선택 + 페이지네이션이 붙는다. 기준: web/components/CompaniesView.tsx
