티켓 = 고객사가 이미 할당받은 SOBP 코드를 실제로 쓸 수 있게 하는 사용 허가다. 발급 메뉴는 사이드바 [티켓 발급] 그룹(TKT-01 N Key 발급 · TKT-03 계정 발급 · TKT-04 발급 목록 · 정산)이며, 이 화면은 그중 N Key 발급(/tickets/nkey)이다.
N Key = 물리 키 · 오프라인 편집툴(Caster lite) 용 · 계정 불필요. 고객사 선택값은 TKT-01 · TKT-03 · TKT-04 3개 화면이 공유한다.
S11~S13 은 이 화면에서 열리는 TKT-02 Key 정보 확인 모달이다.
S1진입 직후 — 고객사 미선택기본
좌측 메뉴 [티켓 발급] → N Key 발급이 기본으로 열린다. 고객사를 고르기 전에는 SOBP 범위 자리에 안내만 나오고 Book·Page 입력이 잠겨 있으며 [Key 생성] 도 눌리지 않는다.
