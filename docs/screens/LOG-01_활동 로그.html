내부 직원이 언제 무엇을 했는지를 시간순으로 확인하는 감사(audit) 화면. ADMIN 전용이며 STAFF는 본문이 🔒 안내로 대체된다. 조회 전용(기록은 각 화면에서 자동 생성) · 한국시간(KST) 기준 · 보관 최근 7일. 필터는 월 · 직원 · 활동 종류 칩 3줄이고 각 칩은 재클릭 시 해제(토글)된다.
S1기본 · 월 ▸ 일자 그룹기본
ADMIN 전용 — 좌측 메뉴 [활동 로그] 또는 DSH-01의 [전체 로그]로 진입. 구현은 본문 최대 1000px이며 필터가 드롭다운이 아니라 칩 3줄(월 · 직원 · 활동 종류)이다. 목록은 월 헤더 + 일자 그리드 92px 1fr 구조로, 왼쪽에 큰 날짜 숫자, 오른쪽에 활동 카드가 붙는다.
