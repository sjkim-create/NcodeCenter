S1 계정 등록 — 진입S2 사용처 중복 선택S3 CasterN 탭 — 권한 개별 선택S4 폼솔루션 · SDK 탭 — 준비중S5 ③ App Key 함께 발급S6 사용처를 바꿔도 App Key 는 그대로S7 등록 검증 실패S8 계정 상세 · 수정S9 상세 — App Key 발급 완료S10 이미 발급된 계정 — 재발급 차단S11 계정 삭제 확인
TKT-01 계정 목록에서 열리는 등록과 상세·수정 두 화면이다. 사용처(연동 서비스)는 중복 선택이며, 서비스마다 지정할 조건이 달라 탭으로 나뉜다 — 조건이 아래로 쌓이지 않는다. 조건이 정의된 서비스는 CasterN 뿐이고 나머지는 준비중이다. App Key 발급은 CasterN 사용처 전용이라 CasterN 탭 안에 있다. 사용처에서 CasterN 을 빼면 App Key는 연동이 끊긴다(삭제되지 않는다). 로그인 허용 판정은 PRD §4.6.
S1계정 등록 — 진입기본
등록은 2단계다 — ① 계정 정보 → ② 사용처·권한. ⚠ 옛 ③ App Key 단계는 폐기되어 CasterN 탭 안으로 들어갔다. 사용처 기본값은 CasterN 이고 권한은 6종 모두 선택된 상태로 시작한다.
