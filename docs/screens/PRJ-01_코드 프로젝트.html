VIEW 용도 — 고객사별로 어떤 코드(SOBP)를 얼마나 발급받았는지를 조회·검색하는 화면. 코드 발급 자체는 SOB-02에서 이뤄지므로 이 화면에는 프로젝트 등록 기능이 없다(조회·검색 전용 — 프로젝트 수정·삭제도 없다 PC-164). SOBP 를 고객사에 매핑한 뒤 코드를 회수하는 기능은 서비스에 없다 PC-165. 실제 구현은 고객사 선택 → 프로젝트 → 발급 구성 3단이며, 좌측에 코드 종류(PDS2 · PDS3 · PDS4 · OID) · 유형(편집/코드발급) · 사용 서비스 3중 필터가 있다. 확장 언어 그룹의 확장 코드는 따로 보이지 않고 그 그룹 기본 코드 프로젝트 안에 보인다(S9). 그림의 값은 로컬 앱 시드 데이터 화면에서 옮겼다 (2026-11-23).
S1기본 · 고객사 선택 (프로젝트 미선택)기본
좌측 메뉴 [코드 ▸ 코드 프로젝트]로 진입. 실제 구현은 3단 구성이다 — ① 고객사 선택(280px) ② 프로젝트(250px) ③ 발급 구성(나머지). 상단은 KPI 카드가 아니라 요약 한 줄이며 우측에 [초기화]가 있다. 좌측·가운데 목록은 칸 안에서 스크롤된다(여기서는 앞부분만 그렸다).
