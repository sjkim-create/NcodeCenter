S1 기본 · 고객사 선택 (프로젝트 미선택)S2 프로젝트 선택 · 발급 구성S3 필터 적용 · PDS3 + 편집S4 공유 코드 · 사용 고객사(하위)S5 프로젝트 수정 (모달)S6 프로젝트 삭제 확인S7 검색 결과 없음S8 프로젝트 종료 고객사
고객사별로 어떤 코드(SOBP)를 얼마나 발급받았는지를 조회·검색하는 화면. 코드 발급 자체는 SOB-02에서 이뤄지므로 이 화면에는 프로젝트 등록 기능이 없다(조회·검색 전용 / 수정·삭제만 가능). 실제 구현은 고객사 선택 → 프로젝트 → 발급 구성 3단이며, 좌측에 코드 종류(PDS2/PDS3) · 유형(편집/코드발급) · 사용 서비스 3중 필터가 있다. 기준: web/components/ProjectsView.tsx (2026-08-27 확인).
S1기본 · 고객사 선택 (프로젝트 미선택)기본
좌측 메뉴 [코드 ▸ 코드 프로젝트]로 진입. 실제 구현은 3단 구성이다 — ① 고객사 선택(280px) ② 프로젝트(250px) ③ 발급 구성(나머지). 상단은 KPI 카드가 아니라 요약 한 줄이며 우측에 [초기화]가 있다. ⚠ PRD §1은 "좌: 고객사 목록 · 우: 선택 프로젝트 상세" 2단으로 적혀 있어 구현과 다르다.
