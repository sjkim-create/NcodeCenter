App Key 를 발급하는 화면이다. 「고객사 | App Key 계정 | 계정 상세」 3단 한 화면이며 옛 TKT-01 계정 발급(목록)과 옛 TKT-02 계정 등록·수정을 합쳤다 PC-146 PC-158. 고객사는 고객사 관리 고객사를 불러온다(여기서 등록하지 않음) PC-153. 계정은 App Key 계정 — 계정과 App Key 가 매칭되는 개념으로, 고객사 관리의 서비스 계정(서비스 권한)과 별개다. 화면 모양은 TKT-02 N Key 관리와 같은 조각을 쓴다 PC-154. App Key 와 티켓은 다른 개념 — 계정 상세의 탭이 [티켓 내역] · [티켓 발급] · [정산] · [계정 정보] · [권한] 순서다 PC-208 PC-211. App Key 는 계정을 만들 때 자동 생성되고(1계정 1키) [계정 정보]에 보인다 PC-210.
