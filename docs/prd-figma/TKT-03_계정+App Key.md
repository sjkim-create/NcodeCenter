## 2. 화면 구성

### 개요

**App Key = 계정과 연동되는 키**. 온라인 편집툴(Caster U)·폼솔루션·SDK 에서 쓰며 **계정(ID/PWD)과 SOBP 범위를 한 번에** 발급한다. 계정이 없으면 발급할 수 없으므로 신규 고객사는 이 화면에서 계정 등록과 키 발급을 한 흐름으로 처리한다.

카드 한 장 안에 **① 계정 → ② 할당된 SOBP 범위 → ③ 발급 조건** 이 이어지고, 맨 아래에 **서비스 DB** 목록이 붙는다. `TKT-01` 과 **고객사 선택값을 공유**한다.

**구분** — 확인창

| 요소 | 액션 | 결과 · 이동 | 메시지 · 비고 |

| [삭제] | 클릭 | 계정 + 키 삭제 | 서비스 DB 목록에서 사라진다 |
| [취소] | 클릭 | `TKT-03` | 변경 없음 |
| 키만 삭제 | — | 확인창 없음 | [키 삭제]는 확인 없이 바로 지운다 |

| 발급 메뉴 [발급 목록 · 정산] | 클릭 | `TKT-04` | 발급 이력·정산 |
