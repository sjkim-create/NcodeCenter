## 2. 화면 구성

### 개요

**PUI(Physical UI) = 종이 위 컨트롤러**에 쓰이는 코드. 재생·정지·볼륨 같은 **피지컬 조작 기능이 어떤 Book/Page에 매핑돼 있는지**를 확인하는 참조 화면. 구성은 **좌 280px 할당 목록 / 우 상세**이며, 상세는 **프로젝트·할당 코드** + 접었다 펼치는 **🖼 컨트롤러 이미지 · ⚙ 기능 매핑 · 📄 원본 시트** 3개 섹션이다. **이 화면에서는 코드를 발급하지 않는다**(발급은 `SOB-02`). 기준: `web/components/PuiView.tsx` · `data/pui-data.json`

## 3. 상태별 변화

### PRJ-06: S01 기본 · 첫 할당 자동 선택

*화면 정의서 상태 `S1`*

**구분** — 기본

좌측 메뉴 [서비스 관리 ▸ CasterN ▸ PUI 코드 (피지컬)]로 진입. 구현은 **첫 할당을 자동 선택**한다(`useState(D.allocations[0].sheet)`) — 따라서 **"할당 미선택" 상태는 실제로 나타나지 않는다**. 기본 펼침 상태는 **이미지만 펼침**, 기능 매핑·원본 시트는 접힘이다. 첫 할당(S3/O52 아이글 출석부)은 정규화된 프로젝트·기능 표가 없어 안내 문구가 보인다. 기준: `web/components/PuiView.tsx`
